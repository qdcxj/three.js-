# 阶段 08 · 开关门与昼夜

> 第 08 阶段的项目驱动教程源码快照：在 stage-07 的基础上加入开关门动画、开关灯、昼夜自动循环，全面教学 Three.js 动画系统。

## 运行

```bash
pnpm install
pnpm dev      # 开发模式
pnpm build    # 生产构建
pnpm preview  # 预览构建产物
```

## 操作

- **O 键**：开门 / 关门（门板绕门轴 Group 平滑旋转 0~90°）
- **L 键**：开灯 / 关灯（室内点光源 + 壁灯聚光灯强度 lerp 过渡）
- **昼夜循环**：自动进行，每 24 秒一天，阳光颜色 / 强度、环境光、天空颜色平滑过渡

## 累积内容

- stage-01：草地（带程序化草地贴图）
- stage-02：地基平台 + 入口台阶
- stage-03：四面墙（含门洞/窗洞）+ 木门
- stage-04：尖屋顶（双坡顶）+ 山墙 + 烟囱 + 室内地板
- stage-05：程序化砖墙 / 木纹 / 玻璃贴图
- stage-06：阳光 + 环境光 + 室内点光源 + 壁灯聚光灯 + 阴影
- stage-07：相机（简化为 OrbitControls，含阻尼）
- stage-08：开关门动画 + 开关灯 + 昼夜交替（Clock + lerp）
