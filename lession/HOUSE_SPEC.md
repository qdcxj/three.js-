# 欧式乡村小屋 · 统一规格说明（HOUSE_SPEC）

> 本文件是全教程 14 个建造阶段的**唯一房屋基准**。所有并行 Agent 必须严格遵守本规格，确保各阶段源码快照建出的是同一栋房子（只是建造进度不同）。

## 一、坐标系约定

- 原点 `(0, 0, 0)` = 房子中心地面点
- `+Y` 向上，`+Z` 向前（门朝向），`+X` 向右
- 右手坐标系（Three.js 默认）
- 单位：米（m），1 单位 = 1 米
- 地面 `y = 0`

## 三、墙面留洞实现方式

stage-03 砌墙时，前墙/侧墙的门窗洞用**多块 Box 拼接**实现（不用 CSG，保持简单可教学）：
- 前墙 = 门洞左侧块 + 门洞上方块 + 门洞右侧块 + 两个窗洞周围块
- 各块尺寸根据洞口位置精确计算，组到 `wallsGroup` 下
- 门洞、窗洞处留空（不填实体），后续阶段填入门板、玻璃

## 四、屋顶实现

stage-04 尖屋顶用 **2 块倾斜的 Box** 拼成双坡顶（人字形），或用 `ConeGeometry(半径, 高, 4, 1)` 旋转 45° 得到四棱锥再压扁。推荐双坡顶：
- 左坡：Box(8.4, 0.2, 3.5)，旋转 `rotateZ` 倾斜，顶边在 y=5.0
- 右坡：对称
- 前后山墙：三角形（用 Shape + ExtrudeGeometry 或两个倾斜 Box）

## 五、各阶段源码累积规则

每个 `stage-XX` 是**完整独立项目**，其 `HouseScene.vue` 包含**从 stage-01 到本阶段的所有构件**。即：
- stage-01 HouseScene.vue = 草地
- stage-02 HouseScene.vue = 草地 + 地基 + 台阶
- stage-03 HouseScene.vue = 草地 + 地基 + 台阶 + 四面墙(含洞) + 门板
- stage-04 HouseScene.vue = stage-03 + 尖屋顶 + 烟囱 + 室内地板 + 外墙材质
- stage-05 = stage-04 + 砖墙/木门/玻璃贴图 + 天空盒
- stage-06 = stage-05 + 阳光/环境光/室内灯/壁灯 + 阴影
- stage-07 = stage-06 + 第一人称漫游 + 鸟瞰切换
- stage-08 = stage-07 + 开关门动画 + 昼夜交替
- stage-09 = stage-08 + 家具 GLTF
- stage-10 = stage-09 + 玻璃着色器 + 草地着色器
- stage-11 = stage-10 + Bloom/景深后期
- stage-12 = stage-11 + 烟囱粒子
- stage-13 = stage-12 + 性能优化（Stats/LOD/InstancedMesh）
- stage-14 = 整合所有，最终完整欧式乡村小屋

**关键**：每个 stage-XX 的 HouseScene.vue 必须是可直接运行的完整代码，复制粘贴即用。后续阶段可在前序阶段代码基础上递增，但每个快照独立完整。

## 六、技术栈与项目模板（每个 stage-XX 通用）

- Vite 5 + Vue 3.5（组合式 API `<script setup>`）
- three@0.169.0
- `import * as THREE from "three"`
- 相机：PerspectiveCamera(50, aspect, 0.1, 200)，初始位置 (12, 8, 12) 看向原点
- 渲染器：WebGLRenderer({ antialias: true })，开启 shadowMap（stage-06 起）
- 控制器：OrbitControls（stage-01~06），stage-07 起加 PointerLockControls
- 渲染循环：requestAnimationFrame + Clock
- 生命周期：onMounted 初始化，onUnmounted dispose 清理（geometry/material/renderer/controls 全释放）
- resize 监听
