# Three.js 教程重构：建造一栋欧式乡村小屋（项目驱动）

## Context（为什么做这个改动）

当前教程是 15 章「理论分章」结构（基础概念 → 核心组件 → 几何体 → 材质 → ... → 案例），知识点虽全但脱离实际场景，学习者难以串联。用户希望将整个教程重构为**一个贯穿始终的实战项目——建造一栋欧式乡村小屋**：每一章推进小屋的一个建造阶段，在建造过程中自然学完所有 Three.js 知识，最终交付一栋完整房子 + 可运行源码。

欧式乡村小屋天然覆盖全部知识点：尖屋顶→锥体几何、砖墙→贴图、烟囱→粒子烟雾、木门→动画开关、玻璃窗→着色器/透射、室内灯→灯光阴影、家具→模型加载。源码按「每章独立快照」组织，每个阶段是一个完整可运行的 Vite + Vue 3 + Three.js 项目，学习者可跳到任意阶段直接运行。
