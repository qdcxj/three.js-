# 🏠 第 08 阶段：开关门与昼夜

> 走到第 08 阶段，我们的乡村小屋终于"活"了起来——门会绕门轴缓缓打开、室内灯会一按 L 键亮起、整片天空还会自动在白天与黑夜之间循环。本阶段在 stage-07 相机漫游的基础上，正式踏入 Three.js 的**动画系统**：用 `requestAnimationFrame` + `THREE.Clock` 驱动每一帧，用 `lerp` 做平滑过渡，用键盘事件触发状态切换，最终实现一栋会呼吸的小屋。

## 🎯 建造目标

| # | 构件 | 关键参数 | 交互方式 |
|---|------|----------|----------|
| 1 | 门动画 | 门轴 Group（pivot）绕 Y 轴 0~90° lerp 旋转 | 按 O 键开关门 |
| 2 | 室内灯动画 | 室内点光源 + 壁灯聚光灯 intensity 在 0↔1.5 间 lerp | 按 L 键开关灯 |
| 3 | 昼夜交替 | 阳光颜色/intensity + 环境光 + 天空颜色 lerp，24 秒一天 | 自动循环 |
| 4 | UI 状态卡片 | 左上角操作提示、右上角实时状态、底部动画说明 | Vue 响应式 |
| 5 | 累积构件 | 草地+地基+台阶+四面墙含洞+木门+尖屋顶+山墙+烟囱+室内地板+玻璃+灯光+阴影 | OrbitControls |

到本阶段末，运行项目应能看到：暖米色砖墙小屋立在草地上，屋顶是砖红色双坡顶、右侧立着灰色烟囱。按一下 **O**，木门会平滑地绕左侧门轴向内打开 90°；再按一下又平滑关闭。按 **L**，室内点光源和两盏壁灯聚光灯会从 0 平滑亮起，把室内照得暖黄。什么都不按时，天空背景会在天空蓝与深夜蓝黑之间缓慢循环，阳光从东升到西落，环境光也随之明暗起伏。

## 📚 学习目标

完成本阶段后，你应当能够：

- **理解 `requestAnimationFrame` 渲染循环的原理**：知道为什么 3D 应用要"每帧重绘"，以及它与 `setInterval` 的本质区别
- **掌握 `THREE.Clock` 与 `getDelta()`**：能用帧间隔 `dt` 写出"帧率无关"的动画代码，理解 60fps 与 30fps 下动画速度一致的秘诀
- **手写 lerp 平滑过渡**：用 `current += (target - current) * factor` 让任意数值（角度、强度、颜色）平滑变化
- **用 Group 做 pivot 实现旋转动画**：理解为什么不能直接旋转门板（会绕自身中心自旋），以及如何用父级 Group 充当门轴
- **用键盘事件驱动 3D 状态切换**：把 `window.addEventListener('keydown', ...)` 接入 Three.js 渲染循环
- **用余弦函数实现昼夜循环**：理解"关键帧"概念，知道如何用一条余弦曲线把时间映射到光照强度与颜色
