# 昼夜交替动画：用余弦曲线驱动整个世界

stage-08 前两节我们做了"局部动画"——门绕轴旋转、灯强度 lerp。本节我们要做"全局动画"：**让整个场景的阳光颜色、阳光强度、环境光强度、天空背景颜色，全部跟随时间循环变化**，实现完整的白天 → 黄昏 → 夜晚 → 黎明循环。

这是 stage-08 最有"世界观"感的一节：你会看到一栋小屋在 24 秒里经历完整的昼夜——天空从蓝变黑又变蓝，阳光从暖白变冷蓝又变暖白，环境光起伏，整片草地和墙面跟着明暗呼吸。本节也是"关键帧动画"概念的最简入门——只不过我们用一条数学曲线（余弦）代替离散关键帧，让代码更紧凑。

## 一、为什么昼夜循环是"动画系统"的集大成

昼夜交替同时驱动了 5 个独立的"动画通道"：

| 通道 | 白天值 | 夜晚值 | 过渡方式 |
|------|--------|--------|----------|
| 阳光颜色 | 暖白 `#fffaf0` | 冷蓝 `#6f8fff` | Color.lerp |
| 阳光 intensity | 1.4 | 0.25 | 数值 lerp |
| 阳光位置 | 东上方 | 西下方（地下） | 极坐标弧线 |
| 环境光 intensity | 0.55 | 0.12 | 数值 lerp |
| 天空背景颜色 | 天空蓝 `#87ceeb` | 深夜蓝黑 `#0a0f2a` | Color.lerp |

这 5 个通道必须**同步**——它们都由同一个"时间因子" `dayFactor` 驱动，所以天然同步。这就是"关键帧动画"的核心思想：**定义几个关键时刻（白天、夜晚）的值，让中间时刻在两个值之间插值**。

## 二、关键帧概念：用余弦代替离散关键帧

### 1. 离散关键帧 vs 数学曲线

正式的"关键帧动画"（如 Three.js 的 `AnimationClip`）会定义一组 `(时间, 值)` 对，中间用线性或样条插值。例如昼夜可以这样定义：

```js
// 离散关键帧写法（更复杂但更灵活）
const keyframes = [
  { t: 0.0, sunIntensity: 1.4, skyColor: 0x87ceeb },   // 正午
  { t: 0.25, sunIntensity: 0.6, skyColor: 0xff8866 },  // 黄昏
  { t: 0.5, sunIntensity: 0.25, skyColor: 0x0a0f2a },  // 子夜
  { t: 0.75, sunIntensity: 0.6, skyColor: 0xffaa88 },  // 黎明
  { t: 1.0, sunIntensity: 1.4, skyColor: 0x87ceeb },   // 回到正午
];
// 然后根据当前 t 找到所在区间，线性插值
```

但昼夜是**周期性、对称**的——白天最高、夜晚最低、中间平滑过渡。这种形状恰好是**余弦曲线**！用一条数学曲线代替离散关键帧，代码大幅简化：

```js
// 余弦曲线写法（stage-08 采用）
const t = cycleTime / DAY_PERIOD;   // 归一化时间 [0, 1]
// cos(2πt) 在 t=0 时为 1（正午），t=0.5 时为 -1（子夜）
// 映射到 [0,1]：(cos(2πt) + 1) / 2
const dayFactor = (Math.cos(t * Math.PI * 2) + 1) / 2;
// dayFactor：t=0 → 1（白天），t=0.5 → 0（夜晚），t=1 → 1（回到白天）
```

::: tip 数学之美
`dayFactor` 这条曲线一次性表达了所有信息：
- `dayFactor = 1`：白天最高点（正午）
- `dayFactor = 0`：夜晚最低点（子夜）
- `dayFactor = 0.5`：黄昏 / 黎明（半亮）

后续 5 个通道都只需要"在白天值和夜晚值之间，按 `dayFactor` 插值"——一行 lerp 搞定。
:::

### 2. 24 秒一天：演示周期

真实昼夜是 24 小时，但教程里我们要等 24 小时才能看到效果就太久了。stage-08 把一天压缩成 **24 秒**：

```js
const DAY_PERIOD = 24; // 一天 24 秒（演示用，便于观察）
let cycleTime = 0;

const updateDayNight = (dt) => {
  cycleTime = (cycleTime + dt) % DAY_PERIOD; // 累加并取模，循环
  const t = cycleTime / DAY_PERIOD;          // 归一化到 [0, 1]
  // ...
};
```

`% DAY_PERIOD` 让 `cycleTime` 在 24 秒后归零，形成无限循环。每帧累加 `dt`，仍是帧率无关——60fps 下每帧 +0.0167s，30fps 下每帧 +0.0333s，但每秒累计都是 1s。

## 三、灯光颜色 / 强度的时间驱动

### 1. 颜色 lerp：Color.lerp

`THREE.Color` 自带 `lerp` 方法，能在两个颜色之间线性插值：

```js
import * as THREE from "three";

const DAY_SUN_COLOR = new THREE.Color(0xfffaf0);   // 暖白阳光
const NIGHT_SUN_COLOR = new THREE.Color(0x6f8fff); // 冷蓝月光

// 复用临时对象，避免每帧 new（GC 压力）
const _tmpSunColor = new THREE.Color();

const updateSunColor = (dayFactor) => {
  // 从夜晚色 lerp 到白天色，比例为 dayFactor
  _tmpSunColor.copy(NIGHT_SUN_COLOR).lerp(DAY_SUN_COLOR, dayFactor);
  sunLight.color.copy(_tmpSunColor);
};
```

::: warning 别在循环里 new Color
每帧 60 次 `new THREE.Color()` 会产生大量临时对象，触发频繁 GC，造成卡顿。**所有动画循环里的临时变量都要在循环外创建一次**，循环里只用 `.copy()` / `.lerp()` / `.set()` 修改值。stage-08 在文件顶部声明了 `_tmpSunColor` / `_tmpSkyColor`，循环里复用。
:::

### 2. 强度 lerp：数值 lerp

强度是普通数值，用上一节的帧率无关 lerp 公式（但其实昼夜循环里 `dayFactor` 本身已经是平滑曲线，不需要再 lerp，直接插值即可）：

```js
const DAY_SUN_INTENSITY = 1.4;
const NIGHT_SUN_INTENSITY = 0.25;

sunLight.intensity =
  NIGHT_SUN_INTENSITY +
  (DAY_SUN_INTENSITY - NIGHT_SUN_INTENSITY) * dayFactor;
```

这就是最朴素的**线性插值**公式：`result = a + (b - a) * t`，其中 `t` 是 [0,1] 的比例。当 `dayFactor=1` 时结果是 `DAY_SUN_INTENSITY`，`dayFactor=0` 时是 `NIGHT_SUN_INTENSITY`。

## 四、天空背景颜色过渡

`scene.background` 可以是一个 `THREE.Color`，每帧修改它的 RGB 即可：

```js
const DAY_SKY_COLOR = new THREE.Color(0x87ceeb);   // 天空蓝
const NIGHT_SKY_COLOR = new THREE.Color(0x0a0f2a); // 深夜蓝黑
const _tmpSkyColor = new THREE.Color();

// 在 updateDayNight 里
_tmpSkyColor.copy(NIGHT_SKY_COLOR).lerp(DAY_SKY_COLOR, dayFactor);
scene.background.copy(_tmpSkyColor);
```

::: tip 进阶：用天空盒贴图代替纯色
stage-08 用纯色背景简化教学。生产环境会用 `CubeTexture` 或 `RGBELoader` 加载 HDR 天空盒，并通过 `scene.background` / `scene.environment` 设置。如果想做"日间天空盒 → 夜间天空盒"过渡，需要加载两张天空盒，用 shader 在两者间混合，或用 `PMREMGenerator` 重新生成环境贴图。stage-10 着色器章节会涉及相关技巧。
:::

## 五、阳光位置：极坐标划弧

阳光颜色和强度还不足以表达"日出日落"——还要让太阳**在天空中划一道弧线**。用极坐标最直观：

```js
const updateSunPosition = (t) => {
  // t 是归一化时间 [0, 1]，0=日出，0.25=正午，0.5=日落，0.75=子夜
  const angle = t * Math.PI * 2; // 一整圈
  sunLight.position.set(
    Math.cos(angle) * 12,             // X：东 → 西
    Math.sin(angle) * 12 + 2,         // Y：日出 → 正午 → 日落 → 地下
    8                                  // Z：固定略偏南
  );
};
```

- `t=0`：`angle=0`，位置 `(12, 2, 8)`——东边低空（日出）
- `t=0.25`：`angle=π/2`，位置 `(0, 14, 8)`——正上方（正午）
- `t=0.5`：`angle=π`，位置 `(-12, 2, 8)`——西边低空（日落）
- `t=0.75`：`angle=3π/2`，位置 `(0, -10, 8)`——地下（子夜，阳光被地球挡住）

`+2` 是把整条弧线抬高一点，避免日出日落时太阳完全贴地。月光其实应该从相反方向来，但 stage-08 简化处理——夜晚阳光 intensity 降到 0.25 充当"残余环境光"，不再单独建模月亮。

::: warning 阳光在地下时阴影怎么办
`sunLight.position.y` 为负时，光线从地下向上照，物理上不合理。但因为我们已经在 `dayFactor=0` 时把 `intensity` 降到 0.25，阴影会变得极淡几乎看不见，视觉上不会出戏。如果追求严谨，可以在 `dayFactor < 0.1` 时把 `sunLight.castShadow = false`，白天再打开。
:::

## 六、完整昼夜循环代码

把上面所有片段合到一起，stage-08 的 `updateDayNight` 函数：

```js
import * as THREE from "three";

// 关键帧常量
const DAY_PERIOD = 24;
const DAY_SUN_COLOR = new THREE.Color(0xfffaf0);
const NIGHT_SUN_COLOR = new THREE.Color(0x6f8fff);
const DAY_SKY_COLOR = new THREE.Color(0x87ceeb);
const NIGHT_SKY_COLOR = new THREE.Color(0x0a0f2a);
const DAY_AMBIENT = 0.55;
const NIGHT_AMBIENT = 0.12;
const DAY_SUN_INTENSITY = 1.4;
const NIGHT_SUN_INTENSITY = 0.25;

// 复用临时对象
const _tmpSunColor = new THREE.Color();
const _tmpSkyColor = new THREE.Color();

// 状态变量
let cycleTime = 0;
let sunLight = null;
let ambientLight = null;

const updateDayNight = (dt) => {
  // 1. 累加时间并取模
  cycleTime = (cycleTime + dt) % DAY_PERIOD;
  const t = cycleTime / DAY_PERIOD;

  // 2. 用余弦把 t 映射到 dayFactor [0, 1]
  const dayFactor = (Math.cos(t * Math.PI * 2) + 1) / 2;

  // 3. 阳光颜色 lerp（暖白 ↔ 冷蓝）
  _tmpSunColor.copy(NIGHT_SUN_COLOR).lerp(DAY_SUN_COLOR, dayFactor);
  sunLight.color.copy(_tmpSunColor);

  // 4. 阳光强度 lerp（0.25 ↔ 1.4）
  sunLight.intensity =
    NIGHT_SUN_INTENSITY +
    (DAY_SUN_INTENSITY - NIGHT_SUN_INTENSITY) * dayFactor;

  // 5. 环境光强度 lerp（0.12 ↔ 0.55）
  ambientLight.intensity =
    NIGHT_AMBIENT + (DAY_AMBIENT - NIGHT_AMBIENT) * dayFactor;

  // 6. 天空背景颜色 lerp（天空蓝 ↔ 深夜蓝黑）
  _tmpSkyColor.copy(NIGHT_SKY_COLOR).lerp(DAY_SKY_COLOR, dayFactor);
  scene.background.copy(_tmpSkyColor);

  // 7. 阳光位置划弧（极坐标）
  const angle = t * Math.PI * 2;
  sunLight.position.set(
    Math.cos(angle) * 12,
    Math.sin(angle) * 12 + 2,
    8
  );

  // 8. 更新 UI 阶段文案
  if (dayFactor > 0.75) ui.phase = "白天";
  else if (dayFactor > 0.4) ui.phase = "黄昏/黎明";
  else ui.phase = "夜晚";
};
```

## 七、UI 阶段文案：把 dayFactor 翻译成人话

`dayFactor` 是 [0, 1] 的连续值，但用户看到的应该是"白天 / 黄昏 / 夜晚 / 黎明"这种离散标签。在 `updateDayNight` 末尾做一次"阈值判断"：

```js
if (dayFactor > 0.75) ui.phase = "白天";
else if (dayFactor > 0.4) ui.phase = "黄昏/黎明";
else ui.phase = "夜晚";
```

为什么 0.75 和 0.4？

- `dayFactor > 0.75`：靠近白天峰值，颜色和强度都接近白天
- `0.4 < dayFactor ≤ 0.75`：过渡区间（黄昏或黎明，从两个方向都经过这里）
- `dayFactor ≤ 0.4`：靠近夜晚谷底

由于余弦曲线是对称的，`dayFactor` 在 `0.4 → 0 → 0.4` 这段会经过两次（黄昏 → 夜晚 → 黎明），但因为我们没区分"上升"还是"下降"，所以统一显示"黄昏/黎明"。如果想精确区分，需要看 `dayFactor` 的导数（`-sin(2πt)`）正负。

## 八、配合开关灯：夜晚自动亮灯

昼夜循环让场景有了白天和黑夜，但小屋的室内灯按 L 键才能开——这意味着夜晚用户不按 L 键，屋里就一片漆黑。可以在 `updateDayNight` 里加一个"夜晚自动开灯"逻辑（stage-08 没启用，但可作为练习）：

```js
// 练习：夜晚自动开灯（未启用）
if (dayFactor < 0.3 && !lampOn) {
  lampOn = true;
  ui.lampState = "开启（自动）";
} else if (dayFactor > 0.5 && lampOn) {
  lampOn = false;
  ui.lampState = "关闭";
}
```

::: tip 思考题
为什么这里要用 `dayFactor < 0.3` 和 `dayFactor > 0.5` 两个不同阈值，而不是同一个阈值？——答：避免在阈值附近反复横跳（"抖动"）。这叫"滞回"（hysteresis），工程上控制开关都该这么写。
:::

## 九、关键帧动画的进阶：AnimationClip

本节用余弦曲线代替关键帧，是"周期性、对称"动画的最简方案。但对于**复杂非周期动画**（如角色行走、相机沿曲线运动），就需要正式的关键帧系统。Three.js 提供了三件套：

| 类 | 作用 |
|----|------|
| `THREE.KeyframeTrack` | 一条动画通道（如"position.x"在 t=0 时为 0，t=1 时为 5） |
| `THREE.AnimationClip` | 多条 Track 的集合（一个完整动作，如"走路"） |
| `THREE.AnimationMixer` | 播放控制器，绑定到 Object3D，控制 play/stop/pause |

stage-08 不深入这块——把它当作"下一站"的预告。当你需要做"开门时有咯吱声 + 门把手先转 10°再拉开门"这种复合动画时，AnimationClip 就比手写 lerp 更合适。

## 十、本节总结

- **昼夜循环的本质**：用一条余弦曲线 `dayFactor = (cos(2πt) + 1) / 2` 把时间映射到 [0, 1]，再让 5 个动画通道（阳光颜色 / 强度 / 位置、环境光强度、天空颜色）按 `dayFactor` 在白天值和夜晚值之间 lerp
- **关键帧概念**：定义几个关键时刻的值，中间插值。本节用数学曲线代替离散关键帧，代码更紧凑；复杂场景需用 `AnimationClip`
- **颜色 lerp**：`Color.lerp(c2, t)`，循环里务必复用临时 Color 对象，避免每帧 `new`
- **阳光位置划弧**：极坐标 `(cos(angle)*r, sin(angle)*r, z)` 让阳光在天空中划圆，物理上等价于地球自转
- **UI 同步**：把连续的 `dayFactor` 用阈值翻译成离散标签（白天/黄昏/夜晚/黎明），更新 Vue 响应式数据
