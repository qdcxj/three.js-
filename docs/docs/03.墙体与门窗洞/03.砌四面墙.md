# 砌四面墙

地基已经摆好，台阶也砌完了。现在我们正式进入「毛坯房」阶段：在 8×6 的地基四周立起四面墙，并在墙上留出门洞和窗洞。

本节是 stage-03 最核心的实战内容。我们会用前两节学到的 `Object3D` 变换和 `Group` 场景图，把一面带洞的墙拆成多块实心 Box，**精确推演每一块的尺寸和位置**，最终拼出完整的小屋墙体。

## 一、整体尺寸回顾

按 `HOUSE_SPEC.md`，四面墙的尺寸和位置如下：

| 墙体 | 尺寸（米） | 中心坐标 | 备注 |
|------|-----------|----------|------|
| 后墙 | 8 × 3 × 0.2 | (0, 1.8, -3) | 整块无洞 |
| 左墙 | 0.2 × 3 × 6 | (-4, 1.8, 0) | 中央留侧窗洞 |
| 右墙 | 0.2 × 3 × 6 | (4, 1.8, 0) | 中央留侧窗洞 |
| 前墙 | 8 × 3 × 0.2 | (0, 1.8, 3) | 中央门洞 + 两侧窗洞 |

需要留的洞口：

- 前墙门洞：`1.0(X) × 2.0(Y)`，中心 `(0, 1.3, 3)`
- 前墙窗洞 ×2：`0.8(X) × 1.2(Y)`，中心 `(-2, 1.5, 3)` 与 `(2, 1.5, 3)`
- 侧墙窗洞 ×2：`1.2(Z) × 1.2(Y)`，中心 `(-4, 1.5, 0)` 与 `(4, 1.5, 0)`

::: tip 关键尺寸推导
地基顶面在 `y=0.3`，墙高 3 米，所以墙的纵向范围是 `y ∈ [0.3, 3.3]`，中心 `y = 1.8`。地基在 X 方向 ±4、Z 方向 ±3，所以墙的四个面就贴着地基的四个边沿。
:::

## 二、后墙：最简单的一块

后墙是整块无洞，直接一块 Box 搞定：

```js
import * as THREE from "three";

function createBackWall(material) {
  // 8(X) × 3(Y) × 0.2(Z)，中心 (0, 1.8, -3)
  const geometry = new THREE.BoxGeometry(8, 3, 0.2);
  const mesh = new THREE.Mesh(geometry, material);
  mesh.position.set(0, 1.8, -3);
  mesh.name = "back-wall";
  return mesh;
}
```

后墙的中心在 `(0, 1.8, -3)`：`z = -3` 是地基后边沿，墙厚 0.2 所以墙体范围 `z ∈ [-3.1, -2.9]`。

## 三、前墙：拆成 9 块拼出门窗洞

前墙是最复杂的——它有 1 个门洞和 2 个窗洞。我们把它**拆成多块实心 Box**，拼出洞口。先列出墙体范围和洞口范围：

```
墙体范围：x ∈ [-4, 4]，y ∈ [0.3, 3.3]，z = 3（厚 0.2）
门洞范围：x ∈ [-0.5, 0.5]，y ∈ [0.3, 2.3]   ← 宽 1.0，高 2.0，门洞通到地面
左窗洞范围：x ∈ [-2.4, -1.6]，y ∈ [0.9, 2.1] ← 宽 0.8，高 1.2
右窗洞范围：x ∈ [1.6, 2.4]，y ∈ [0.9, 2.1]
```

### 拆分思路

按 X 方向把墙切成 9 段，每段在 Y 方向再切（如有窗洞）：

| # | 名称 | X 范围 | Y 范围 | 尺寸 (W×H×D) | 中心 (x, y, z) |
|---|------|--------|--------|--------------|----------------|
| ① | 左端块 | [-4, -2.4] | [0.3, 3.3] | 1.6 × 3.0 × 0.2 | (-3.2, 1.8, 3) |
| ② | 左窗台 | [-2.4, -1.6] | [0.3, 0.9] | 0.8 × 0.6 × 0.2 | (-2, 0.6, 3) |
| ③ | 左窗顶 | [-2.4, -1.6] | [2.1, 3.3] | 0.8 × 1.2 × 0.2 | (-2, 2.7, 3) |
| ④ | 门洞左侧块 | [-1.6, -0.5] | [0.3, 3.3] | 1.1 × 3.0 × 0.2 | (-1.05, 1.8, 3) |
| ⑤ | 门洞上方块 | [-0.5, 0.5] | [2.3, 3.3] | 1.0 × 1.0 × 0.2 | (0, 2.8, 3) |
| ⑥ | 门洞右侧块 | [0.5, 1.6] | [0.3, 3.3] | 1.1 × 3.0 × 0.2 | (1.05, 1.8, 3) |
| ⑦ | 右窗台 | [1.6, 2.4] | [0.3, 0.9] | 0.8 × 0.6 × 0.2 | (2, 0.6, 3) |
| ⑧ | 右窗顶 | [1.6, 2.4] | [2.1, 3.3] | 0.8 × 1.2 × 0.2 | (2, 2.7, 3) |
| ⑨ | 右端块 | [2.4, 4] | [0.3, 3.3] | 1.6 × 3.0 × 0.2 | (3.2, 1.8, 3) |

::: tip 验证一下尺寸
墙体总面积 = 8 × 3 = 24 m²。洞口总面积 = 门洞 1.0×2.0 + 两个窗洞 2×0.8×1.2 = 2.0 + 1.92 = 3.92 m²。墙体净面积 = 24 - 3.92 = 20.08 m²。

九块墙面积之和 = 4.8 + 0.48 + 0.96 + 3.3 + 1.0 + 3.3 + 0.48 + 0.96 + 4.8 = 20.08 m² ✓

完全对得上，没有遗漏也没有重叠。
:::

### 代码实现

```js
import * as THREE from "three";

// 小工具：根据尺寸 + 中心位置创建一块墙
function makeWallBox(width, height, depth, x, y, z, material, name) {
  const geometry = new THREE.BoxGeometry(width, height, depth);
  const mesh = new THREE.Mesh(geometry, material);
  mesh.position.set(x, y, z);
  if (name) mesh.name = name;
  return mesh;
}

function createFrontWall(material) {
  const group = new THREE.Group();
  group.name = "front-wall";

  // ① 左端块
  group.add(makeWallBox(1.6, 3.0, 0.2, -3.2, 1.8, 3, material, "front-wall-left-edge"));
  // ② 左窗台
  group.add(makeWallBox(0.8, 0.6, 0.2, -2, 0.6, 3, material, "front-wall-left-sill"));
  // ③ 左窗顶
  group.add(makeWallBox(0.8, 1.2, 0.2, -2, 2.7, 3, material, "front-wall-left-header"));
  // ④ 门洞左侧块
  group.add(makeWallBox(1.1, 3.0, 0.2, -1.05, 1.8, 3, material, "front-wall-left-of-door"));
  // ⑤ 门洞上方块（过梁）
  group.add(makeWallBox(1.0, 1.0, 0.2, 0, 2.8, 3, material, "front-wall-above-door"));
  // ⑥ 门洞右侧块
  group.add(makeWallBox(1.1, 3.0, 0.2, 1.05, 1.8, 3, material, "front-wall-right-of-door"));
  // ⑦ 右窗台
  group.add(makeWallBox(0.8, 0.6, 0.2, 2, 0.6, 3, material, "front-wall-right-sill"));
  // ⑧ 右窗顶
  group.add(makeWallBox(0.8, 1.2, 0.2, 2, 2.7, 3, material, "front-wall-right-header"));
  // ⑨ 右端块
  group.add(makeWallBox(1.6, 3.0, 0.2, 3.2, 1.8, 3, material, "front-wall-right-edge"));

  return group;
}
```

注意所有块都用 `material` 这个**共享实例**——节省显存，且将来换贴图只需改一处。这是「材质共享」模式。

## 四、左右墙：各拆成 4 块拼出侧窗洞

左右墙是对称的，我们以左墙为例。左墙尺寸 `0.2 × 3 × 6`，中心 `(-4, 1.8, 0)`，墙体范围 `x ∈ [-4.1, -3.9]`、`y ∈ [0.3, 3.3]`、`z ∈ [-3, 3]`。

侧墙窗洞在墙体中央：`1.2(Z) × 1.2(Y)`，中心 `(-4, 1.5, 0)`，即 `z ∈ [-0.6, 0.6]`、`y ∈ [0.9, 2.1]`。

### 拆分思路

把墙沿 Z 方向切三段（前段、中段、后段），中段再沿 Y 方向切两段（窗台 + 窗顶）：

| # | 名称 | Z 范围 | Y 范围 | 尺寸 (X×Y×Z) | 中心 (x, y, z) |
|---|------|--------|-------|--------------|----------------|
| ① | 前段 | [0.6, 3.0] | [0.3, 3.3] | 0.2 × 3.0 × 2.4 | (-4, 1.8, 1.8) |
| ② | 后段 | [-3.0, -0.6] | [0.3, 3.3] | 0.2 × 3.0 × 2.4 | (-4, 1.8, -1.8) |
| ③ | 窗台 | [-0.6, 0.6] | [0.3, 0.9] | 0.2 × 0.6 × 1.2 | (-4, 0.6, 0) |
| ④ | 窗顶 | [-0.6, 0.6] | [2.1, 3.3] | 0.2 × 1.2 × 1.2 | (-4, 2.7, 0) |

### 代码实现

```js
function createLeftWall(material) {
  const group = new THREE.Group();
  group.name = "left-wall";

  group.add(makeWallBox(0.2, 3.0, 2.4, -4, 1.8, 1.8, material, "left-wall-front"));
  group.add(makeWallBox(0.2, 3.0, 2.4, -4, 1.8, -1.8, material, "left-wall-back"));
  group.add(makeWallBox(0.2, 0.6, 1.2, -4, 0.6, 0, material, "left-wall-sill"));
  group.add(makeWallBox(0.2, 1.2, 1.2, -4, 2.7, 0, material, "left-wall-header"));

  return group;
}

function createRightWall(material) {
  // 与左墙完全对称，只是 x=4
  const group = new THREE.Group();
  group.name = "right-wall";

  group.add(makeWallBox(0.2, 3.0, 2.4, 4, 1.8, 1.8, material, "right-wall-front"));
  group.add(makeWallBox(0.2, 3.0, 2.4, 4, 1.8, -1.8, material, "right-wall-back"));
  group.add(makeWallBox(0.2, 0.6, 1.2, 4, 0.6, 0, material, "right-wall-sill"));
  group.add(makeWallBox(0.2, 1.2, 1.2, 4, 2.7, 0, material, "right-wall-header"));

  return group;
}
```

::: warning 别忘了 BoxGeometry 参数顺序
`BoxGeometry(width, height, depth)` 对应 `(X, Y, Z)`。左墙是「瘦高长」的板子，宽（X）= 0.2，高（Y）= 3，深（Z）= 6。但拆出来的「前段」是「矮粗」板子：宽 0.2、高 3、深 2.4。注意区分。
:::

## 五、组装到 house Group

四面墙都创建好之后，把它们挂到一个统一的 `wallsGroup` 里，再挂到 `house` 下：

```js
function createHouse() {
  const house = new THREE.Group();
  house.name = "house";

  // 共享一份墙体材质
  const wallMaterial = new THREE.MeshStandardMaterial({
    color: 0xe6d5b8, // 暖米色
    roughness: 0.85,
    metalness: 0.0,
  });

  // wallsGroup：所有墙归到一起
  const wallsGroup = new THREE.Group();
  wallsGroup.name = "walls";
  wallsGroup.add(createBackWall(wallMaterial));
  wallsGroup.add(createLeftWall(wallMaterial));
  wallsGroup.add(createRightWall(wallMaterial));
  wallsGroup.add(createFrontWall(wallMaterial));
  house.add(wallsGroup);

  // 门板单独挂到 house（下一节实现）
  // const door = createDoor();
  // house.add(door);

  return house;
}

scene.add(createHouse());
```

到这里，四面墙已经围合完整。运行起来你应该能看到一栋有门洞和窗洞的毛坯房——但门洞是空的，还需要把门板装上（下一节）。

## 六、为什么不用 CSG？

CSG（Constructive Solid Geometry）确实能「在一个 Box 上减去另一个 Box」得到带洞形状，但我们选择「多块拼接」的方案，原因如下：

1. **零依赖**：CSG 需要引入 `three-bvh-csg` 等额外库，多一个依赖就多一个潜在问题源
2. **可调试**：每块墙都是独立的 Mesh，命名后可以单独 `visible=false` 看效果，调试极其方便
3. **顶点更少**：CSG 生成的几何体顶点结构复杂，拼接方案每块都是简单 Box，渲染更快
4. **教学清晰**：拼接方案能让学生直观看到「墙是怎么变成这个形状的」，CSG 是黑盒

::: tip 什么时候用 CSG
当洞口形状复杂（圆形、不规则曲线）或墙体本身就是异形（弧形墙、斜墙）时，拼接方案会变得非常繁琐，那时再考虑 CSG。本项目所有洞都是矩形，拼接是最优解。
:::

## 本节总结

| 知识点 | 要点 |
|--------|------|
| 后墙 | 整块无洞，最简单 |
| 前墙 | 拆 9 块：2 端块 + 2 窗台 + 2 窗顶 + 门洞左/右 + 门洞上方 |
| 左右墙 | 各拆 4 块：前段 + 后段 + 窗台 + 窗顶，对称结构 |
| 拆分原则 | 按 X / Z 方向切长段，洞口位置再沿 Y 切短段 |
| 共享材质 | 所有墙用同一份 `MeshStandardMaterial` 实例，节省显存 |
| 工具函数 | `makeWallBox(W, H, D, x, y, z, material, name)` 简化重复代码 |
| 不用 CSG | 拼接方案零依赖、可调试、顶点少、教学清晰 |
