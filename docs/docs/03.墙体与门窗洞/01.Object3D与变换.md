# Object3D 与变换

在 Three.js 里，几乎**所有出现在场景里的东西**——网格 Mesh、灯光 Light、相机 Camera、辅助对象 Helper、分组 Group——都继承自同一个基类：`Object3D`。理解 `Object3D` 就是理解 Three.js 的「世界观」：所有可见对象都有位置、旋转、缩放，都能被加到场景里、被父节点带着走。

本节我们从 `Object3D` 这个根概念出发，掌握它的三大变换属性 `position` / `rotation` / `scale`，再学一个常用的 `lookAt` 朝向方法。这些都是本阶段砌墙时定位每一块墙板的基础。

## 一、Object3D 是「万物基类」

`Object3D` 是 Three.js 中所有 3D 对象的基类。它本身不渲染任何东西，但它定义了所有 3D 对象**共有的能力**：

- **变换**：`position`（位置）、`rotation`（旋转）、`scale`（缩放）
- **父子关系**：`parent` / `children`，构成场景图
- **可见性**：`visible` 控制是否渲染
- **命名**：`name` 属性，便于后续查找
- **矩阵**：`matrix`（局部变换矩阵）、`matrixWorld`（世界变换矩阵）

我们平时用的 `Mesh`、`Group`、`Light`、`Camera` 等都是 `Object3D` 的子类：

```js
import * as THREE from "three";

// Mesh 是 Object3D 的子类
const mesh = new THREE.Mesh(geometry, material);
console.log(mesh instanceof THREE.Object3D); // true

// Light 也是
const light = new THREE.AmbientLight(0xffffff, 0.5);
console.log(light instanceof THREE.Object3D); // true

// Camera 也是
const camera = new THREE.PerspectiveCamera(50, 1, 0.1, 200);
console.log(camera instanceof THREE.Object3D); // true

// Group 自然也是
const group = new THREE.Group();
console.log(group instanceof THREE.Object3D); // true
```

::: tip 为什么基类是 Object3D？
因为「位置 / 旋转 / 缩放 / 父子关系」这些能力是所有 3D 对象都需要的。把这些共性抽到基类里，子类只需专注自己的「专业能力」（Mesh 负责渲染几何体，Light 负责发光，Camera 负责投影），代码复用就到位了。
:::

## 二、position：对象在哪儿

`position` 是一个 `Vector3`，表示对象**在父节点坐标系下**的位置。三个分量分别是 `x`、`y`、`z`。

```js
import * as THREE from "three";

const mesh = new THREE.Mesh(geometry, material);

// 三种等价的写法
mesh.position.set(0, 1.8, -3);
mesh.position.x = 0;
mesh.position.y = 1.8;
mesh.position.z = -3;
mesh.position = new THREE.Vector3(0, 1.8, -3);
```

在我们的小屋项目里，后墙的位置就是 `(0, 1.8, -3)`：

- `x=0`：在房子中心，左右居中
- `y=1.8`：墙体中心高度。地基顶面在 `y=0.3`，墙高 3.0，所以墙中心 `0.3 + 1.5 = 1.8`
- `z=-3`：在房子的背面（`+Z` 是门前方向）

::: warning 注意坐标系
Three.js 默认使用右手坐标系：`+Y` 向上、`+Z` 向「屏幕外」（也就是相机方向）、`+X` 向右。但「`+Z` 是前还是后」要结合你的场景约定——本项目按 HOUSE_SPEC 约定 `+Z` 是「门前方向」。
:::

`position` 还有一些常用方法：

```js
// 距离另一个点的距离
const dist = mesh.position.distanceTo(camera.position);

// 把位置设置成「从某个点出发，沿着某个方向走一段」
mesh.position.copy(otherMesh.position);
mesh.position.add(new THREE.Vector3(0, 1, 0)); // 在原地基础上向上移动 1 米
```

## 三、rotation：朝哪个方向

`rotation` 是一个 `Euler`（欧拉角），表示绕三个坐标轴的旋转角度，单位是弧度（不是度）。三个分量：

- `x`：绕 X 轴旋转（俯仰）
- `y`：绕 Y 轴旋转（左右转头）
- `z`：绕 Z 轴旋转（左右歪脖子）

```js
import * as THREE from "three";

const mesh = new THREE.Mesh(geometry, material);

// 三种等价的写法
mesh.rotation.set(-Math.PI / 2, 0, 0); // 绕 X 轴旋转 -90°，常用于把 PlaneGeometry 躺平
mesh.rotation.x = -Math.PI / 2;
mesh.rotation.y = 0;
mesh.rotation.z = 0;
```

我们项目里的草地就是一块 `PlaneGeometry`，默认是在 XY 平面（竖着）的，需要绕 X 轴旋转 -90° 才能躺平到 XZ 平面：

```js
const ground = new THREE.Mesh(
  new THREE.PlaneGeometry(40, 40),
  new THREE.MeshStandardMaterial({ color: 0x67c23a })
);
ground.rotation.x = -Math.PI / 2; // 躺平到地面
ground.position.set(0, 0, 0);
```

::: tip 弧度 vs 角度
Three.js 内部统一使用**弧度**。如果习惯了角度，可以用 `THREE.MathUtils.degToRad`：

```js
mesh.rotation.x = THREE.MathUtils.degToRad(-90); // 等价于 -Math.PI / 2
```
:::

### Euler 的「顺序」问题

`Euler` 有一个 `order` 属性，默认是 `'XYZ'`，表示**先绕 X、再绕 Y、最后绕 Z**。这个顺序会影响最终结果——同样的三个角度，顺序不同，朝向可能完全不一样。

如果旋转看起来「不对劲」，多半是顺序问题。Three.js 也提供了 `Quaternion`（四元数）来规避欧拉角的万向锁问题，本阶段我们用 Euler 就够了。

## 四、scale：缩放多少

`scale` 也是一个 `Vector3`，表示在三个轴上的缩放比例。默认是 `(1, 1, 1)`，即不缩放。

```js
import * as THREE from "three";

const mesh = new THREE.Mesh(geometry, material);

// 整体放大 2 倍
mesh.scale.set(2, 2, 2);

// 只在 Y 方向拉高 1.5 倍
mesh.scale.set(1, 1.5, 1);

// 等价写法
mesh.scale.multiplyScalar(2); // 整体放大 2 倍
```

在我们小屋项目里，`scale` 用得不多——因为我们直接在 `BoxGeometry` 里就指定了精确尺寸。但有些场景下用 `scale` 调整大小很方便：例如把一个标准门复制成「大号门」，直接 `mesh.scale.set(1.5, 1.5, 1)` 比重新构造几何体更轻量。

::: warning scale 的副作用
`scale` 会同时缩放位置和大小。如果你给一个父节点设置 `scale = (2, 2, 2)`，那么它下面所有子节点的**位置**也会被乘以 2——子节点离父节点的「视觉距离」会变成两倍。这在搭建场景图时容易踩坑。
:::

## 五、三大变换的执行顺序

当一个 `Object3D` 同时设置了 `position`、`rotation`、`scale` 时，Three.js 按 **`scale → rotation → position`** 的顺序合成变换矩阵。这相当于：

1. 先把对象**缩放**到合适大小（`scale`）
2. 再**旋转**到合适的朝向（`rotation`）
3. 最后**平移**到目标位置（`position`）

这个顺序固定，所以一般不会出现「先平移再旋转导致位置错乱」的问题。如果你确实需要自定义顺序，可以直接操作 `matrix`。

## 六、lookAt：让对象「看着」某个点

除了用 `rotation` 设置朝向，`Object3D` 还提供了 `lookAt` 方法，让对象的 `-Z` 轴指向某个目标点：

```js
import * as THREE from "three";

const camera = new THREE.PerspectiveCamera(50, 1, 0.1, 200);
camera.position.set(12, 8, 12);
camera.lookAt(0, 1, 0); // 相机看向 (0, 1, 0)，即房子中部
```

`lookAt` 在我们的项目里被相机使用——初始位置在 `(12, 8, 12)`，看向房子中部 `(0, 1, 0)`。这样无论房子建多高，相机始终对着它。

::: tip lookAt 的「陷阱」
`lookAt` 让对象的 **`-Z` 轴**指向目标。这意味着如果你想让一个箭头 Mesh「指向」某个点，需要让箭头的几何体本身朝向 `-Z` 方向。常见的「箭头不朝目标」多半是几何体本身朝向不对。
:::

## 七、visible 与 name：两个小但有用的属性

### visible：显隐控制

```js
mesh.visible = false; // 不渲染（但不释放资源）
```

`visible = false` 的对象不参与渲染，但**仍然在场景图里**——切回 `true` 立刻又显示。这比 `remove` + `add` 更轻量，适合频繁切换的场景。

### name：给对象打标签

```js
mesh.name = "door";
scene.add(mesh);

// 后续可以通过名字找到它
const door = scene.getObjectByName("door");
```

我们本阶段给门板命名为 `door`，正是为了 stage-08 开关门动画时通过 `getObjectByName("door")` 拿到它的引用。下一节我们会详细讲 `getObjectByName` 的用法。

## 八、实战：定位一块墙板

把上面学的串起来。我们要在 `(0, 1.8, -3)` 砌一块后墙，尺寸 `8 × 3 × 0.2`，朝向默认（不旋转）：

```js
import * as THREE from "three";

// 创建几何体与材质
const geometry = new THREE.BoxGeometry(8, 3, 0.2);
const material = new THREE.MeshStandardMaterial({ color: 0xe6d5b8 });

// 创建 Mesh
const backWall = new THREE.Mesh(geometry, material);

// 三大变换：position 必填、rotation/scale 用默认
backWall.position.set(0, 1.8, -3);
backWall.rotation.set(0, 0, 0); // 默认朝向，可以省略
backWall.scale.set(1, 1, 1); // 默认大小，可以省略

// 命名
backWall.name = "back-wall";

// 加入场景
scene.add(backWall);
```

仅此而已！所有墙板都是这个套路：构造几何体 → 创建 Mesh → 设置 `position` → 加入场景。下一节我们会把多块墙板组织到一个 `Group` 里，让它们成为一个整体。

## 九、常见踩坑与对策

刚接触 `Object3D` 变换时，有几个高频陷阱。提前知道能少走很多弯路。

### 坑 1：旋转方向「反了」

设置 `mesh.rotation.y = Math.PI / 2` 后，发现对象朝着**反方向**旋转。这是因为 `Euler` 默认是 **右手螺旋**——拇指指向轴的正方向，四指弯曲方向就是正旋转方向。绕 Y 轴正方向旋转，从上往下看是**逆时针**，从下往上看是**顺时针**。

如果方向不对，直接取反：`mesh.rotation.y = -Math.PI / 2`。

### 坑 2：position 看起来「没生效」

```js
const mesh = new THREE.Mesh(geo, mat);
mesh.position.set(0, 1.8, -3);
console.log(mesh.position); // 还是 (0, 0, 0)？
```

这种「没生效」多半是因为 `position` 的赋值方式搞错了：

- `mesh.position.set(x, y, z)` ✓ 直接设置三个分量
- `mesh.position = new THREE.Vector3(x, y, z)` ✓ 替换整个 Vector3
- `mesh.position.x = x` ✓ 单独设置一个分量
- `mesh.position = (x, y, z)` ❌ 这是元组，不是 Vector3，会报错

### 坑 3：旋转后位置「飞了」

```js
mesh.position.set(2, 0, 0);
mesh.rotation.y = Math.PI / 4; // 旋转 45°
// 看起来位置变了？
```

实际上没有变——`position` 是**局部坐标**，旋转只改变朝向不改变位置。你看到的「位置变了」多半是相机视角问题，或者对象**几何中心**不在原点（例如几何体建模时偏移过）。

### 坑 4：scale 把子节点也「拉走」了

```js
const parent = new THREE.Group();
const child = new THREE.Mesh(geo, mat);
child.position.set(2, 0, 0);
parent.add(child);
parent.scale.set(2, 2, 2); // 想让 parent 整体放大 2 倍

// 结果：child 的世界坐标变成了 (4, 0, 0)，因为它离 parent 的距离也被 ×2 了
```

这是 Group 的预期行为——`scale` 同时影响子节点的位置和大小。如果你只想放大「外观」不想改变距离，需要在每个子节点上单独设 `scale`，而不是给父节点设。

::: tip 调试技巧
不确定变换是否正确时，加一个 `AxesHelper` 看坐标系：

```js
const axes = new THREE.AxesHelper(2); // 2 米长的坐标轴
scene.add(axes);
```

红色 X、绿色 Y、蓝色 Z，符合 Three.js 默认配色。配合 `OrbitControls` 旋转视角，能快速验证对象是否在预期位置。
:::

## 十、本节小结：变换的三句话

如果只能记三句话：

1. **位置用 `position.set(x, y, z)`，旋转用 `rotation.set(rx, ry, rz)`（弧度），缩放用 `scale.set(sx, sy, sz)`。**
2. **变换会从父节点传递到子节点——给父节点设变换等于给整棵子树设变换。**
3. **`lookAt(target)` 让对象 `-Z` 轴指向目标，常用于相机和「朝向」类对象。**

记住这三句话，本阶段砌墙时遇到的所有定位问题都能解决。

## 本节总结

| 知识点 | 要点 |
|--------|------|
| `Object3D` | Three.js 所有 3D 对象的基类，定义位置/旋转/缩放/父子关系等共性能力 |
| `position` | `Vector3`，对象在父坐标系下的位置 |
| `rotation` | `Euler`，欧拉角，单位是弧度；默认顺序 `XYZ` |
| `scale` | `Vector3`，三个轴的缩放比例，默认 `(1,1,1)`；会同时缩放子节点的位置 |
| 变换顺序 | `scale → rotation → position`，固定 |
| `lookAt(target)` | 让对象的 `-Z` 轴指向目标点 |
| `visible` | 控制显隐，不释放资源 |
| `name` | 字符串标签，配合 `getObjectByName` 查找 |
