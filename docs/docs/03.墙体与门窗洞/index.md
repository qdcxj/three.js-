# 墙体与门窗洞

经过前两个阶段的准备，我们已经有了一片草地、一块地基和两级入口台阶。但这块地基仍然只是一块「光秃秃的水泥板」——它还不是一栋房子，连个能遮风挡雨的围墙都没有。

本阶段要做的事情很简单也很关键：**把四面墙砌起来，并在墙上留出门洞和窗洞，最后把门板装上去**。完成这一步后，你的 3D 场景就从「工地」迈进了「毛坯房」阶段。

## 建造目标

完成本阶段后，你的场景将包含：

- 草地（stage-01 累积）
- 地基平台 + 入口台阶（stage-02 累积）
- **四面墙**：后墙（整块）、左墙、右墙（各带一个侧窗洞）、前墙（带门洞 + 2 个窗洞）
- **门板**：嵌在前墙门洞里，命名为 `door`，为 stage-08 的开关门动画预留接口

所有墙体共用一份 `MeshStandardMaterial({ color: 0xe6d5b8 })` 暖米色材质，门板使用 `0x8b5a2b` 木色。墙体留洞采用 **多块 Box 拼接** 的方式实现，不使用 CSG（构造实体几何），保持简单可教学。

## 学习目标

完成本章节后，你将能够：

- 理解 `Object3D` 这个「万物基类」的角色，掌握 `position` / `rotation` / `scale` 三大变换属性
- 学会使用 `Group` 把多个 Mesh 组织成层级场景图，理解父节点变换如何影响子节点
- 熟练运用 `add` / `remove` / `traverse` / `getObjectByName` 管理 3D 对象树
- 区分「世界坐标」与「局部坐标」，知道何时该用哪个
- 用「多块 Box 拼接」的工程思维实现墙面留洞，而无需依赖 CSG 库
- 学会通过 `name` 属性 + `getObjectByName` 给节点打「标签」，为后续动画预留可访问的引用

## 一个核心问题：墙上怎么开洞？

在 CSS 里，墙上挖个洞可以用 `clip-path` 或者绝对定位一个透明方块；在 Three.js 里，最直观的「挖洞」方式是 **CSG（Constructive Solid Geometry，构造实体几何）**——把一个长方体减去另一个长方体得到带洞的形状。

但 CSG 库有几个问题：

1. 引入额外依赖（`three-bvh-csg` 等），计算量大
2. 生成的几何体顶点较多，难以直观调试
3. 对初学者不友好，难以理解「墙是怎么变成这个形状的」

所以我们采用更朴素、更易教学的方案：**把一面带洞的墙拆成多块实心 Box，拼出洞口**。这就像现实里砌砖一样——门洞两侧各砌一段墙，门洞上方再砌一段过梁。本章节会详细推演每一块的尺寸和位置。
