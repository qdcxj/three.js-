# 烟囱烟雾

上一节我们在烟囱顶摆好了 200 个静止的灰白圆点。但真正的炊烟是流动的——它会上升、扩散、变淡，最后消散在空中，同时烟囱口又源源不断地冒出新的烟。本节我们就来为粒子加上"生命"：用平行数组管理每颗粒子的速度、年龄、寿命，在渲染循环里更新位置，实现上升 + 扩散 + 衰减 + 循环重生的完整烟雾算法。

## 烟雾的物理直觉

在写代码之前，先观察真实烟雾的行为：

- **上升**：烟气比空气轻，受浮力作用持续上升，速度先快后慢
- **扩散**：上升过程中受空气湍流扰动，水平方向逐渐散开
- **衰减**：烟颗粒越升越高、越来越稀薄，肉眼看上去越来越淡
- **重生**：烟囱口的火不断产生新烟，整体形成稳定的"烟柱"

把这四点翻译成代码，就是四个数组运算：位置加上速度、速度加上扰动、亮度随年龄下降、超寿命则重置。

## 平行数组：管理每粒子状态

`PointsMaterial` 默认所有粒子共用同一份大小、颜色、透明度。要让每个粒子有独立的速度和年龄，我们用**平行数组**（parallel arrays）在 CPU 侧维护这些状态——它们不进 GPU，只是 JS 普通数组，每帧读取并更新。

::: tip 为什么不用 ShaderMaterial
要让每粒子独立透明度，更"硬核"的做法是自定义 `ShaderMaterial`，把年龄作为 attribute 传进着色器，在片元阶段算 alpha。但这超出了"PointsMaterial 全知识"的教学范围，且本阶段的亮度衰减方案（vertexColors）已能达到很好的视觉效果。我们把着色器方案留作进阶练习。
:::

下面是烟雾粒子的全部状态数组：

```js
const SMOKE_COUNT = 200;
const SMOKE_ORIGIN = new THREE.Vector3(2, 5.3, -1.5); // 烟囱顶中心
const SMOKE_MAX_Y = 8.5; // 升到该高度后重生

// —— 进 GPU 的属性（每帧上传）——
let smokePositions = new Float32Array(SMOKE_COUNT * 3); // position 属性
let smokeColors    = new Float32Array(SMOKE_COUNT * 3); // color 属性（亮度衰减）

// —— CPU 维护的状态（不上 GPU）——
let smokeVel  = new Float32Array(SMOKE_COUNT * 3); // 速度 (vx, vy, vz)
let smokeAge  = new Float32Array(SMOKE_COUNT);     // 已存活时间
let smokeLife = new Float32Array(SMOKE_COUNT);     // 寿命
```

### 初始化每个粒子

初始化时，给每个粒子一个起点、一个初始上升速度、一个随机寿命，并把年龄随机化（让粒子不同步，避免整团一起重生）：

```js
for (let i = 0; i < SMOKE_COUNT; i++) {
  const i3 = i * 3;
  // 起点：烟囱顶附近 ±0.3 的方块内随机
  smokePositions[i3]     = SMOKE_ORIGIN.x + (Math.random() - 0.5) * 0.3;
  smokePositions[i3 + 1] = SMOKE_ORIGIN.y + Math.random() * 0.2;
  smokePositions[i3 + 2] = SMOKE_ORIGIN.z + (Math.random() - 0.5) * 0.3;
  // 初始速度：主上升 0.4~0.8 m/s + 微小水平随机
  smokeVel[i3]     = (Math.random() - 0.5) * 0.1;
  smokeVel[i3 + 1] = 0.4 + Math.random() * 0.4;
  smokeVel[i3 + 2] = (Math.random() - 0.5) * 0.1;
  // 寿命 3~6 秒，年龄随机初始（让粒子错开重生节奏）
  smokeLife[i] = 3 + Math.random() * 3;
  smokeAge[i]  = Math.random() * smokeLife[i];
  // 颜色初始白色（与 material.color 0xd3d3d3 相乘得灰白烟）
  smokeColors[i3] = 1;
  smokeColors[i3 + 1] = 1;
  smokeColors[i3 + 2] = 1;
}
```

::: tip 随机化年龄的意义
如果所有粒子年龄都从 0 开始，它们会同时长大、同时到寿、同时重生，烟柱看起来"一节一节"的，极不自然。把初始年龄随机分散到 `[0, life]` 区间，烟柱立刻变得连续均匀。
:::

## 启用 vertexColors 实现亮度衰减

`PointsMaterial` 的 `vertexColors` 选项允许为每个粒子指定独立颜色，这个颜色会与材质的 `color` 相乘。我们利用这个机制实现"亮度衰减"：随年龄增长，把 vertex color 从白色 `(1,1,1)` 线性衰减到暗灰 `(0.2,0.2,0.2)`，乘上材质色 `0xd3d3d3` 后，粒子就从灰白慢慢变暗变淡，模拟烟雾消散。

```js
const mat = new THREE.PointsMaterial({
  size: 0.3,
  map: smokeTexture,        // 上一节的圆形烟雾贴图
  transparent: true,
  opacity: 0.6,
  depthWrite: false,
  color: 0xd3d3d3,          // 灰白烟色（与 vertex color 相乘）
  vertexColors: true,       // 启用每粒子颜色（用于亮度衰减）
  sizeAttenuation: true,
  blending: THREE.NormalBlending,
});

const geo = new THREE.BufferGeometry();
geo.setAttribute("position", new THREE.BufferAttribute(smokePositions, 3));
geo.setAttribute("color",    new THREE.BufferAttribute(smokeColors, 3));
```

## 上升 + 扩散 + 衰减算法

核心更新函数 `updateSmoke(dt)` 每帧调用一次，遍历所有粒子做四件事：

```js
/**
 * 每帧更新烟雾粒子
 * @param {number} dt 帧间隔（秒），由 Clock.getDelta() 提供
 */
const updateSmoke = (dt) => {
  if (!smokePoints) return;
  for (let i = 0; i < SMOKE_COUNT; i++) {
    const i3 = i * 3;
    // 1. 年龄累加
    smokeAge[i] += dt;
    const t = smokeAge[i] / smokeLife[i]; // 归一化进度 [0,1]

    // 2. 位置更新：上升 + 水平扩散
    smokePositions[i3]     += smokeVel[i3] * dt;
    smokePositions[i3 + 1] += smokeVel[i3 + 1] * dt;
    smokePositions[i3 + 2] += smokeVel[i3 + 2] * dt;

    // 3. 速度演化：水平方向加随机扰动（模拟空气湍流，烟雾越升越散）
    smokeVel[i3]     += (Math.random() - 0.5) * 0.15 * dt;
    smokeVel[i3 + 2] += (Math.random() - 0.5) * 0.15 * dt;
    // 上升速度逐渐衰减（烟雾到高处减速）
    smokeVel[i3 + 1] *= 1 - 0.15 * dt;

    // 4. 亮度衰减：1 → 0.2，随 t 线性下降
    const brightness = 1 - t * 0.8;
    smokeColors[i3]     = brightness;
    smokeColors[i3 + 1] = brightness;
    smokeColors[i3 + 2] = brightness;

    // 5. 重生条件：超寿命 或 升过最大高度
    if (smokeAge[i] >= smokeLife[i] || smokePositions[i3 + 1] > SMOKE_MAX_Y) {
      smokePositions[i3]     = SMOKE_ORIGIN.x + (Math.random() - 0.5) * 0.3;
      smokePositions[i3 + 1] = SMOKE_ORIGIN.y + Math.random() * 0.2;
      smokePositions[i3 + 2] = SMOKE_ORIGIN.z + (Math.random() - 0.5) * 0.3;
      smokeVel[i3]     = (Math.random() - 0.5) * 0.1;
      smokeVel[i3 + 1] = 0.4 + Math.random() * 0.4;
      smokeVel[i3 + 2] = (Math.random() - 0.5) * 0.1;
      smokeLife[i] = 3 + Math.random() * 3;
      smokeAge[i]  = 0;
      smokeColors[i3] = 1;
      smokeColors[i3 + 1] = 1;
      smokeColors[i3 + 2] = 1;
    }
  }
  // 标记属性需要重新上传 GPU
  smokePoints.geometry.attributes.position.needsUpdate = true;
  smokePoints.geometry.attributes.color.needsUpdate = true;
};
```

### 算法逐行拆解

**上升**：`smokePositions[i3+1] += smokeVel[i3+1] * dt`。这里用 `dt` 乘速度，是 stage-08 学过的帧率无关动画——60fps 与 30fps 下每秒上升的高度完全一致。

**扩散**：`smokeVel[i3] += (Math.random() - 0.5) * 0.15 * dt`。每帧给水平速度加一个微小随机扰动，扰动会累积，于是粒子越升越偏，整团烟雾呈"漏斗形"散开。

**衰减**：`smokeVel[i3+1] *= 1 - 0.15 * dt`。上升速度按指数衰减，模拟高空气流阻力让烟雾减速。

**亮度衰减**：`brightness = 1 - t * 0.8`。`t` 是归一化年龄（0=刚生，1=将死），亮度从 1 线性降到 0.2，配合 vertexColors 让粒子变淡。

::: tip 指数衰减的数学
`v *= 1 - k * dt` 是一种简单的指数衰减，等价于 `v = v0 * e^(-k*t)` 的离散近似。`k=0.15` 表示每秒衰减约 15%。这种写法在游戏开发中极为常见，因为它天然帧率无关。
:::

## 循环重生

烟雾不能"用完就没"，烟囱会持续冒烟。重生逻辑很简单：当粒子年龄超过寿命，或飞到最大高度时，把它"传送"回烟囱顶，重新分配随机速度与寿命，于是它又变成一颗新烟。200 个粒子这样循环，整团烟雾就源源不断。

```js
if (smokeAge[i] >= smokeLife[i] || smokePositions[i3 + 1] > SMOKE_MAX_Y) {
  // 重置到烟囱顶附近，新随机参数
  smokePositions[i3]     = SMOKE_ORIGIN.x + (Math.random() - 0.5) * 0.3;
  smokePositions[i3 + 1] = SMOKE_ORIGIN.y + Math.random() * 0.2;
  smokePositions[i3 + 2] = SMOKE_ORIGIN.z + (Math.random() - 0.5) * 0.3;
  smokeVel[i3]     = (Math.random() - 0.5) * 0.1;
  smokeVel[i3 + 1] = 0.4 + Math.random() * 0.4;
  smokeVel[i3 + 2] = (Math.random() - 0.5) * 0.1;
  smokeLife[i] = 3 + Math.random() * 3;
  smokeAge[i]  = 0;
}
```

::: warning 重生与初始要一致
重置时分配的随机参数范围必须与初始化时**完全一致**，否则重生粒子会与初始粒子表现不同，烟柱会出现"断层"。建议把随机参数封装成一个 `resetSmokeParticle(i)` 函数，初始化和重生都调用它，杜绝不一致。
:::

## needsUpdate：通知 GPU 重新上传

CPU 改了 `Float32Array`，GPU 缓冲区里的数据并不会自动更新。必须把对应属性的 `needsUpdate` 设为 `true`，Three.js 才会在本帧把新数据上传到 GPU：

```js
smokePoints.geometry.attributes.position.needsUpdate = true;
smokePoints.geometry.attributes.color.needsUpdate = true;
```

::: warning 别忘了这一步
这是粒子动画最常见的"踩坑点"——代码逻辑全对，但粒子就是不动。九成原因是忘了设 `needsUpdate`。改了数组就要标记上传，这是 BufferGeometry 的工作机制。
:::

## 烟雾贴图回顾

完整起见，这里再贴一次烟雾贴图的生成函数。径向渐变是烟雾柔和感的核心：

```js
const makeSmokeTexture = () => {
  const size = 64;
  const c = document.createElement("canvas");
  c.width = size;
  c.height = size;
  const ctx = c.getContext("2d");
  const grad = ctx.createRadialGradient(
    size / 2, size / 2, 0,
    size / 2, size / 2, size / 2
  );
  grad.addColorStop(0.0, "rgba(255,255,255,1)");
  grad.addColorStop(0.4, "rgba(255,255,255,0.6)");
  grad.addColorStop(1.0, "rgba(255,255,255,0)");
  ctx.fillStyle = grad;
  ctx.fillRect(0, 0, size, size);
  const tex = new THREE.CanvasTexture(c);
  tex.needsUpdate = true;
  return tex;
};
```

调色上，烟雾材质色 `0xd3d3d3` 是 Element Plus 信息灰的浅色变体，与昼/夜天空都能形成适度对比，既不会黑得突兀，也不会白得刺眼。

## 本节总结

本节我们让烟囱真正"冒"起了烟：

- 用**平行数组**（position / color / vel / age / life）管理每粒子独立状态，CPU 维护、不进 GPU
- **上升**用 `position += vel * dt` 的帧率无关积分
- **扩散**靠每帧给水平速度加随机扰动并累积
- **衰减**用 vertexColors 把亮度从 1 线性降到 0.2，配合材质色实现变淡
- **重生**在超寿命或超高度时把粒子重置回烟囱顶，形成持续烟柱
- 改完数组务必设 `needsUpdate = true` 通知 GPU 上传
