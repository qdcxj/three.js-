# 落叶粒子

烟囱的炊烟已经袅袅升起，但小屋周围仍是空荡荡的。秋日的乡村，最动人的画面莫过于橙红的落叶从枝头飘洒而下，在风中打着旋儿缓缓落地。本节我们来做第二套粒子系统——100 片秋叶，从高空随机下落，伴随正弦飘摆，触地后换位重生。它与烟雾共用同一套 Points 框架，但运动模型完全不同，正好巩固粒子系统的通用思路。

## 落叶与烟雾的差异

虽然都是粒子，落叶和烟雾在运动特征上有本质区别。理解这些区别，才能选对算法：

| 特征 | 烟雾 | 落叶 |
|------|------|------|
| 主运动方向 | 上升（+Y） | 下落（−Y） |
| 水平运动 | 随机扰动累积扩散 | 围绕基准点正弦摆动 |
| 生命周期 | 寿命到期重生 | 触地（y<0）重生 |
| 颜色变化 | 亮度衰减变淡 | 固定秋叶橙红 |
| 贴图 | 圆形渐变 | 叶子形状 |

烟雾的扩散是"随机游走"——每帧给速度加扰动，路径不可预测。落叶的飘摆则是"周期运动"——叶子围绕一个基准位置左右摇摆，路径是规整的正弦曲线。这两种模型覆盖了粒子动画最常见的两类需求。

## 落叶的状态数组

落叶不需要亮度衰减，所以没有 color 数组，但多了飘摆参数：

```js
const LEAF_COUNT = 100;
const LEAF_COLOR = 0xe6a23c; // Element Plus 警告色（秋叶橙红）

let leafPositions = new Float32Array(LEAF_COUNT * 3); // 进 GPU 的 position
// CPU 维护的状态
let leafVy       = new Float32Array(LEAF_COUNT); // 下落速度
let leafSwayAmp  = new Float32Array(LEAF_COUNT); // 飘摆振幅（米）
let leafSwayFreq = new Float32Array(LEAF_COUNT); // 飘摆频率（rad/s）
let leafPhase    = new Float32Array(LEAF_COUNT); // 飘摆相位（让叶子不同步）
let leafBaseX    = new Float32Array(LEAF_COUNT); // 水平基准 X（飘摆围绕它）
let leafBaseZ    = new Float32Array(LEAF_COUNT); // 水平基准 Z
let leafFallTime = new Float32Array(LEAF_COUNT); // 已下落时间
```

### 初始化每片叶子

叶子从房子上方一片区域随机出现，给每片不同的下落速度和飘摆参数：

```js
for (let i = 0; i < LEAF_COUNT; i++) {
  const i3 = i * 3;
  // 水平基准位置：房子周围 ±12 范围
  leafBaseX[i] = (Math.random() - 0.5) * 24;
  leafBaseZ[i] = (Math.random() - 0.5) * 24;
  // 初始高度：5~15 米高空
  leafPositions[i3]     = leafBaseX[i];
  leafPositions[i3 + 1] = 5 + Math.random() * 10;
  leafPositions[i3 + 2] = leafBaseZ[i];
  // 下落速度：0.4~0.9 m/s
  leafVy[i] = 0.4 + Math.random() * 0.5;
  // 飘摆参数：振幅 0.5~1.5 米，频率 0.5~1.5 rad/s，相位 0~2π
  leafSwayAmp[i]  = 0.5 + Math.random() * 1.0;
  leafSwayFreq[i] = 0.5 + Math.random() * 1.0;
  leafPhase[i]    = Math.random() * Math.PI * 2;
  leafFallTime[i] = Math.random() * 5;
}
```

::: tip 相位随机化
`leafPhase` 让每片叶子的飘摆错开起始角度。如果所有叶子相位相同，它们会同步左右摆动，看起来像集体跳舞，极其违和。随机相位让飘摆各不相同，画面才自然。
:::

## 叶子贴图：Canvas 画一片叶子

烟雾用的是圆形渐变，落叶则需要一片真正的"叶子"形状。我们用 Canvas 的椭圆 API 画一片斜放的椭圆叶身，再画一条中脉和叶柄。贴图底色用白色，实际显示色由 `material.color` 叠加决定——这样同一张贴图可以复用为不同颜色的叶子。

```js
/**
 * 生成叶子贴图：在透明背景上画一片简化的椭圆叶子 + 中脉
 * @returns {THREE.CanvasTexture}
 */
const makeLeafTexture = () => {
  const size = 64;
  const c = document.createElement("canvas");
  c.width = size;
  c.height = size;
  const ctx = c.getContext("2d");
  ctx.clearRect(0, 0, size, size);
  // 移到中心并斜放，更像落叶
  ctx.translate(size / 2, size / 2);
  ctx.rotate(Math.PI / 4);
  // 叶身：白色椭圆（实际色由 material.color 叠加）
  ctx.fillStyle = "rgba(255,255,255,1)";
  ctx.beginPath();
  ctx.ellipse(0, 0, 22, 11, 0, 0, Math.PI * 2);
  ctx.fill();
  // 中脉：深色细线
  ctx.strokeStyle = "rgba(120,60,20,0.6)";
  ctx.lineWidth = 1.5;
  ctx.beginPath();
  ctx.moveTo(-22, 0);
  ctx.lineTo(22, 0);
  ctx.stroke();
  // 叶柄
  ctx.strokeStyle = "rgba(90,45,15,0.8)";
  ctx.lineWidth = 2;
  ctx.beginPath();
  ctx.moveTo(22, 0);
  ctx.lineTo(28, 0);
  ctx.stroke();
  const tex = new THREE.CanvasTexture(c);
  tex.needsUpdate = true;
  return tex;
};
```

::: tip 为什么底色画白色
`PointsMaterial` 的 `color` 会与贴图像素相乘。贴图白色 `(255,255,255)` 乘上材质色 `0xe6a23c` 就得到橙红叶子；如果你想做黄叶、红叶，只需换 `material.color`，贴图无需重画。这是程序化纹理的复用技巧。
:::

## 落叶材质

落叶材质与烟雾类似，但颜色固定为秋叶橙红 `#e6a23c`（Element Plus 警告色），不开启 vertexColors，opacity 提高到 0.95 让叶子更实在：

```js
const mat = new THREE.PointsMaterial({
  size: 0.25,                // 叶子尺寸
  map: leafTexture,
  transparent: true,
  opacity: 0.95,
  depthWrite: false,
  color: LEAF_COLOR,         // 秋叶橙红
  sizeAttenuation: true,
  blending: THREE.NormalBlending,
});

const geo = new THREE.BufferGeometry();
geo.setAttribute("position", new THREE.BufferAttribute(leafPositions, 3));

leafPoints = new THREE.Points(geo, mat);
leafPoints.frustumCulled = false;
scene.add(leafPoints);
```

## 下落 + sin 飘摆算法

核心更新函数 `updateLeaves(dt, elapsed)` 每帧调用。`elapsed` 是 `Clock.elapsedTime`，即从启动以来的累计时间，用作飘摆的时间轴：

```js
/**
 * 每帧更新落叶粒子
 * @param {number} dt 帧间隔（秒）
 * @param {number} elapsed 累计时间（秒），用于飘摆相位
 */
const updateLeaves = (dt, elapsed) => {
  if (!leafPoints) return;
  for (let i = 0; i < LEAF_COUNT; i++) {
    const i3 = i * 3;
    // 1. 下落：Y 持续下降
    leafPositions[i3 + 1] -= leafVy[i] * dt;
    // 2. 飘摆：X 围绕基准做正弦，Z 围绕基准做余弦（相位差让运动更自然）
    leafPositions[i3] =
      leafBaseX[i] +
      Math.sin(elapsed * leafSwayFreq[i] + leafPhase[i]) * leafSwayAmp[i];
    leafPositions[i3 + 2] =
      leafBaseZ[i] +
      Math.cos(elapsed * leafSwayFreq[i] + leafPhase[i]) * leafSwayAmp[i] * 0.5;
    leafFallTime[i] += dt;

    // 3. 触地重生：换一个新的水平基准位置 + 高空起点
    if (leafPositions[i3 + 1] < 0.1) {
      leafBaseX[i] = (Math.random() - 0.5) * 24;
      leafBaseZ[i] = (Math.random() - 0.5) * 24;
      leafPositions[i3]     = leafBaseX[i];
      leafPositions[i3 + 1] = 12 + Math.random() * 5;
      leafPositions[i3 + 2] = leafBaseZ[i];
      leafVy[i]       = 0.4 + Math.random() * 0.5;
      leafSwayAmp[i]  = 0.5 + Math.random() * 1.0;
      leafSwayFreq[i] = 0.5 + Math.random() * 1.0;
      leafPhase[i]    = Math.random() * Math.PI * 2;
      leafFallTime[i] = 0;
    }
  }
  leafPoints.geometry.attributes.position.needsUpdate = true;
};
```

### 飘摆的数学

`Math.sin(elapsed * freq + phase) * amp` 是经典的正弦波公式：

- `elapsed * freq`：把累计时间乘以频率，得到随时间增长的弧度
- `+ phase`：加上相位偏移，让每片叶子从波形的不同位置开始
- `* amp`：乘以振幅，控制摆动幅度

X 用 `sin`、Z 用 `cos`，两者相位差 90°，于是叶子在水平面上走出一个**椭圆轨迹**——这正是真实落叶在风中打旋的样子。

::: tip 为什么 Z 振幅乘 0.5
让 Z 方向的飘摆幅度只有 X 的一半，叶子的运动轨迹是扁椭圆而非正圆，看起来更像被侧风吹动，而不是原地打转。这种"不对称"细节是提升真实感的关键。
:::

## 触地重生

落叶没有"寿命"概念，它的重生条件是触地（`y < 0.1`）。重生时换一个新的水平基准位置，让叶子落向不同地方，避免总在同一点堆积。同时重新分配下落速度和飘摆参数，让每片"新叶子"表现各异。

```js
if (leafPositions[i3 + 1] < 0.1) {
  leafBaseX[i] = (Math.random() - 0.5) * 24;
  leafBaseZ[i] = (Math.random() - 0.5) * 24;
  leafPositions[i3]     = leafBaseX[i];
  leafPositions[i3 + 1] = 12 + Math.random() * 5; // 重新升回高空
  leafPositions[i3 + 2] = leafBaseZ[i];
  // 重新随机运动参数
  leafVy[i]       = 0.4 + Math.random() * 0.5;
  leafSwayAmp[i]  = 0.5 + Math.random() * 1.0;
  leafSwayFreq[i] = 0.5 + Math.random() * 1.0;
  leafPhase[i]    = Math.random() * Math.PI * 2;
  leafFallTime[i] = 0;
}
```

::: warning 别让叶子"瞬移"被看见
重生时叶子从地面直接跳回 12 米高空，如果相机正盯着这片叶子，会看到突兀的瞬移。实际项目中可以加一个"淡出再淡入"的过渡，或者让重生发生在相机视野外。本教程为简洁起见直接跳回，100 片叶子的密度下基本察觉不到。
:::

## 季节氛围的整体搭配

落叶粒子不是孤立存在的，它与场景的其他元素共同构成"秋日乡村"的氛围：

- **落叶橙红 `#e6a23c`** 与草地成功绿 `#67c23a` 形成秋色对比
- **烟囱灰白烟**与**落叶橙红**在画面上一冷一暖，互相呼应
- 昼夜循环下，夜晚的落叶在月光中变成深色剪影，黄昏时则被染成金红
- Bloom 后期让被灯光照亮的落叶泛出柔和光晕

```js
// 在渲染循环中，烟雾与落叶并行更新
const animate = () => {
  animationId = requestAnimationFrame(animate);
  const dt = clock.getDelta();
  const elapsed = clock.elapsedTime;

  controls.update();
  updateDoor(dt);
  updateLamp(dt);
  updateDayNight(dt);
  updateSmoke(dt);          // 烟雾粒子
  updateLeaves(dt, elapsed); // 落叶粒子（用 elapsed 驱动飘摆）

  composer.render(); // Bloom 后期输出
};
```

::: tip 雾效增强氛围
场景里加一点 `THREE.Fog`，让远处的落叶在雾中变淡消失，能极大增强纵深感。本阶段在 `initScene` 中设置了 `scene.fog = new THREE.Fog(0x87ceeb, 25, 70)`，且雾色跟随昼夜循环变化，落叶在远处自然融入天空。
:::

## 资源释放

落叶的资源释放与烟雾同理，覆盖 texture、Points 对象、geometry、material：

```js
// 释放落叶贴图
if (leafTexture) {
  leafTexture.dispose();
  leafTexture = null;
}
// 落叶 Points 从场景移除
if (leafPoints) {
  if (leafPoints.parent) leafPoints.parent.remove(leafPoints);
  leafPoints = null;
}
// geometry / material 走 disposables 统一释放
```

至此，stage-12 的全部粒子资源都能在组件卸载时干净释放，长时间运行也不会泄漏显存。

## 本节总结

本节我们完成了第二套粒子系统，给小屋补上了秋日氛围：

- 落叶与烟雾共用 Points 框架，但运动模型不同：**下落 + 正弦飘摆**
- 用 `Math.sin(elapsed * freq + phase) * amp` 实现周期性飘摆，X 用 sin、Z 用 cos 形成椭圆轨迹
- **相位随机化**让每片叶子飘摆不同步，避免集体跳舞的违和感
- **触地重生**（`y < 0.1`）代替寿命到期，换新基准位置避免堆积
- 叶子贴图底色画白色，靠 `material.color` 叠加成橙红，便于复用为其他颜色
- 落叶橙红 `#e6a23c` 与草地绿、烟雾灰白共同构成秋日色彩，配合 Bloom 与雾效形成完整氛围

到这里，stage-12 圆满完成——一栋冒着炊烟、落叶纷飞的欧式乡村小屋已经活灵活现。但 200 + 100 个粒子加上 Bloom 后期、阴影、着色器，对帧率也是考验。下一阶段我们将进入性能优化，用 Stats 监控、LOD 分级、InstancedMesh 等技术让小屋在任何设备上都能流畅运行。
