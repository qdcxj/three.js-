# 烟囱冒烟

到上一阶段为止，我们的欧式乡村小屋已经具备了完整的建筑结构、贴图、灯光、阴影、家具、着色器与 Bloom 后期。但它仍然是"静态"的——烟囱矗立却不出烟，庭院空荡没有一丝风。本阶段我们就来给小屋注入**生命的气息**：让烟囱口缓缓升起一缕灰白色的烟雾，让秋日的橙红落叶从空中飘洒而下。

要实现这些效果，传统的 `Mesh`（网格）方案完全行不通——你不可能为 200 颗烟雾颗粒、100 片落叶分别创建几何体，那会瞬间拖垮 GPU。Three.js 为这类"大量离散个体"场景提供了专门的方案：**粒子系统（Particle System）**。

## 建造目标

本阶段在 stage-11 的完整小屋基础上，新增两套粒子系统：

- **烟囱烟雾**：200 个粒子从烟囱顶 `(2, 5.3, -1.5)` 升起，向上飘升同时水平扩散，亮度逐渐衰减，到顶后循环重生
- **秋日落叶**：100 个橙红色叶子粒子从高空随机下落，伴随正弦飘摆，触地后换位重生

最终效果是一栋**冒着炊烟、落叶纷飞**的活生生的小屋。

## 学习目标

完成本章节后，你将能够：

- 理解 `THREE.Points`、`BufferGeometry`、`PointsMaterial` 三者协作渲染粒子的原理
- 用 `Float32Array` 写入 `position` 属性，一次性创建上百上千个粒子
- 用 Canvas API 程序化绘制圆形烟雾贴图与叶子贴图，告别"方点"外观
- 在渲染循环中更新粒子位置数组，实现上升、扩散、衰减、飘摆、循环重生等动画
- 为粒子系统编写完整的 `dispose` 资源释放（geometry / material / texture）

::: tip 粒子系统的本质
粒子系统用**一个几何体 + 一个材质**渲染**大量离散点**。每个粒子可以有自己的位置、颜色，但它们共用同一份材质，因此 GPU 只需一次绘制调用（DrawCall）就能渲染全部粒子，性能远超创建等量 Mesh。
:::
