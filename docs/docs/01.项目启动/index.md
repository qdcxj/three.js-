# 项目启动

欢迎来到「建造一栋欧式乡村小屋」实战教程的**第 01 阶段：项目启动**。本阶段是整个 14 阶段建造项目的起点——正如盖房子之前要先平整场地、通水通电一样，我们在写 3D 房子之前，也要先把 Three.js 工程搭起来、把施工场地清理好、把草地铺平，让后续阶段的所有构件都能稳稳地落在这块地基上。

本阶段只做两件事：**搭建施工场地**（Vite + Vue 3 + Three.js 工程）和**铺设草地地皮**（一块 40m × 40m 的绿色平面），并接入 OrbitControls 让你自由浏览施工现场。本阶段**不建造**任何房屋构件——地基、墙体、屋顶都要等到后面的阶段。

## 本阶段建造目标

| 建造内容 | 说明 |
|----------|------|
| 施工场地 | Vite + Vue 3 + Three.js 工程脚手架，Scene / Camera / Renderer 三件套 |
| 草地地皮 | 40m × 40m 平面，颜色 `#67c23a`（Element Plus 成功绿），位于地面 `y=0` |
| 辅助工具 | AxesHelper（坐标轴）+ GridHelper（网格），便于观察尺寸和方位 |
| 轨道控制 | OrbitControls 鼠标交互，旋转 / 平移 / 缩放浏览场地 |

## 学习目标

完成本阶段后，你将能够：

- 使用 Vite 从零搭建一个 Vue 3 + Three.js 工程，并理解项目结构与模块化导入方式
- 准确说明 Scene、Camera、Renderer 三件套各自的职责，并写出最小可运行的渲染循环
- 理解 Three.js 右手坐标系（+Y 向上、+Z 向前、+X 向右），会用 AxesHelper / GridHelper 调试方位
- 用 PlaneGeometry 铺设一块水平地面，并接入 OrbitControls 实现鼠标交互浏览

本阶段配套**完整可运行**的源码快照，位于：

```
lession/stage-01-项目启动/
├── index.html
├── package.json
├── vite.config.js
├── README.md
└── src/
    ├── main.js
    ├── App.vue
    └── components/
        └── HouseScene.vue   ← 核心场景组件，本阶段所有 3D 代码都在这里
```

::: tip 源码使用方式
进入 `lession/stage-01-项目启动/` 目录，执行 `pnpm install && pnpm dev`，即可在浏览器中看到本阶段的最终效果——一片绿色草地 + 坐标轴 + 网格，可用鼠标自由旋转浏览。本教程文档中的所有代码片段都与该快照保持一致，可直接对照阅读。
:::

::: warning 阶段递进说明
本教程共 14 个阶段，每个阶段都是**完整独立**的 Vite 项目，其 `HouseScene.vue` 包含从 stage-01 到当前阶段的所有构件。也就是说，stage-01 只有草地，stage-02 在草地上加地基，stage-03 再加墙体……以此类推，到 stage-14 就是完整的欧式乡村小屋。你可以随时切到任意阶段的源码快照查看进度。
:::
