# 铺设草地地皮

到这里，我们有了三件套、有了坐标系、有了辅助工具，但施工场地还是光秃秃的网格——没有「地」的感觉。本节我们就用 `PlaneGeometry` 在地面上铺一块 40m × 40m 的草地（颜色 `#67c23a`，Element Plus 成功绿），让这块场地真正变成一片可以盖房子的「草坪」。同时接入 `OrbitControls` 轨道控制器，让你用鼠标自由旋转、平移、缩放浏览整个施工现场。这是本阶段的最后一节，完成后你就拥有了一个可交互的施工场地。

## 1. PlaneGeometry：平面几何体

`PlaneGeometry` 是 Three.js 内置的矩形平面几何体，它生成一个位于 **XY 平面**（垂直于屏幕）的矩形，默认朝向 +Z 方向。

```js
import * as THREE from "three";

// PlaneGeometry(width, height)
//   width:  平面宽度（沿 X 轴）
//   height: 平面高度（沿 Y 轴）
const grassGeometry = new THREE.PlaneGeometry(40, 40);
```

::: warning PlaneGeometry 默认是竖直的
`PlaneGeometry` 生成的平面**默认在 XY 平面上**，也就是竖直的（像一面墙）。要把它变成「地面」，必须**绕 X 轴旋转 -90°**，让它躺平到 XZ 平面上。这是初学者最容易踩的坑——不加旋转，你只会看到一条细线（因为平面正对相机时几乎没有厚度）。
:::

### 1.1 旋转 -90° 让平面躺平

```js
// 绕 X 轴旋转 -90°（-π/2），让平面从竖直变成水平
grassMesh.rotation.x = -Math.PI / 2;
```

为什么是 -90° 而不是 +90°？因为 `PlaneGeometry` 默认的法线（朝向）是 +Z 方向。绕 X 轴旋转 -90° 后，法线指向 +Y（向上），平面就平铺在 XZ 平面（地面）上了。如果旋转 +90°，法线会指向 -Y（向下），从上往下看就是背面，材质可能显示异常（取决于 `side` 设置）。

### 1.2 设置草地位置

```js
// 草地表面正好在 y=0
grassMesh.position.y = 0;
```

按照 `HOUSE_SPEC`，地面 `y = 0`，所以草地中心放在 `(0, 0, 0)`。由于 `position.y = 0` 是默认值，这行其实可以省略，但写出来更清晰。

## 2. MeshStandardMaterial：PBR 标准材质

材质决定了几何体的「外观」——颜色、质感、反光等。本教程统一使用 `MeshStandardMaterial`，它是 Three.js 的 **PBR（Physically Based Rendering，基于物理的渲染）** 标准材质，参数符合真实光学规律，渲染效果逼真。

```js
// MeshStandardMaterial({ color })
//   color: 材质颜色，传入十六进制色值
// 按 HOUSE_SPEC，草地用 #67c23a（Element Plus 成功绿）
const grassMaterial = new THREE.MeshStandardMaterial({ color: 0x67c23a });
```

::: tip Element Plus 配色
本项目所有构件颜色都遵循 Element Plus 设计规范：

| 用途 | 颜色 | 十六进制 | 用在本项目的哪里 |
|------|------|----------|------------------|
| 主色 | 蓝 | `#409eff` | stage-05 窗框 |
| 成功 | 绿 | `#67c23a` | stage-01 草地 |
| 警告 | 橙 | `#e6a23c` | （暂未使用） |
| 危险 | 红 | `#f56c6c` | （暂未使用） |
| 信息 | 灰 | `#909399` | stage-02 地基 / stage-04 烟囱 |

统一配色让最终的房屋视觉协调，也方便记忆。
:::

### 2.1 为什么不用 MeshBasicMaterial

`MeshBasicMaterial` 是最简单的材质，**不受光照影响**，永远是纯色。用它画草地虽然简单，但无法体现明暗变化，整个草地会是一块死板的纯绿色块。

`MeshStandardMaterial` 配合平行光，能让草地在阳光照射方向更亮、背光方向稍暗，呈现自然的明暗过渡。虽然 stage-01 只铺草地，但用 PBR 材质能为后续阶段的光照效果做好铺垫。

## 3. 组装成 Mesh

几何体（Geometry）+ 材质（Material）= 网格（Mesh）。Mesh 是 Three.js 中最常用的 3D 对象类型，它把「形状」和「外观」组合在一起，可以直接 `add` 到场景里渲染：

```js
// 创建草地网格
const grassMesh = new THREE.Mesh(grassGeometry, grassMaterial);
// 旋转 -90° 让平面躺平到地面
grassMesh.rotation.x = -Math.PI / 2;
// 草地表面在 y=0
grassMesh.position.y = 0;
// 加入场景
scene.add(grassMesh);
```

加入场景后，你会看到地面上铺满了一片绿色——草地出现了！配合上一节的 `GridHelper`，可以清楚看到草地是 40m × 40m，每格 1m，正好覆盖整个施工场地。

## 4. OrbitControls：轨道控制器

到现在为止，相机一直固定在 `(12, 8, 12)`，你只能看到一个角度。要真正「浏览」3D 场景，需要让相机响应鼠标操作——这就是 `OrbitControls` 的作用。

### 4.1 导入 OrbitControls

`OrbitControls` 不是 `three` 核心包的内容，它位于 `three/examples/jsm/controls/` 目录下，需要单独导入：

```js
import { OrbitControls } from "three/examples/jsm/controls/OrbitControls.js";
```

::: warning 注意路径后缀
导入路径必须带 `.js` 后缀（`OrbitControls.js`），不能只写 `OrbitControls`。这是因为 `three/examples/jsm/` 是纯 ESM 文件，没有打包，必须显式写文件名。
:::

### 4.2 创建并配置 OrbitControls

```js
// OrbitControls(camera, domElement)
//   camera:    要控制的相机
//   domElement: 鼠标事件监听的 DOM 元素（通常是 renderer.domElement）
controls = new OrbitControls(camera, renderer.domElement);
// 控制器目标点设为房子中心地面附近
controls.target.set(0, 1, 0);
// 启用阻尼，让旋转/缩放有惯性，更顺滑
controls.enableDamping = true;
controls.dampingFactor = 0.08;
// 限制缩放范围，避免拉太近穿模或拉太远看不见
controls.minDistance = 3;
controls.maxDistance = 60;
// 限制俯仰角，禁止翻到地下
controls.maxPolarAngle = Math.PI / 2 - 0.05;
controls.update();
```

几个关键配置：

- **`target`**：相机围绕旋转的中心点。设为 `(0, 1, 0)` 表示围绕房子中心地面附近旋转
- **`enableDamping` + `dampingFactor`**：阻尼让操作有惯性，松开鼠标后相机会继续滑动一段，手感更自然
- **`minDistance` / `maxDistance`**：缩放范围 3m ~ 60m，避免拉到地下或拉到看不见
- **`maxPolarAngle`**：限制相机最多只能俯视到 `90° - 0.05`（接近水平），不能翻到地下

### 4.3 OrbitControls 的鼠标操作

| 鼠标操作 | 效果 |
|----------|------|
| 左键拖拽 | 围绕 `target` 旋转视角 |
| 右键拖拽 | 平移（target 跟着移动） |
| 滚轮 | 沿视线方向缩放（拉远/拉近） |
| 中键拖拽 | （同滚轮）缩放 |

::: tip OrbitControls 的本质
`OrbitControls` 不会「移动相机」，它只是**修改相机的 `position` 和 `quaternion`**，让相机围绕 `target` 旋转。每帧调用 `renderer.render(scene, camera)` 时，相机已经处于新的位置和朝向，渲染出的画面自然就变了。
:::

### 4.4 渲染循环里调用 update

启用了 `enableDamping` 后，**必须在每帧调用 `controls.update()`**，否则阻尼不会生效：

```js
const animate = () => {
  animationId = requestAnimationFrame(animate);
  // OrbitControls 阻尼模式必须在每帧调用 update()
  controls.update();
  renderer.render(scene, camera);
};
animate();
```

如果你忘了调 `controls.update()`，相机会「卡住」——鼠标拖动时画面会跳变，松开后立刻停止，没有顺滑的滑动手感。

## 5. 完整的 HouseScene.vue

把草地和 OrbitControls 加入 `HouseScene.vue`，本阶段就大功告成了。下面是完整的源码（你可以直接复制粘贴覆盖整个文件）：

```vue
<script setup>
import { onMounted, onUnmounted, ref } from "vue";
import * as THREE from "three";
import { OrbitControls } from "three/examples/jsm/controls/OrbitControls.js";

const containerRef = ref(null);

let scene = null;
let camera = null;
let renderer = null;
let controls = null;
let animationId = null;
let resizeHandler = null;

let grassGeometry = null;
let grassMaterial = null;
let grassMesh = null;

let axesHelper = null;
let gridHelper = null;

let ambientLight = null;
let directionalLight = null;

function initScene() {
  const container = containerRef.value;
  const width = container.clientWidth;
  const height = container.clientHeight;

  // 1. 场景
  scene = new THREE.Scene();
  scene.background = new THREE.Color(0xcfd8e3);

  // 2. 相机
  camera = new THREE.PerspectiveCamera(50, width / height, 0.1, 200);
  camera.position.set(12, 8, 12);
  camera.lookAt(0, 1, 0);

  // 3. 渲染器
  renderer = new THREE.WebGLRenderer({ antialias: true });
  renderer.setSize(width, height);
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
  container.appendChild(renderer.domElement);

  // 4. 临时光照
  ambientLight = new THREE.AmbientLight(0xffffff, 0.6);
  scene.add(ambientLight);
  directionalLight = new THREE.DirectionalLight(0xffffff, 0.8);
  directionalLight.position.set(10, 15, 8);
  scene.add(directionalLight);

  // 5. 草地
  grassGeometry = new THREE.PlaneGeometry(40, 40);
  grassMaterial = new THREE.MeshStandardMaterial({ color: 0x67c23a });
  grassMesh = new THREE.Mesh(grassGeometry, grassMaterial);
  grassMesh.rotation.x = -Math.PI / 2;
  grassMesh.position.y = 0;
  scene.add(grassMesh);

  // 6. 辅助工具
  axesHelper = new THREE.AxesHelper(5);
  scene.add(axesHelper);
  gridHelper = new THREE.GridHelper(40, 40);
  scene.add(gridHelper);

  // 7. OrbitControls
  controls = new OrbitControls(camera, renderer.domElement);
  controls.target.set(0, 1, 0);
  controls.enableDamping = true;
  controls.dampingFactor = 0.08;
  controls.minDistance = 3;
  controls.maxDistance = 60;
  controls.maxPolarAngle = Math.PI / 2 - 0.05;
  controls.update();

  // 8. 渲染循环
  const animate = () => {
    animationId = requestAnimationFrame(animate);
    controls.update();
    renderer.render(scene, camera);
  };
  animate();

  // 9. resize 监听
  resizeHandler = () => {
    const w = container.clientWidth;
    const h = container.clientHeight;
    camera.aspect = w / h;
    camera.updateProjectionMatrix();
    renderer.setSize(w, h);
  };
  window.addEventListener("resize", resizeHandler);
}

function disposeScene() {
  if (animationId !== null) {
    cancelAnimationFrame(animationId);
    animationId = null;
  }
  if (resizeHandler) {
    window.removeEventListener("resize", resizeHandler);
    resizeHandler = null;
  }
  if (controls) {
    controls.dispose();
    controls = null;
  }
  if (grassMesh) {
    scene.remove(grassMesh);
    grassGeometry.dispose();
    grassMaterial.dispose();
    grassMesh = null;
    grassGeometry = null;
    grassMaterial = null;
  }
  if (axesHelper) {
    scene.remove(axesHelper);
    axesHelper = null;
  }
  if (gridHelper) {
    scene.remove(gridHelper);
    gridHelper = null;
  }
  if (ambientLight) {
    scene.remove(ambientLight);
    ambientLight = null;
  }
  if (directionalLight) {
    scene.remove(directionalLight);
    directionalLight = null;
  }
  if (renderer) {
    renderer.dispose();
    if (renderer.domElement.parentNode) {
      renderer.domElement.parentNode.removeChild(renderer.domElement);
    }
    renderer = null;
  }
  scene = null;
  camera = null;
}

onMounted(() => initScene());
onUnmounted(() => disposeScene());
</script>

<template>
  <div ref="containerRef" class="scene-container"></div>
</template>

<style scoped>
.scene-container {
  width: 100vw;
  height: 100vh;
  overflow: hidden;
  background: #1f1f1f;
}
</style>
```

## 7. 关于资源销毁的完整套路

注意上面 `disposeScene` 函数里，我们做了如下清理：

1. `cancelAnimationFrame` 停止渲染循环
2. `removeEventListener` 移除 resize 监听
3. `controls.dispose()` 释放控制器（OrbitControls 内部有事件监听，必须 dispose）
4. `grassGeometry.dispose()` / `grassMaterial.dispose()` 释放几何体和材质（GPU 内存）
5. `scene.remove(...)` 从场景移除所有物体
6. `renderer.dispose()` 释放渲染器
7. 移除 `<canvas>` DOM 节点

这套销毁流程是**所有 Three.js 项目的通用模板**，后续阶段加入更多 Mesh / Material / Texture / GLTF 时，只需在 `disposeScene` 里追加对应的 `dispose()` 调用即可。养成「创建和销毁成对出现」的习惯，能避免绝大多数内存泄漏问题。

::: warning OrbitControls 不 dispose 会怎样
`OrbitControls` 内部监听了 `domElement` 上的 `mousedown` / `wheel` / `contextmenu` 等事件。如果不调用 `controls.dispose()`，组件卸载后这些事件监听还在，会持续触发并占用内存，多次挂载/卸载后浏览器会越来越卡。所以 **OrbitControls 必须显式 dispose**。
:::
