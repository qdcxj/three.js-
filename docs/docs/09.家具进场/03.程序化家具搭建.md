# 程序化家具搭建：用 Box 与 Cylinder 拼出桌椅床沙发

01、02 节我们完整学习了 `GLTFLoader` 的生产用法——加载真实 glb 模型、播放动画、Draco 压缩。但本阶段源码快照 `HouseScene.vue` 里的家具并没有用任何 `.glb` 文件，而是用 `BoxGeometry` 和 `CylinderGeometry` 一块块**程序化搭建**出来的。原因很简单：源码快照必须**离线可运行**，不能依赖外部模型文件。这一节我们就逐行拆解这份程序化家具方案，看 Box + Cylinder 怎么拼出可识别的餐桌、椅子、床、沙发，这也是理解 Three.js 几何体组合的绝佳练习。

## 一、为什么需要程序化家具

程序化搭建家具不是"为了不用 GLTF"，它有独立的不可替代价值：

| 场景 | 程序化方案 | GLTF 模型方案 |
|------|-----------|---------------|
| 教程/演示源码（必须离线跑） | ✅ 首选 | ❌ 依赖外部文件 |
| 快速原型/灰盒 | ✅ 几行代码出形 | ❌ 还得等建模 |
| 简单几何体（方块桌椅） | ✅ 体积小 | ⚠️ 杀鸡用牛刀 |
| 复杂雕花/角色/扫描资产 | ❌ 做不出 | ✅ 必须用 |
| 需要逐零件动画/交互 | ✅ 直接拿到 Mesh 引用 | ⚠️ 要 traverse 找子级 |

::: tip 教学价值
就算你最终会用 GLTF，本节的代码也值得逐行读——它把 stage-03 墙体的"多块 Box 拼 Group"思路推到了更细的颗粒度（一把椅子由 6 个零件组成），把这套组合技巧内化后，后续做"用代码生成建筑/机械结构"会非常顺手。
:::

## 二、坐标系约定：家具原点放在地板顶面

回忆 HOUSE_SPEC：室内地板 mesh 中心在 `(0, 0.325, 0)`，厚 0.05，所以**地板顶面 y = 0.35**。所有家具的腿/底座底部都应该落在 y=0.35。

为了让家具代码里"局部 y=0 就是地板顶面"，我们把每件家具的 Group 原点都放在 `(x, 0.35, z)`，零件用局部坐标从 y=0 向上搭。这样腿的 `position.y = legHeight/2` 时，腿底刚好在地板顶面：

```js
import * as THREE from "three";

const FLOOR_TOP = 0.35; // 地板顶面 y

const table = new THREE.Group();
table.position.set(-2, FLOOR_TOP, -1); // Group 原点在地板顶面
// 之后零件用局部坐标，y=0 即地板顶面
```

::: warning 别让家具"陷进地板"或"飘在空中"
如果家具 Group 原点直接放 `(x, 0, z)`（地面），那零件局部 y 还要从 0.35 起算，每个零件都得加 0.35 偏移，麻烦易错。把 Group 原点抬到地板顶面是最干净的做法。
:::

## 三、共享材质与几何体

四件家具共用木色材质，桌椅腿用圆柱体。每件家具单独 new 一份材质/几何体浪费——Three.js 里每个 geometry 都对应一个 GPU buffer，材质对应一个 shader 程序。共享能省显存、省 drawcall。

```js
import * as THREE from "three";

// 共享材质
const woodMat = new THREE.MeshStandardMaterial({
  color: 0x8b5a2b, // 木色（HOUSE_SPEC 木门同色）
  roughness: 0.6,
  metalness: 0.0,
});

// 共享几何体：桌腿（高 0.5）与椅腿（高 0.41）不能共用（高度不同），
// 但同一把椅子的 4 条腿共用一个 geometry
const tableLegGeo = new THREE.CylinderGeometry(0.04, 0.04, 0.5, 12);
const chairLegGeo = new THREE.CylinderGeometry(0.025, 0.025, 0.41, 10);
```

::: tip 共享 geometry 的 dispose 注意
共享 geometry 意味着 dispose 时只能 dispose 一次。本阶段源码用 `furnitureGroup.traverse` 遍历释放，但同一个 geometry 被 4 个 Mesh 引用会被 dispose 4 次——好在 `dispose()` 重复调用是安全的（第二次是 no-op），不会报错。
:::

## 四、餐桌：桌面 + 4 圆柱腿

餐桌是入门级组合：1 块桌面 Box + 4 条圆柱腿。

```js
import * as THREE from "three";

const makeTable = (woodMat, legGeo) => {
  const table = new THREE.Group();
  table.name = "Table";

  // 桌面：1.2 × 0.1 × 0.8，局部 y=0.55（桌高 0.6m，从地板顶面起算）
  const top = new THREE.Mesh(new THREE.BoxGeometry(1.2, 0.1, 0.8), woodMat);
  top.position.set(0, 0.55, 0);
  top.castShadow = true;
  top.receiveShadow = true;
  table.add(top);

  // 4 条腿：高 0.50（从地板顶面 y=0 到桌面底 y=0.50），中心 y=0.25
  // 位置在桌面四角内侧
  const legPositions = [
    [-0.5, 0.25, -0.32],
    [0.5, 0.25, -0.32],
    [-0.5, 0.25, 0.32],
    [0.5, 0.25, 0.32],
  ];
  legPositions.forEach((p) => {
    const leg = new THREE.Mesh(legGeo, woodMat);
    leg.position.set(p[0], p[1], p[2]);
    leg.castShadow = true;
    leg.receiveShadow = true;
    table.add(leg);
  });

  return table;
};

// 摆放：餐桌在室内左前区 (-2, 0.9, -1)
// 注意 0.9 是桌面世界 y = FLOOR_TOP(0.35) + 局部 y(0.55) = 0.90，与 HOUSE_SPEC 吻合
const table = makeTable(woodMat, tableLegGeo);
table.position.set(-2, FLOOR_TOP, -1);
furnitureGroup.add(table);
```

::: tip 腿的半径分段
`CylinderGeometry(0.04, 0.04, 0.5, 12)` 第 4 参数 12 是圆周分段。桌腿这么细，12 段足够圆滑且省面；如果用 32 段，4 条腿就多出 80 个三角面，得不偿失。细节零件用低分段是性能常识。
:::

## 五、椅子：座板 + 靠背 + 4 腿，封装复用

椅子要做 2 把，封装成 `makeChair()` 函数复用。关键设计：椅子**默认朝 +Z 坐**（靠背在 -Z 端），这样旋转 `rotation.y` 就能让它朝任意方向。椅子1 在桌子左侧，要朝 +X 坐（看向桌子），就 `rotation.y = π/2`；椅子2 在右侧，朝 -X 坐，`rotation.y = -π/2`。

```js
import * as THREE from "three";

const makeChair = (woodMat, legGeo) => {
  const chair = new THREE.Group();
  chair.name = "Chair";

  // 座板：0.4 × 0.04 × 0.4，座高 0.45m（局部 y=0.43，座板顶 0.45）
  const seat = new THREE.Mesh(new THREE.BoxGeometry(0.4, 0.04, 0.4), woodMat);
  seat.position.set(0, 0.43, 0);
  seat.castShadow = true;
  seat.receiveShadow = true;
  chair.add(seat);

  // 靠背：0.4 × 0.45 × 0.04，在座板 -Z 端（背后）
  const back = new THREE.Mesh(new THREE.BoxGeometry(0.4, 0.45, 0.04), woodMat);
  back.position.set(0, 0.66, -0.18);
  back.castShadow = true;
  back.receiveShadow = true;
  chair.add(back);

  // 4 条腿：高 0.41，中心 y=0.205，底在 y=0（地板顶面）
  const legPositions = [
    [-0.17, 0.205, -0.17],
    [0.17, 0.205, -0.17],
    [-0.17, 0.205, 0.17],
    [0.17, 0.205, 0.17],
  ];
  legPositions.forEach((p) => {
    const leg = new THREE.Mesh(legGeo, woodMat);
    leg.position.set(p[0], p[1], p[2]);
    leg.castShadow = true;
    leg.receiveShadow = true;
    chair.add(leg);
  });

  return chair;
};

// 椅子1：桌子 -X 侧（x=-3.0），朝 +X 坐 → rotation.y = π/2
const chair1 = makeChair(woodMat, chairLegGeo);
chair1.position.set(-3.0, FLOOR_TOP, -1);
chair1.rotation.y = Math.PI / 2;
furnitureGroup.add(chair1);

// 椅子2：桌子 +X 侧（x=-1.0），朝 -X 坐 → rotation.y = -π/2
const chair2 = makeChair(woodMat, chairLegGeo);
chair2.position.set(-1.0, FLOOR_TOP, -1);
chair2.rotation.y = -Math.PI / 2;
furnitureGroup.add(chair2);
```

::: tip 旋转方向推导
椅子默认朝 +Z（靠背在 -Z）。绕 Y 轴转 +90°（π/2）后，原本 +Z 方向变成 +X 方向（右手坐标系：Y 轴朝上时，从上往下看 +Y 是逆时针，+90° 把 +Z 转到 +X）。所以"朝 +X 坐"就是 `rotation.y = π/2`，"朝 -X 坐"就是 `rotation.y = -π/2`。
:::

## 六、床：床框 + 床垫 + 枕头×2

床是三件套：床框（深木色 Box）、床垫（白色 Box 叠在床框上）、两个枕头（浅蓝小 Box 放在床头）。

```js
import * as THREE from "three";

const makeBed = (frameMat, mattressMat, pillowMat) => {
  const bed = new THREE.Group();
  bed.name = "Bed";

  // 床框：1.5 × 0.3 × 2，底贴地板顶面（局部 y=0.15，底 y=0）
  const frame = new THREE.Mesh(new THREE.BoxGeometry(1.5, 0.3, 2), frameMat);
  frame.position.set(0, 0.15, 0);
  frame.castShadow = true;
  frame.receiveShadow = true;
  bed.add(frame);

  // 床垫：1.4 × 0.2 × 1.9，叠在床框上（局部 y=0.40，底 y=0.30 = 床框顶）
  const mattress = new THREE.Mesh(
    new THREE.BoxGeometry(1.4, 0.2, 1.9),
    mattressMat
  );
  mattress.position.set(0, 0.4, 0);
  mattress.castShadow = true;
  mattress.receiveShadow = true;
  bed.add(mattress);

  // 枕头 ×2：0.45 × 0.12 × 0.3，放在床的 +Z 端（床头）
  // 局部 y=0.56（床垫顶 0.50 + 枕头半高 0.06）
  const pillowGeo = new THREE.BoxGeometry(0.45, 0.12, 0.3);
  const pillowPositions = [
    [-0.35, 0.56, 0.78],
    [0.35, 0.56, 0.78],
  ];
  pillowPositions.forEach((p) => {
    const pillow = new THREE.Mesh(pillowGeo, pillowMat);
    pillow.position.set(p[0], p[1], p[2]);
    pillow.castShadow = true;
    pillow.receiveShadow = true;
    bed.add(pillow);
  });

  return bed;
};

// 摆放：床在右后区 (2.5, 0.5, -1.5)，床头朝 +Z（朝房子中部）
const bed = makeBed(frameMat, mattressMat, pillowMat);
bed.position.set(2.5, FLOOR_TOP, -1.5);
furnitureGroup.add(bed);
```

::: warning 床头朝向
枕头在 `z = +0.78`（床 +Z 端），意味着床头朝 +Z（朝房子中部）。这样从门口（z=3）一进来，看到的是床尾（脚那头），符合生活常识——总不能一进门就看到枕头。这种"朝向符合生活逻辑"的细节是程序化家具容易忽略的地方，多想想就不会摆反。
:::

## 七、沙发：底座 + 靠背 + 2 扶手 + 2 坐垫

沙发零件最多：底座、靠背、2 个扶手、2 个坐垫。靠背朝 +Z（沙发背朝门，人坐下朝 -Z 看后墙的壁炉），符合"沙发面对客厅焦点"的布置逻辑。

```js
import * as THREE from "three";

const makeSofa = (sofaMat, cushionMat) => {
  const sofa = new THREE.Group();
  sofa.name = "Sofa";

  // 底座：2.0 × 0.3 × 0.9，底贴地板顶面
  const base = new THREE.Mesh(new THREE.BoxGeometry(2.0, 0.3, 0.9), sofaMat);
  base.position.set(0, 0.15, 0);
  base.castShadow = true;
  base.receiveShadow = true;
  sofa.add(base);

  // 靠背：2.0 × 0.6 × 0.15，在底座 +Z 端（背朝门）
  const backrest = new THREE.Mesh(
    new THREE.BoxGeometry(2.0, 0.6, 0.15),
    sofaMat
  );
  backrest.position.set(0, 0.55, 0.375);
  backrest.castShadow = true;
  backrest.receiveShadow = true;
  sofa.add(backrest);

  // 扶手 ×2：0.15 × 0.4 × 0.9，在底座左右
  const armGeo = new THREE.BoxGeometry(0.15, 0.4, 0.9);
  const armLeft = new THREE.Mesh(armGeo, sofaMat);
  armLeft.position.set(-0.925, 0.35, 0);
  armLeft.castShadow = true;
  armLeft.receiveShadow = true;
  sofa.add(armLeft);
  const armRight = new THREE.Mesh(armGeo, sofaMat);
  armRight.position.set(0.925, 0.35, 0);
  armRight.castShadow = true;
  armRight.receiveShadow = true;
  sofa.add(armRight);

  // 坐垫 ×2：0.95 × 0.15 × 0.8，叠在底座上
  const cushionGeo = new THREE.BoxGeometry(0.95, 0.15, 0.8);
  const cushionPositions = [
    [-0.48, 0.375, -0.02],
    [0.48, 0.375, -0.02],
  ];
  cushionPositions.forEach((p) => {
    const cushion = new THREE.Mesh(cushionGeo, cushionMat);
    cushion.position.set(p[0], p[1], p[2]);
    cushion.castShadow = true;
    cushion.receiveShadow = true;
    sofa.add(cushion);
  });

  return sofa;
};

// 摆放：沙发在中部靠前 (0, 0.5, 1.5)
const sofa = makeSofa(sofaMat, cushionMat);
sofa.position.set(0, FLOOR_TOP, 1.5);
furnitureGroup.add(sofa);
```

## 八、家具进场总入口：addFurniture

把上面四件家具组装到一起，挂到 `houseGroup` 下，随房子一起渲染和 dispose：

```js
import * as THREE from "three";

const addFurniture = (houseGroup) => {
  const furnitureGroup = new THREE.Group();
  furnitureGroup.name = "Furniture";

  // 共享材质：木色（桌椅）、深木色（床框）、白（床垫）、浅蓝（枕头）、
  // 暖灰（沙发）、浅米（坐垫）
  const woodMat = new THREE.MeshStandardMaterial({ color: 0x8b5a2b, roughness: 0.6 });
  const frameMat = new THREE.MeshStandardMaterial({ color: 0x6b4423, roughness: 0.7 });
  const mattressMat = new THREE.MeshStandardMaterial({ color: 0xf5f5f5, roughness: 0.9 });
  const pillowMat = new THREE.MeshStandardMaterial({ color: 0xa8d0ff, roughness: 0.9 });
  const sofaMat = new THREE.MeshStandardMaterial({ color: 0x9c8a78, roughness: 0.85 });
  const cushionMat = new THREE.MeshStandardMaterial({ color: 0xe6d5b8, roughness: 0.85 });

  // 共享几何体
  const tableLegGeo = new THREE.CylinderGeometry(0.04, 0.04, 0.5, 12);
  const chairLegGeo = new THREE.CylinderGeometry(0.025, 0.025, 0.41, 10);

  // 餐桌 + 2 椅子（左前区）
  const table = makeTable(woodMat, tableLegGeo);
  table.position.set(-2, FLOOR_TOP, -1);
  furnitureGroup.add(table);

  const chair1 = makeChair(woodMat, chairLegGeo);
  chair1.position.set(-3.0, FLOOR_TOP, -1);
  chair1.rotation.y = Math.PI / 2;
  furnitureGroup.add(chair1);

  const chair2 = makeChair(woodMat, chairLegGeo);
  chair2.position.set(-1.0, FLOOR_TOP, -1);
  chair2.rotation.y = -Math.PI / 2;
  furnitureGroup.add(chair2);

  // 床（右后区）
  const bed = makeBed(frameMat, mattressMat, pillowMat);
  bed.position.set(2.5, FLOOR_TOP, -1.5);
  furnitureGroup.add(bed);

  // 沙发（中部靠前）
  const sofa = makeSofa(sofaMat, cushionMat);
  sofa.position.set(0, FLOOR_TOP, 1.5);
  furnitureGroup.add(sofa);

  houseGroup.add(furnitureGroup);
};
```

::: tip 为什么挂到 houseGroup 而非 scene
家具是"房子内容物"，逻辑上属于房子。挂到 `houseGroup` 下，未来如果要让整栋房子移动/旋转/隐藏（如 stage-14 整合阶段做"鸟瞰俯视"切换），家具会跟着一起动。这也意味着 dispose 时只要 traverse `houseGroup` 就能统一释放，不需要单独管理家具生命周期。
:::

## 九、dispose：traverse 释放家具 Group

家具 Group 内有几十个 Mesh，逐个 track 太繁琐。源码用 `traverse` 统一遍历释放，且兼容可能加载进来的 GLTF 模型材质（带 map 贴图）：

```js
import * as THREE from "three";

if (furnitureGroup) {
  furnitureGroup.traverse((obj) => {
    if (obj.geometry) obj.geometry.dispose();
    if (obj.material) {
      if (Array.isArray(obj.material)) {
        obj.material.forEach((m) => {
          if (m.map) m.map.dispose(); // GLTF 材质可能带贴图
          m.dispose();
        });
      } else {
        if (obj.material.map) obj.material.map.dispose();
        obj.material.dispose();
      }
    }
  });
  if (furnitureGroup.parent) furnitureGroup.parent.remove(furnitureGroup);
  furnitureGroup = null;
}
```

::: warning 共享 geometry 的重复 dispose
`furnitureGroup` 里 4 条桌腿共用 `tableLegGeo`，traverse 时会被 dispose 4 次。好在 `Geometry.dispose()` 重复调用是安全的（第二次起 no-op），不会报错。但如果你用了 `ReferenceCounter` 之类的精细管理，要小心计数。
:::

## 十、本节总结

- **离线可运行的核心**：源码快照里的家具用 `BoxGeometry` + `CylinderGeometry` 程序化搭建，不依赖任何外部 .glb 文件，断网也能跑
- **坐标系约定**：家具 Group 原点放在地板顶面 `(x, 0.35, z)`，零件局部坐标从 y=0 向上搭，腿底自然落在地板上
- **共享材质与几何体**：木色材质、桌/椅腿 geometry 在多件家具间共享，省显存省 drawcall
- **Group 复用**：`makeChair()` / `makeTable()` / `makeBed()` / `makeSofa()` 封装为函数，返回 Group，外部用 `position` / `rotation` 摆放
- **朝向约定**：椅子默认朝 +Z（靠背 -Z），靠 `rotation.y` 旋转朝向桌子；床头朝 +Z（朝房子中部）；沙发背朝门、人朝壁炉墙
- **dispose 用 traverse**：家具 Group 内几十个 Mesh 用 `traverse` 统一遍历释放 geometry / material / map，重复 dispose 安全

::: tip 阶段收尾
