# 🪑 第 09 阶段：家具进场

> 走到第 09 阶段，小屋的"骨架 + 皮肤 + 灯光 + 动画"都齐了，可屋里还空荡荡的——一栋没有家具的房子始终只是个"建筑"，而不是"家"。本阶段我们把家具搬进室内：餐桌、椅子、床、沙发各就各位，小屋终于"住得下人"。在技术层面，这正是 Three.js **模型加载**（Model Loading）登场的时候——真实生产环境几乎不会手写每一把椅子，而是用 Blender / Maya 建模后导出 glTF，再用 `GLTFLoader` 加载进场景。本章会完整教学 `GLTFLoader` API、模型内嵌动画播放、Draco 压缩模型加载，同时给出一份**离线可运行**的程序化家具方案作为源码快照。

## 🎯 建造目标

| # | 构件 | 关键参数 | 实现方式 |
|---|------|----------|----------|
| 1 | 餐桌 | 桌面 Box(1.2,0.1,0.8) + 4 CylinderGeometry 腿 | 程序化 Group，位置 (-2, 0.9, -1) |
| 2 | 椅子 ×2 | 座板 + 靠背 + 4 腿，`makeChair()` 复用 | 桌两侧，绕 Y 轴 ±90° 朝向桌子 |
| 3 | 床 | 床框 Box(1.5,0.3,2) + 床垫 + 枕头×2 | 程序化，位置 (2.5, 0.5, -1.5) |
| 4 | 沙发 | 底座 + 靠背 + 2 扶手 + 坐垫×2 | 程序化，位置 (0, 0.5, 1.5) |
| 5 | GLTFLoader 演示 | 四回调 + traverse 处理 + onError 回退 | 在线尝试，离线静默回退 |
| 6 | 累积构件 | 草地+地基+台阶+墙含洞+门+屋顶+烟囱+地板+贴图+玻璃+灯光阴影+OrbitControls+开关门+昼夜 | 继承 stage-08 全部 |

到本阶段末，运行项目应能看到：暖米色砖墙小屋立在草地上，屋顶是砖红色双坡顶、右侧立着灰色烟囱。**走进室内**（拖拽视角或缩放进去），左前区摆着一张木色餐桌、两侧各一把椅子；右后区是一张铺着白床垫、浅蓝枕头的双人床；中部靠前是一张暖灰布艺沙发，背朝大门、面朝后墙。按 **O** 门会绕门轴打开，按 **L** 室内灯亮起，家具在暖黄灯光下投出各自的阴影——一栋真正"有人住"的小屋成型了。

## 📚 学习目标

完成本阶段后，你应当能够：

- **理解 glTF 格式为何是 Web 3D 的事实标准**：知道它跟 OBJ/FBX 相比赢在哪里，以及 `.gltf`（文本/分文件）与 `.glb`（二进制单文件）的区别
- **掌握 `GLTFLoader` 的四回调用法**：`load(url, onLoad, onProgress, onError)` 各自何时触发、参数是什么、为什么是异步的
- **处理加载后的场景图**：用 `gltf.scene`（一个 `Group`）的 `traverse` 遍历所有 Mesh，统一开启阴影、改材质、改投影
- **适配模型尺寸与位置**：导出的模型往往"巨大或微小且原点偏"，会用 `Box3` 包围盒计算尺寸后 `scale` 归一化、再 `position` 就位
- **播放模型内嵌动画**：用 `AnimationMixer` + `AnimationClip` 让带骨骼的模型（如角色走、风扇转）动起来
- **加载 Draco 压缩模型**：用 `DRACOLoader` 配置 wasm 解码器路径，加载体积缩小 90%+ 的压缩 glb
- **用基础几何体程序化搭建家具**：在无外部模型文件时，用 Box/Cylinder 也能搭出可识别的桌椅床沙发，且离线可运行

::: tip 离线可运行说明
源码快照里的家具是**程序化搭建**的（Box + CylinderGeometry），不依赖任何外部 `.glb/.gltf` 文件，因此 `pnpm install && pnpm build` 之后断网也能看到完整家具场景。`GLTFLoader` 的真实加载则以"在线尝试 + 失败静默回退"的方式演示——联网时会从 threejs 官方 CDN 加载一个示例模型放到屋顶当装饰，离线时自动回退到纯程序化家具。文档章节则完整教学 `GLTFLoader` 的生产用法，让你理解真实项目里怎么把 Blender 导出的家具模型搬进场景。
:::
