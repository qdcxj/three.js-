# 第一人称漫游：PointerLockControls + WASD 键盘控制

鸟瞰模式让我们从宏观俯视小屋，但真正的"沉浸感"来自第一人称——站在门口，推门而入，环顾四周。本节实现本阶段最核心的交互：用 `PointerLockControls` 锁定鼠标控制视角，用 WASD 键盘控制移动，让你真正"走进"小屋参观。

## 一、为什么需要 Pointer Lock API

第一人称漫游的核心需求是：**鼠标移动控制视角旋转，且鼠标不会移出屏幕**。普通的 `mousemove` 事件有致命缺陷——鼠标移到屏幕边缘后就无法继续移动，视角就卡住了。

浏览器的 **Pointer Lock API**（指针锁定）解决了这个问题：

- 锁定后鼠标光标**隐藏**，且**无法移出**浏览器窗口
- 鼠标移动时持续触发 `mousemove`，并提供 `movementX` / `movementY` 表示**相对位移**
- 即使鼠标"移到屏幕边缘"，相对位移依然持续产生（鼠标被虚拟地"困住"）
- 用户按 **ESC** 键退出锁定

```
普通 mousemove：                    Pointer Lock：
鼠标到边缘就卡住                    鼠标无限移动，光标隐藏

  ┌────────────┐                    ┌────────────┐
  │            │                    │  光标隐藏  │
  │     ●←──→ │ 卡住               │  ←→持续移动│
  │            │                    │            │
  └────────────┘                    └────────────┘
```

::: tip Pointer Lock 与 FPS 游戏
所有网页端的第一人称射击游戏（如 Krunker、方块方舟）都用 Pointer Lock API。它是 Web 端实现"鼠标转头"的唯一可靠方案。
:::

## 二、PointerLockControls 基础

Three.js 把 Pointer Lock API 封装成了 `PointerLockControls`，位于 `three/examples/jsm/controls/PointerLockControls.js`：

```js
import * as THREE from "three";
import { PointerLockControls } from "three/examples/jsm/controls/PointerLockControls.js";

// 创建：绑定到漫游相机和渲染器的 domElement
const pointerLockControls = new PointerLockControls(roamCamera, renderer.domElement);

// 请求指针锁定（必须由用户手势触发：按键、点击等）
pointerLockControls.lock();

// 退出指针锁定
pointerLockControls.unlock();

// 是否已锁定（只读属性）
console.log(pointerLockControls.isLocked); // true / false

// 启用/禁用控制器（禁用后鼠标移动不生效）
pointerLockControls.enabled = false;
```

::: warning lock() 必须由用户手势触发
浏览器安全策略要求 `requestPointerLock()` 必须在**用户手势**（click、keydown 等）的回调中调用。直接在 `onMounted` 里调用 `lock()` 会被浏览器拒绝。本阶段用 **F 键**触发锁定，keydown 是合法的用户手势。
:::

## 三、PointerLockControls 的事件

`PointerLockControls` 继承自 `EventDispatcher`，会派发三个事件：

| 事件 | 触发时机 | 用途 |
|------|----------|------|
| `lock` | 指针锁定成功 | 切换到漫游模式、显示 UI |
| `unlock` | 指针锁定退出（ESC 或 unlock()） | 切回鸟瞰模式 |
| `change` | 相机旋转（鼠标移动时） | 通常不需要手动处理 |

```js
import * as THREE from "three";
import { PointerLockControls } from "three/examples/jsm/controls/PointerLockControls.js";

const pointerLockControls = new PointerLockControls(roamCamera, renderer.domElement);

// 监听锁定成功
pointerLockControls.addEventListener("lock", () => {
  console.log("指针锁定成功，进入第一人称模式");
  mode.value = "roam";
});

// 监听锁定退出（用户按 ESC）
pointerLockControls.addEventListener("unlock", () => {
  console.log("指针锁定退出，切回鸟瞰模式");
  mode.value = "bird";
});
```

::: tip ESC 是浏览器内置行为
用户按 ESC 退出指针锁定是**浏览器内置行为**，不需要我们手动监听 ESC 键。我们只需监听 `unlock` 事件，在退出时自动切回鸟瞰模式即可。
:::

## 四、WASD 键盘控制：状态机模式

第一人称移动的核心是 **WASD 键盘控制**。关键设计：**不要在 keydown 里直接移动相机**，而是用"状态机"——keydown 记录按键状态，渲染循环里根据状态持续移动。

```js
// 按键状态：true 表示按下
const keys = { w: false, a: false, s: false, d: false };

// keydown：记录按下
function onKeyDown(e) {
  switch (e.code) {
    case "KeyW": keys.w = true; break;
    case "KeyA": keys.a = true; break;
    case "KeyS": keys.s = true; break;
    case "KeyD": keys.d = true; break;
  }
}

// keyup：记录松开
function onKeyUp(e) {
  switch (e.code) {
    case "KeyW": keys.w = false; break;
    case "KeyA": keys.a = false; break;
    case "KeyS": keys.s = false; break;
    case "KeyD": keys.d = false; break;
  }
}

window.addEventListener("keydown", onKeyDown);
window.addEventListener("keyup", onKeyUp);
```

::: warning 为什么不用 keydown 直接移动
如果按住 W 键，`keydown` 会以操作系统按键重复频率（约每秒 10~30 次）触发，移动会**一顿一顿**。用状态机模式，在渲染循环（每秒 60 次）里平滑移动，才能流畅。这是所有游戏引擎的标准做法。
:::

## 五、渲染循环里的移动更新

`PointerLockControls` 提供了 `moveForward` 和 `moveRight` 两个方法，自动按相机朝向移动：

```js
import * as THREE from "three";

const clock = new THREE.Clock();
const ROAM_SPEED = 5.0; // 移动速度：5 米/秒

function animate() {
  requestAnimationFrame(animate);
  const delta = clock.getDelta(); // 距上一帧的时间（秒）

  // 只在锁定状态下移动
  if (pointerLockControls.isLocked) {
    const distance = ROAM_SPEED * delta; // 这一帧移动距离 = 速度 × 时间

    if (keys.w) pointerLockControls.moveForward(distance);   // 前进
    if (keys.s) pointerLockControls.moveForward(-distance);  // 后退
    if (keys.d) pointerLockControls.moveRight(distance);     // 右移
    if (keys.a) pointerLockControls.moveRight(-distance);    // 左移
  }

  renderer.render(scene, activeCamera);
}
animate();
```

`moveForward(distance)` 的原理：从相机的世界矩阵中提取前进方向（投影到 XZ 水平面），沿该方向移动 `distance` 距离。**保持 Y 不变**，所以不会"飞起来"或"钻地下"。

::: tip 帧率无关的移动
`distance = speed * delta` 保证移动速度与帧率无关：60fps 时每帧移动 `5 * 0.0167 = 0.083m`，30fps 时每帧移动 `5 * 0.033 = 0.167m`，但每秒总位移都是 5m。如果用固定值（如 `moveForward(0.1)`），高帧率会移动更快，低帧率更慢——这是新手常犯的错。
:::

## 六、边界约束与高度锁定

`moveForward` / `moveRight` 只管移动，不管边界。需要手动约束，防止走出草地或飞起来：

```js
import * as THREE from "three";

// 在渲染循环里，移动后约束位置
if (pointerLockControls.isLocked) {
  // ... WASD 移动代码 ...

  // 边界约束：限制在草地范围（±18m，草地 40×40 留 2m 边距）
  roamCamera.position.x = THREE.MathUtils.clamp(roamCamera.position.x, -18, 18);
  roamCamera.position.z = THREE.MathUtils.clamp(roamCamera.position.z, -18, 18);
  // 高度锁定：人眼始终 1.6m，避免飞起来或掉下去
  roamCamera.position.y = 1.6;
}
```

::: warning moveForward 会改变 Y 吗
看 `PointerLockControls` 源码，`moveForward` 内部用 `camera.up` 与相机矩阵的列向量做叉积，得到**水平面内**的前进方向，所以 Y 不会被改变。但 `moveRight` 提取的是相机矩阵第 0 列（右方向），如果相机俯仰了，这个方向有 Y 分量——所以移动后仍建议手动锁定 Y。本阶段代码做了双重保险。
:::

::: tip 简易边界 vs 碰撞检测
本阶段只做"草地边界"约束（±18m），不做墙体碰撞——你可以穿墙。真正的碰撞检测需要射线检测（Raycaster）或物理引擎（Cannon.js / Rapier），属于进阶内容。stage-09 加家具后可以考虑加入。
:::

## 七、模式切换：G / F / ESC

本阶段支持三种模式切换操作：

| 按键 | 动作 | 实现 |
|------|------|------|
| **F** | 切到第一人称 | 关闭 OrbitControls → 请求 PointerLock → 切 activeCamera |
| **G** | 切到鸟瞰 | 退出 PointerLock → 启用 OrbitControls → 切 activeCamera |
| **ESC** | 退出指针锁 | 浏览器内置 → 触发 unlock 事件 → 自动切鸟瞰 |

```js
import * as THREE from "three";

// 模式切换函数
function switchMode(next) {
  if (next === "roam") {
    // 鸟瞰 → 第一人称
    orbitControls.enabled = false;             // 关闭鸟瞰控制器
    pointerLockControls.enabled = true;        // 启用漫游控制器
    pointerLockControls.lock();                // 请求指针锁（keydown 触发，合法）
    activeCamera = roamCamera;                 // 切换渲染相机
    roamCamera.position.set(0, 1.6, 6);        // 重置到门口前
    roamCamera.lookAt(0, 1.6, 0);
  } else {
    // 第一人称 → 鸟瞰
    if (pointerLockControls.isLocked) {
      pointerLockControls.unlock();            // 退出指针锁
    }
    pointerLockControls.enabled = false;
    orbitControls.enabled = true;              // 启用鸟瞰控制器
    orbitControls.update();
    activeCamera = birdCamera;                 // 切换渲染相机
  }
  mode.value = next;
}

// keydown 里监听 G/F
function onKeyDown(e) {
  if (e.code === "KeyG") { switchMode("bird"); return; }
  if (e.code === "KeyF") { switchMode("roam"); return; }
  // ... WASD 状态记录 ...
}

// ESC 退出时自动切鸟瞰
pointerLockControls.addEventListener("unlock", () => {
  if (mode.value === "roam") switchMode("bird");
});
```

::: warning 两套控制器不能同时启用
`OrbitControls` 和 `PointerLockControls` 都监听鼠标事件。如果同时启用，会冲突——拖拽时既旋转又转头。所以切换时必须**关闭一个、启用另一个**：`orbitControls.enabled = false` + `pointerLockControls.enabled = true`，反之亦然。
:::

## 八、完整渲染循环与 dispose

本阶段的渲染循环需要同时处理两种模式：

```js
import * as THREE from "three";

const clock = new THREE.Clock();

function animate() {
  requestAnimationFrame(animate);
  const delta = clock.getDelta();

  if (mode.value === "bird") {
    // 鸟瞰模式：更新 OrbitControls 阻尼
    orbitControls.update();
  } else if (mode.value === "roam" && pointerLockControls.isLocked) {
    // 漫游模式：WASD 移动
    const distance = ROAM_SPEED * delta;
    if (keys.w) pointerLockControls.moveForward(distance);
    if (keys.s) pointerLockControls.moveForward(-distance);
    if (keys.d) pointerLockControls.moveRight(distance);
    if (keys.a) pointerLockControls.moveRight(-distance);
    // 边界约束
    roamCamera.position.x = THREE.MathUtils.clamp(roamCamera.position.x, -18, 18);
    roamCamera.position.z = THREE.MathUtils.clamp(roamCamera.position.z, -18, 18);
    roamCamera.position.y = 1.6;
  }

  renderer.render(scene, activeCamera);
}
```

资源释放（dispose）需要清理两套控制器和键盘监听：

```js
function disposeScene() {
  // 取消渲染循环
  cancelAnimationFrame(animationId);
  // 移除事件监听
  window.removeEventListener("resize", handleResize);
  window.removeEventListener("keydown", onKeyDown);
  window.removeEventListener("keyup", onKeyUp);

  // 释放 PointerLockControls（移除 unlock 监听 + disconnect）
  if (pointerLockControls) {
    pointerLockControls.removeEventListener("unlock", onPointerUnlock);
    if (pointerLockControls.isLocked) pointerLockControls.unlock();
    pointerLockControls.dispose();
    pointerLockControls = null;
  }
  // 释放 OrbitControls
  if (orbitControls) {
    orbitControls.dispose();
    orbitControls = null;
  }
  // 释放几何体/材质/渲染器...
}
```

::: tip 完整 dispose 的重要性
本阶段引入了键盘监听和两套控制器，如果不在 `onUnmounted` 里清理，组件卸载后键盘事件依然触发、控制器依然监听鼠标——导致内存泄漏和幽灵事件。Vue 的 `onUnmounted` 钩子是清理的最佳时机。
:::

```vue
      </div>

    </div>
  </div>
</template>
```

::: tip pointer-events: none
UI 提示 div 必须设置 `pointer-events: none`，否则会阻挡画布的鼠标事件——在鸟瞰模式下拖拽旋转会被 UI 挡住。设置后鼠标事件穿透到画布。
:::

## 十、本节总结

| 知识点 | 关键 API | 说明 |
|--------|---------|------|
| 指针锁定 | `pointerLockControls.lock()` | 必须由用户手势触发 |
| 退出锁定 | `pointerLockControls.unlock()` | 或用户按 ESC |
| 锁定状态 | `pointerLockControls.isLocked` | 只读布尔值 |
| 锁定事件 | `addEventListener("lock"/"unlock")` | 监听锁定/退出 |
| 前进移动 | `pointerLockControls.moveForward(distance)` | 沿视线水平前进 |
| 右移 | `pointerLockControls.moveRight(distance)` | 沿相机右侧平移 |
| WASD 状态机 | `keys = {w,a,s,d}` + keydown/keyup | 不要在 keydown 里直接移动 |
| 帧率无关 | `distance = speed * clock.getDelta()` | 60fps 和 30fps 移动一致 |
| 边界约束 | `THREE.MathUtils.clamp()` | 防止走出场景 |
| 模式切换 | `orbitControls.enabled` + `activeCamera` | 两套控制器互斥 |
| 资源释放 | `pointerLockControls.dispose()` | 清理监听 + disconnect |
