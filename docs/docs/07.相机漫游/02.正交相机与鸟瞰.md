# 正交相机与鸟瞰：OrthographicCamera 的六个参数

透视相机模拟人眼"近大远小"，但有时我们不想要这种效果——比如从正上方俯视小屋时，房子近的那边不应该比远的那边大。这时就需要 `OrthographicCamera`（正交相机）。本阶段的**鸟瞰模式**就用它：从 30 米高空垂直俯视，整栋小屋在画面中保持真实比例，不因远近而变形。

## 一、正交投影 vs 透视投影

两种投影的本质区别在于**投影线是否汇聚于一点**：

```
透视投影（投影线汇聚）        正交投影（投影线平行）

   相机 ●                       相机
   ╱  ╲ ╲                      │ │ │ │
  ╱    ╲ ╲                    │ │ │ │
 ╱      ╲ ╲                   │ │ │ │
□ □ □ □ □                    □ □ □ □ □
近大远小                     远近一样大
```

- **透视投影**：所有投影线汇聚到相机一点，近处物体投影面积大，远处小
- **正交投影**：所有投影线互相平行，物体无论远近投影面积相同

::: tip 生活中的正交投影
建筑平面图、机械工程图、地图俯视图都是正交投影——它们需要精确反映尺寸，不能有"近大远小"的畸变。本阶段的鸟瞰模式就是一个"建筑俯视图"。
:::

## 二、构造函数与六个参数

`OrthographicCamera` 的构造函数接收六个参数：

```js
new THREE.OrthographicCamera(left, right, top, bottom, near, far)
```

| 参数 | 类型 | 说明 | 本阶段取值 |
|------|------|------|-----------|
| `left` | Number | 视景体左边界（世界单位：米） | `-15 * aspect` |
| `right` | Number | 视景体右边界 | `15 * aspect` |
| `top` | Number | 视景体上边界 | `15` |
| `bottom` | Number | 视景体下边界 | `-15` |
| `near` | Number | 近裁剪面距离 | `0.1` |
| `far` | Number | 远裁剪面距离 | `200` |

注意：与透视相机不同，正交相机**没有 `fov` 参数**。视野范围直接由 `left/right/top/bottom` 四个边界决定，单位是世界单位（本教程中 1 单位 = 1 米）。

本阶段鸟瞰相机的创建代码：

```js
import * as THREE from "three";

const aspect = window.innerWidth / window.innerHeight;
const orthoHalf = 15; // 半边长（米）：能完整看到 8×6 的房子并留余量

// 正交相机（鸟瞰用）：从 (0,30,0) 俯视，视景体覆盖房子
const birdCamera = new THREE.OrthographicCamera(
  -orthoHalf * aspect, // left：左边界
  orthoHalf * aspect,  // right：右边界
  orthoHalf,           // top：上边界
  -orthoHalf,          // bottom：下边界
  0.1,                 // near
  200                  // far
);
// 位置：房子正上方 30m
birdCamera.position.set(0, 30, 0);
// 关键：相机朝下看时，默认 up=(0,1,0) 会与视线共线（退化）
// 把 up 改成 (0,0,-1)，让屏幕"上"对应世界 -Z 方向
birdCamera.up.set(0, 0, -1);
birdCamera.lookAt(0, 0, 0);
birdCamera.updateProjectionMatrix();
```

## 三、left / right / top / bottom：视景体边界

这四个参数定义了正交相机的**矩形视景体**（一个长方体盒子）。只有在盒子内的物体才会被渲染：

```
         top
          │
          │
  ────────┼──────── right
  │       │        │
  │       │        │
 left─────┼────────┘
          │
         bottom

  （从相机方向看过去的视景体截面）
```

本阶段房子是 8m(X) × 6m(Z)，所以半边长 15m 能完整覆盖并留余量。`left/right` 乘以 `aspect` 是为了让宽屏时水平方向看到更多内容，避免画面拉伸。

::: warning 为什么 left/right 要乘以 aspect
如果 `left = -15, right = 15`（不乘 aspect），在宽屏（aspect=1.78）上画面会被横向拉伸——房子变扁。乘以 aspect 后，水平视景体变成 `±15*1.78 = ±26.7m`，水平看到更多，但比例正确。这和透视相机的 `aspect` 作用类似：保证画面不变形。
:::

## 四、near 与 far：与透视相同的含义

正交相机的 `near` / `far` 与透视相机完全相同：定义可见深度范围。本阶段鸟瞰相机在 y=30，看向 y=0，所以 `near=0.1`、`far=200` 足够覆盖 30m 的距离。

```js
// 鸟瞰相机深度范围：0.1m ~ 200m
// 相机在 y=30，房子在 y=0~5，距离 25~30m，完全在范围内
new THREE.OrthographicCamera(-15, 15, 15, -15, 0.1, 200);
```

::: tip 正交相机的阴影关联
stage-06 的平行光阴影相机（`DirectionalLight.shadow.camera`）本质上就是一台 `OrthographicCamera`！它的 `left/right/top/bottom/near/far` 参数与正交相机完全相同。理解了本节，你就同时掌握了阴影相机的配置。
:::

## 五、up 向量：俯视的关键

正交相机从正上方俯视时，有一个**陷阱**：默认 `up = (0, 1, 0)`（Y 轴向上），但相机视线也是 Y 轴方向，两者共线导致姿态退化——相机不知道"哪边是上"，画面会出问题。

```js
import * as THREE from "three";

// 错误：up 与视线共线，姿态退化
birdCamera.position.set(0, 30, 0);
birdCamera.lookAt(0, 0, 0);
// 此时 up=(0,1,0)，视线=(0,-1,0)，共线 → 画面异常

// 正确：把 up 改成 (0,0,-1)，让屏幕"上"对应世界 -Z
birdCamera.up.set(0, 0, -1);
birdCamera.lookAt(0, 0, 0);
// 此时视线=(0,-1,0)，up=(0,0,-1)，不共线 → 画面正常
```

`up` 向量决定了**屏幕的"上"方向**对应世界的哪个方向。本阶段设 `up=(0,0,-1)`，意味着屏幕上方对应世界 `-Z` 方向。由于房子正面朝 `+Z`，所以俯视图中房子正面朝屏幕下方，符合"北朝上、南朝下"的地图习惯。

::: warning up 必须在 lookAt 之前设置
`lookAt()` 内部会根据 `up` 向量计算相机的旋转。所以必须**先设 `up`，再调 `lookAt`**。顺序反了会导致 `up` 不生效。
:::

## 六、与透视相机的对比

| 维度 | PerspectiveCamera | OrthographicCamera |
|------|-------------------|-------------------|
| 近大远小 | ✅ 有 | ❌ 无 |
| 投影线 | 汇聚于一点 | 互相平行 |
| 视野参数 | `fov`（角度） | `left/right/top/bottom`（世界单位） |
| 宽高比 | `aspect` | 通过 `left/right × aspect` 体现 |
| near / far | ✅ 有 | ✅ 有 |
| 典型用途 | 游戏、漫游、产品展示 | 工程图、鸟瞰、2.5D 游戏 |
| 本阶段用途 | 第一人称漫游 | 鸟瞰俯视 |

::: tip 同一场景两台相机
本阶段同时维护两台相机：`roamCamera`（透视，第一人称）和 `birdCamera`（正交，鸟瞰）。渲染时通过 `activeCamera` 变量切换 `renderer.render(scene, activeCamera)` 的第三个参数，决定用哪台相机渲染。
:::

## 七、鸟瞰模式的完整实现

下面是本阶段鸟瞰相机的完整配置，包括 resize 处理和与 OrbitControls 的配合：

```js
import * as THREE from "three";
import { OrbitControls } from "three/examples/jsm/controls/OrbitControls.js";

// ===== 创建正交相机（鸟瞰用）=====
const aspect = window.innerWidth / window.innerHeight;
const orthoHalf = 15;

const birdCamera = new THREE.OrthographicCamera(
  -orthoHalf * aspect,
  orthoHalf * aspect,
  orthoHalf,
  -orthoHalf,
  0.1,
  200
);
birdCamera.position.set(0, 30, 0);
birdCamera.up.set(0, 0, -1); // 俯视关键：避免 up 与视线共线
birdCamera.lookAt(0, 0, 0);
birdCamera.updateProjectionMatrix();

// ===== OrbitControls 绑定到鸟瞰相机 =====
const orbitControls = new OrbitControls(birdCamera, renderer.domElement);
orbitControls.enableDamping = true;
orbitControls.dampingFactor = 0.05;
orbitControls.target.set(0, 1.5, 0); // 视线中心略抬到房子中部
orbitControls.minDistance = 5;        // 限制缩放范围
orbitControls.maxDistance = 60;
orbitControls.update();

// ===== resize 处理：更新正交相机视景体 =====
function handleResize() {
  const w = window.innerWidth;
  const h = window.innerHeight;
  const aspect = w / h;
  // 正交相机：根据 aspect 更新 left/right（top/bottom 不变）
  birdCamera.left = -orthoHalf * aspect;
  birdCamera.right = orthoHalf * aspect;
  birdCamera.updateProjectionMatrix();
  renderer.setSize(w, h);
}
window.addEventListener("resize", handleResize);
```

::: warning OrbitControls 与正交相机的缩放
`OrbitControls` 对正交相机的"缩放"行为与透视不同：透视相机靠改变 `position`（拉近拉远）缩放，正交相机靠改变 `zoom` 属性缩放（`camera.zoom = 2` 画面放大 2 倍）。所以 `minDistance` / `maxDistance` 对正交相机效果有限，更精确的缩放限制应该用 `orbitControls.minZoom` / `maxZoom`。
:::

## 八、鸟瞰 ↔ 漫游的相机切换

本阶段的核心是**两台相机的切换**。用一个 `activeCamera` 变量记录当前激活的相机，渲染时用它：

```js
import * as THREE from "three";

let roamCamera = null;      // 透视相机（漫游）
let birdCamera = null;      // 正交相机（鸟瞰）
let activeCamera = null;    // 当前激活的相机

// 创建两台相机（代码见上文）...
activeCamera = birdCamera;  // 默认鸟瞰

// 渲染循环：用 activeCamera 渲染
function animate() {
  requestAnimationFrame(animate);
  renderer.render(scene, activeCamera); // 关键：第三个参数是当前相机
}
animate();

// 切换到漫游
function switchToRoam() {
  activeCamera = roamCamera;
}
// 切换到鸟瞰
function switchToBird() {
  activeCamera = birdCamera;
}
```

::: tip 切换相机不消耗性能
切换 `activeCamera` 只是改一个变量引用，不重建相机、不重新分配内存，性能开销几乎为零。所以可以频繁切换（比如每帧切换做画中画效果）。
:::

## 九、本节总结

| 知识点 | 关键 API | 说明 |
|--------|---------|------|
| 创建正交相机 | `new THREE.OrthographicCamera(left, right, top, bottom, near, far)` | 无近大远小 |
| 视景体边界 | `left/right/top/bottom` | 世界单位，定义可见矩形 |
| 宽高比 | `left/right × aspect` | 避免画面拉伸 |
| up 向量 | `camera.up.set(0, 0, -1)` | 俯视时必须修改，避免共线退化 |
| 更新投影 | `camera.updateProjectionMatrix()` | 改参数后必须调用 |
| 相机切换 | `renderer.render(scene, activeCamera)` | 用变量切换渲染目标 |
| 与阴影相机的关系 | `DirectionalLight.shadow.camera` | 本质相同，都是正交投影 |
| OrbitControls 缩放 | `camera.zoom` | 正交相机靠 zoom 缩放，非 position |
