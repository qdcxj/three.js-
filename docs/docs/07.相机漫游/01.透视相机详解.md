# 透视相机详解：PerspectiveCamera 的四个核心参数

人眼看到的世界是"近大远小"的——同样高的两棵树，近的那棵在视网膜上占的面积更大。`PerspectiveCamera`（透视相机）就是模拟这种效果的相机，它是 Three.js 中**使用频率最高**的相机类型，绝大多数 3D 场景都用它。本阶段我们的第一人称漫游相机就是一台 `PerspectiveCamera`。

## 一、为什么需要透视投影

3D 场景里的物体有三维坐标，但屏幕是二维的。把三维"压扁"到二维的过程叫**投影（Projection）**。投影方式有两种：

- **透视投影（Perspective）**：近大远小，符合人眼视觉，有纵深感
- **正交投影（Orthographic）**：没有近大远小，平行线永远平行，符合工程图纸

```
透视投影（近大远小）          正交投影（远近一样大）

      ◻ ← 近，大                  ◻    ◻    ◻
     ╱                              大小
    ╱                               相同
   ◻ ← 远，小
```

::: tip 哪种相机更常用
绝大多数游戏、产品展示、室内漫游都用**透视相机**，因为它符合人眼习惯。正交相机主要用于工程 CAD 视图、2.5D 等距游戏（如《暗黑破坏神》）、以及本阶段的鸟瞰俯视图。
:::

## 二、构造函数与四个参数

`PerspectiveCamera` 的构造函数接收四个参数：

```js
new THREE.PerspectiveCamera(fov, aspect, near, far)
```

| 参数 | 类型 | 说明 | 本阶段取值 |
|------|------|------|-----------|
| `fov` | Number | 垂直视野范围（Field of View），单位**度** | `50` |
| `aspect` | Number | 宽高比 = 渲染宽度 / 渲染高度 | `innerWidth / innerHeight` |
| `near` | Number | 近裁剪面距离（比这更近的物体被裁掉） | `0.1` |
| `far` | Number | 远裁剪面距离（比这更远的物体被裁掉） | `200` |

本阶段漫游相机的创建代码：

```js
import * as THREE from "three";

// 透视相机（漫游用）：FOV 50°，宽高比跟随窗口，近 0.1m，远 200m
const roamCamera = new THREE.PerspectiveCamera(
  50,                                  // fov：垂直视野 50°
  window.innerWidth / window.innerHeight, // aspect：宽高比
  0.1,                                 // near：0.1 米内的物体看不见
  200                                  // far：200 米外的物体看不见
);
// 相机起始位置：门口正前方 6m，人眼高度 1.6m
roamCamera.position.set(0, 1.6, 6);
roamCamera.lookAt(0, 1.6, 0); // 看向房子内部
```

下面逐一拆解这四个参数。

## 三、fov：视野范围（最关键的参数）

`fov`（Field of View）是相机**垂直方向**的视野角度，单位是度。它决定了你能"看到多宽"的世界：

```
              fov 角度
             ╱  ╲
            ╱    ╲
           ╱  相机 ╲
          ╱    ●    ╲
         ╱    /│\    ╲
        ╱   /  │  \   ╲
       ╱  /    │    \  ╲
      ╱ /      │      \ ╲
     ─────────────────────
     ←  能看到的范围  →
```

| fov 值 | 效果 | 适用场景 |
|--------|------|----------|
| 30°~45° | 窄视野，"望远镜"感，物体显得更近 | 人像摄影、产品特写 |
| 50°~60° | 中等视野，接近人眼舒适区 | **通用 3D 场景（本阶段用 50°）** |
| 75°~90° | 宽视野，"广角"感，边缘畸变明显 | 第一人称射击游戏、室内 |
| 100°+ | 超广角，鱼眼效果，畸变严重 | 特殊艺术效果 |

::: warning fov 不是越大越好
新手常犯的错：想让"看得更多"就把 `fov` 调到 90°+。结果画面边缘严重拉伸变形，直线变弯，物体比例失真。本阶段用 50°，既保证视野足够，又没有明显畸变。
:::

::: tip fov 是垂直方向
`fov` 是**垂直**方向的视野角度。水平方向的视野由 `fov` 和 `aspect` 共同决定。所以宽屏（aspect > 1）水平视野更宽，竖屏（aspect < 1）垂直视野相对更窄。
:::

## 四、aspect：宽高比

`aspect` 是渲染区域的宽高比（宽度 / 高度）。它必须与画布的实际宽高比一致，否则画面会**拉伸变形**：

```js
// 正确：aspect 与画布一致
const aspect = window.innerWidth / window.innerHeight;
camera.aspect = aspect;

// 错误：aspect 固定为 16/9，但窗口被拉成竖屏 → 画面变形
camera.aspect = 16 / 9;
```

窗口大小变化时（用户拖拽浏览器窗口、或全屏切换），必须更新 `aspect` 并调用 `updateProjectionMatrix()`：

```js
import * as THREE from "three";

// resize 处理函数
function handleResize() {
  const w = window.innerWidth;
  const h = window.innerHeight;
  // 更新 aspect
  camera.aspect = w / h;
  // 关键：必须调用 updateProjectionMatrix 让新参数生效！
  camera.updateProjectionMatrix();
  // 同步更新渲染器尺寸
  renderer.setSize(w, h);
}
window.addEventListener("resize", handleResize);
```

::: warning 忘记 updateProjectionMatrix 的坑
修改了 `fov` / `aspect` / `near` / `far` 任何一个参数后，**必须**调用 `camera.updateProjectionMatrix()`。否则画面不会更新——相机内部缓存的投影矩阵还是旧值。这是新手最常踩的坑之一。
:::

## 五、near 与 far：裁剪面

`near` 和 `far` 定义了相机的**可见深度范围**。只有在这个范围内的物体才会被渲染：

```
        near              far
         │                 │
    ─────●─────────────────●─────→ 视线方向
   裁掉  │   可见区域      │  裁掉
  (太近) │                 │ (太远)
```

- `near`：比这个距离更近的物体被裁掉（避免相机内部的物体挡住全部视线）
- `far`：比这个距离更远的物体被裁掉（控制渲染距离，提升性能）

本阶段取 `near=0.1`、`far=200`：0.1m 内的东西看不到（人眼不会贴到 10cm 内），200m 外的草地边缘也看不到（草地 40×40，对角线约 56m，200m 足够覆盖）。

::: warning near 不能太小
新手常犯的错：把 `near` 设成 `0.0001` 想要"看到所有近处物体"。这会导致**深度缓冲精度下降**（Z-fighting）：两个距离很近的物体会出现闪烁、表面交替显示。`near` 一般取 `0.1` 到 `1` 就够了。
:::

::: tip far 与性能
`far` 越大，渲染的物体越多，性能消耗越大。但更重要的是 `far / near` 的比值——比值越大，深度精度越差。本阶段 `200 / 0.1 = 2000`，在合理范围内。如果场景需要 `near=0.01` 又 `far=10000`，就需要用对数深度缓冲（`logarithmicDepthBuffer: true`）。
:::

## 六、position 与 lookAt

创建相机后，需要设置它的**位置**和**朝向**：

```js
import * as THREE from "three";

// 方式 1：position.set + lookAt
camera.position.set(12, 8, 12); // 相机位置
camera.lookAt(0, 0, 0);          // 看向原点

// 方式 2：单独设置分量
camera.position.x = 12;
camera.position.y = 8;
camera.position.z = 12;
camera.lookAt(0, 1.5, 0); // 看向房子中部

// 方式 3：用 copy 复制其他位置
const target = new THREE.Vector3(0, 1.5, 0);
camera.position.set(12, 8, 12);
camera.lookAt(target);
```

`lookAt(x, y, z)` 让相机的**视线方向**指向目标点。注意：调用 `lookAt` 后相机的 `up` 方向（默认 `(0,1,0)`，即 Y 轴向上）保持不变，相机会绕 up 轴旋转到对准目标。

::: tip lookAt 与 OrbitControls 的关系
`OrbitControls` 内部就是用 `camera.position`（绕 target 旋转）+ `camera.lookAt(target)` 实现的。所以手动设置 `position` + `lookAt` 后，再创建 `OrbitControls`，控制器会以当前 `position` 为起点继续旋转。
:::

## 七、本阶段漫游相机的完整配置

下面是本阶段 `HouseScene.vue` 中漫游相机的完整配置，包含 resize 处理：

```js
import * as THREE from "three";

// ===== 创建透视相机（漫游用）=====
const roamCamera = new THREE.PerspectiveCamera(
  50,                                      // fov：50°，接近人眼舒适区
  window.innerWidth / window.innerHeight,  // aspect：跟随窗口
  0.1,                                     // near：0.1m
  200                                      // far：200m
);
// 起始位置：门口前 6m，人眼高度 1.6m
roamCamera.position.set(0, 1.6, 6);
roamCamera.lookAt(0, 1.6, 0);

// ===== resize 处理：更新 aspect + 投影矩阵 =====
function handleResize() {
  const w = window.innerWidth;
  const h = window.innerHeight;
  roamCamera.aspect = w / h;
  roamCamera.updateProjectionMatrix(); // 关键！
  renderer.setSize(w, h);
}
window.addEventListener("resize", handleResize);
```

::: tip 为什么人眼高度是 1.6m
现实中成年人眼高度约 1.5~1.8m，取 1.6m 作为漫游相机的 Y 坐标，让第一人称视角接近真实身高。门洞高 2.0m，相机 1.6m，进门时不会觉得门太矮或太高。
:::

## 八、透视相机的视锥体

四个参数 `fov` / `aspect` / `near` / `far` 共同定义了一个**视锥体（Frustum）**——一个被截掉尖顶的四棱锥。只有在视锥体内的物体才会被渲染：

```
            相机 ●
           ╱    │    ╲
          ╱     │     ╲
         ╱  near│      ╲
        ╱───┐   │   ┌───╲
       ╱    │   │   │    ╲
      ╱     │   │   │     ╲
     ╱──────┴───│───┴──────╲
              far
        （视锥体俯视图）
```

Three.js 提供了 `CameraHelper` 可视化这个视锥体，调试时非常有用：

```js
import * as THREE from "three";

// 可视化相机的视锥体（调试用，正式发布时移除）
const cameraHelper = new THREE.CameraHelper(roamCamera);
scene.add(cameraHelper);
```

::: warning 视锥体裁剪的性能意义
Three.js 默认开启**视锥体裁剪（Frustum Culling）**：不在视锥体内的物体不会被渲染。这意味着即使场景里有 1000 个物体，相机看不到的会被自动跳过。所以 `far` 设得再大，看不到的物体也不消耗渲染性能（只消耗深度精度）。
:::

## 九、本节总结

| 知识点 | 关键 API | 说明 |
|--------|---------|------|
| 创建透视相机 | `new THREE.PerspectiveCamera(fov, aspect, near, far)` | 模拟人眼近大远小 |
| 视野范围 | `fov`（度） | 垂直视野，50° 最通用，过大畸变 |
| 宽高比 | `aspect = w / h` | 必须与画布一致，否则变形 |
| 近裁剪面 | `near` | 太小导致 Z-fighting，建议 0.1~1 |
| 远裁剪面 | `far` | far/near 比值影响深度精度 |
| 更新投影 | `camera.updateProjectionMatrix()` | 改参数后必须调用 |
| 相机位置 | `camera.position.set(x, y, z)` | 决定视点 |
| 相机朝向 | `camera.lookAt(x, y, z)` | 决定看向哪里 |
| 视锥体 | `CameraHelper(camera)` | 调试可视化的裁剪范围 |
