# 📷 第 07 阶段：相机漫游

> 走到第 07 阶段，我们的小屋已经盖好了屋顶、装好了门板、点亮了室内灯——但一直以来，我们只能站在固定位置用 `OrbitControls` 绕着房子转。本阶段要解决的核心问题是：**如何让相机真正"走进"房子？** 我们会同时配置两台相机（透视 + 正交）、两套控制器（OrbitControls + PointerLockControls），实现"鸟瞰俯视整栋小屋"与"第一人称走入室内参观"的一键切换。

## 🎯 建造目标

| # | 构件 | 关键参数 | 说明 |
|---|------|----------|------|
| 1 | 透视相机（漫游用） | PerspectiveCamera(50, aspect, 0.1, 200) | 第一人称视角，FOV 50°，初始位于门口前 (0, 1.6, 6) |
| 2 | 正交相机（鸟瞰用） | OrthographicCamera(±15·aspect, ±15, 0.1, 200) | 从 (0, 30, 0) 俯视，视景体覆盖整栋房子 |
| 3 | OrbitControls（鸟瞰控制器） | enableDamping, target(0,1.5,0) | 默认模式：拖拽旋转、滚轮缩放 |
| 4 | PointerLockControls（漫游控制器） | WASD 移动 + 鼠标转头 | 按 F 进入第一人称，指针锁定后鼠标控制视角 |
| 5 | 模式切换 | G 键 / F 键 / ESC | G→鸟瞰，F→第一人称，ESC→自动退出指针锁回鸟瞰 |
| 6 | WASD 键盘控制 | keydown/keyup + 渲染循环更新 | 速度 5m/s，用 Clock.delta 保证帧率无关 |
| 7 | 操作提示 UI | 绝对定位 div + Element Plus 配色 | 左下角显示当前模式与按键说明 |

到本阶段末，打开页面默认是**鸟瞰模式**：从正上方俯视小屋，可以拖拽旋转、滚轮缩放。按下 **F** 键，浏览器进入指针锁定，相机瞬移到门口前的人眼高度，移动鼠标转头、按 WASD 走进房子参观。按下 **G** 或 **ESC** 回到鸟瞰。

## 📚 学习目标

完成本阶段后，你应当能够：

- **理解透视相机与正交相机的本质区别**：透视有"近大远小"，正交没有；知道何时该用哪种
- **手写 PerspectiveCamera 的四个核心参数**：`fov` / `aspect` / `near` / `far`，并理解它们对画面的影响
- **手写 OrthographicCamera 的六个参数**：`left` / `right` / `top` / `bottom` / `near` / `far`，并配合 `aspect` 避免拉伸
- **同时管理多台相机与多套控制器**：用 `activeCamera` 变量切换渲染目标，用 `enabled` 开关控制器
- **实现 PointerLockControls 第一人称漫游**：指针锁定 API、WASD 键盘状态机、`moveForward`/`moveRight` 移动
- **写出帧率无关的移动逻辑**：用 `Clock.getDelta()` 计算位移，60fps 和 30fps 移动距离一致
- **完整释放相机系统的资源**：dispose 两台 controls、移除键盘监听

::: tip 浏览器安全提示
第一人称模式使用浏览器的 **Pointer Lock API**（指针锁定），需要用户主动触发（按键或点击）。部分浏览器在退出指针锁后会有约 1 秒的"冷却期"，期间无法立即重新锁定。这是浏览器安全策略，不是 Bug。如果按 F 没反应，等 1 秒再试。
:::
