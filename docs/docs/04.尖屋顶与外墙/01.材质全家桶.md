# 材质全家桶：Three.js 的 8 种材质一次看懂

给屋顶盖瓦、给外墙刷漆、给烟囱上石材质感——这些视觉表现都靠**材质（Material）**完成。Three.js 内置了 8 类材质，从"完全不受光"的 `MeshBasicMaterial`，到"基于物理真实"的 `MeshPhysicalMaterial`，再到"自己写 GLSL 着色器"的 `ShaderMaterial`，每一种都对应一类使用场景。

本节不深入每种材质的属性细节（那是 [03. 外墙 PBR 材质](./03.外墙PBR材质) 小节的任务），而是给你一张**全家族合影**：8 种材质怎么排、怎么选、性能差多少。学完本节，你会知道为什么小屋的外墙用 `MeshStandardMaterial` 而不是 `MeshBasicMaterial`，以及 stage-04 草地远处那排对比球的含义。

## 一、8 种材质全家族对比表

下表把 8 种材质的核心维度拉平对比，建议先扫一遍建立全局印象：

| # | 材质类 | 受光照 | 真实感 | 性能开销 | 典型用途 | 小屋中的用途 |
|---|--------|:------:|:------:|:--------:|----------|--------------|
| 1 | `MeshBasicMaterial` | ❌ | 最低 | 最低 | UI 元素、线框调试、天空盒、扁平占位 | （暂未使用） |
| 2 | `MeshLambertMaterial` | ✅ 漫反射 | 低 | 低 | 纸张、布料、未抛光木材、低多边形风格 | （备选外墙） |
| 3 | `MeshPhongMaterial` | ✅ 漫反射 + 镜面高光 | 中 | 中 | 塑料、陶瓷、抛光金属、光泽表面 | （备选门板） |
| 4 | `MeshStandardMaterial` | ✅ PBR（金属度+粗糙度） | 高 | 中高 | 现代 PBR 渲染、glTF 模型默认 | **外墙、屋顶、烟囱、地板、门** |
| 5 | `MeshPhysicalMaterial` | ✅ PBR 扩展（清漆/透射/虹彩） | 最高 | 高 | 车漆、玻璃、肥皂泡、虹彩薄膜 | （后续玻璃窗会用） |
| 6 | `MeshNormalMaterial` | ❌（按法线着色） | 调试用 | 中 | 调试法线方向、可视化几何法线 | 调试用 |
| 7 | `MeshShaderMaterial` | 自定义 | 完全可控 | 视代码而定 | 自定义 GLSL 渲染特效、特殊视觉 | （stage-10 着色器章节） |
| 8 | `PointsMaterial` / `SpriteMaterial` | ✅/❌ | 粒子专用 | 低 | 粒子系统（雨/雪/星空）、始终面向相机的 2D 标签 | （stage-12 烟囱粒子） |

::: tip 编号说明
表中前 6 种是 **Mesh 系**材质（必须搭配 `Mesh` + 几何体使用），第 7 种 `MeshShaderMaterial` 也是 Mesh 系（自定义着色器），第 8 种是 **粒子/精灵系**（搭配 `Points` 或 `Sprite` 使用，不能用普通 `Mesh`）。
:::

## 二、按"是否受光照"分类

理解材质最直观的轴是**光照响应**——同一个蓝色球，在不同材质下呈现完全不同的视觉效果：

### 1. 完全不受光照：MeshBasicMaterial / MeshNormalMaterial

```js
import * as THREE from "three";

// 1. MeshBasicMaterial：恒定颜色，无视灯光
const basicMat = new THREE.MeshBasicMaterial({ color: 0x409eff });

// 6. MeshNormalMaterial：把顶点法线方向映射成 RGB 颜色（调试用）
const normalMat = new THREE.MeshNormalMaterial();
```

- `MeshBasicMaterial`：场景里有没有灯都一样亮，最适合做 HUD 标签、线框调试、天空盒贴图载体
- `MeshNormalMaterial`：颜色随法线方向变化，紫色/绿色/红色斑斓，**只用于调试几何法线**，不是正式材质

::: warning BasicMaterial 的坑
用 `MeshBasicMaterial` 渲染的物体没有立体感——它是一片"扁平色块"。如果你给小屋外墙用 Basic，看起来就像贴纸，没有任何光影层次。除了天空盒和 UI，正式材质请务必用受光照的材质。
:::

### 2. 经验光照模型：Lambert / Phong

这两个材质用**经验公式**模拟光照，不追求物理真实，但计算快：

```js
// 2. MeshLambertMaterial：纯漫反射，无高光（哑光）
const lambertMat = new THREE.MeshLambertMaterial({ color: 0x409eff });

// 3. MeshPhongMaterial：漫反射 + 镜面高光（有光泽）
const phongMat = new THREE.MeshPhongMaterial({
  color: 0x409eff,
  shininess: 100, // 高光锐度，越大高光越小越亮
  specular: 0x333333, // 高光颜色
});
```

- `MeshLambertMaterial`：表面粗糙、漫反射为主，没有镜面高光斑点。适合纸张、未抛光木材、粉刷墙面、低多边形美术风格
- `MeshPhongMaterial`：在 Lambert 基础上加镜面高光，能看到光斑。适合塑料、陶瓷、抛光金属。`shininess` 控制高光锐度

### 3. PBR 物理材质：Standard / Physical

**PBR（Physically Based Rendering，基于物理的渲染）** 是现代 3D 渲染的主流，用真实物理参数描述材质，跨引擎（Unity/Unreal/Blender）通用：

```js
// 4. MeshStandardMaterial：PBR 金属度+粗糙度工作流
const standardMat = new THREE.MeshStandardMaterial({
  color: 0x409eff, // 漫反射颜色（非金属）或反射率（金属）
  metalness: 0.5, // 金属度 0~1：0=电介质(塑料/木材)，1=纯金属
  roughness: 0.4, // 粗糙度 0~1：0=镜面光滑，1=完全哑光
});

// 5. MeshPhysicalMaterial：在 Standard 基础上扩展
const physicalMat = new THREE.MeshPhysicalMaterial({
  color: 0x409eff,
  metalness: 0.5,
  roughness: 0.3,
  clearcoat: 1.0, // 清漆层强度 0~1（车漆/钢琴漆）
  clearcoatRoughness: 0.1, // 清漆层粗糙度
  // 还有 transmission（透射，做玻璃）、ior（折射率）、sheen（绒毛）等
});
```

- `MeshStandardMaterial`：**本阶段外墙/屋顶/烟囱/地板/门全用它**。PBR 主流，glTF 模型默认材质，跨引擎通用
- `MeshPhysicalMaterial`：Standard 的"豪华版"，多了清漆层、透射、虹彩等高级属性。本阶段先在材质对比球里露个脸，stage-05 玻璃窗会真正用到

### 4. 自定义着色器：MeshShaderMaterial

```js
// 7. MeshShaderMaterial：完全自定义 GLSL 顶点+片元着色器
const shaderMat = new THREE.ShaderMaterial({
  uniforms: { uTime: { value: 0 } },
  vertexShader: `
    varying vec3 vPos;
    void main() {
      vPos = position;
      gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
    }
  `,
  fragmentShader: `
    varying vec3 vPos;
    uniform float uTime;
    void main() {
      gl_FragColor = vec4(vPos * 0.5 + 0.5, 1.0);
    }
  `,
});
```

完全自定义渲染逻辑，能力最强但需要 GLSL 基础。本教程 stage-10 着色器章节会专门讲，本阶段不深入。

### 5. 粒子/精灵：PointsMaterial / SpriteMaterial

```js
// 8. PointsMaterial + Points：粒子系统（每个顶点是一个小方块）
const pointsMat = new THREE.PointsMaterial({
  color: 0xffffff,
  size: 0.1,
  sizeAttenuation: true, // 远近粒子大小不同
});
const points = new THREE.Points(geometry, pointsMat);

// SpriteMaterial + Sprite：始终面向相机的 2D 标签
const spriteMat = new THREE.SpriteMaterial({ map: texture });
const sprite = new THREE.Sprite(spriteMat);
```

这两个材质不能搭配普通 `Mesh`，是粒子系统和精灵专用。stage-12 烟囱冒烟会用 `PointsMaterial`，stage-09 家具标签可能用 `SpriteMaterial`。

## 三、材质选型决策树

下面这张决策树是本阶段选材质的核心方法论，建议背下来：

```
渲染什么物体？
├── 调试几何 / 法线
│   └── MeshNormalMaterial（看法线方向，调几何用）
├── UI / 线框 / 天空盒 / 扁平占位
│   └── MeshBasicMaterial（最快，不受光）
├── 粒子 / 始终面向相机的 2D
│   ├── 大量粒子 → PointsMaterial + Points
│   └── 单个标签 → SpriteMaterial + Sprite
├── 需要自定义特效（波纹/渐变/扭曲）
│   └── ShaderMaterial（自己写 GLSL）
└── 普通 3D 物体表面
    ├── 不追求真实感（低多边形、卡通风格）
    │   ├── 无高光 → MeshLambertMaterial（纸张/木材/布料）
    │   └── 有高光 → MeshPhongMaterial（塑料/陶瓷）
    └── 追求真实感（PBR 主流）
        ├── 普通材质 → MeshStandardMaterial（金属度+粗糙度）
        └── 高级材质 → MeshPhysicalMaterial（清漆/玻璃/虹彩）
```

::: tip 性能排序（从快到慢）
`Basic ≈ Lambert < Phong < Standard < Physical < ShaderMaterial`。手机端或大量物体时，能用 Lambert 就别用 Standard；能用 Standard 就别用 Physical。`PhysicalMaterial` 比 `StandardMaterial` 慢约 20%~30%，只在需要清漆/透射等高级属性时才用。
:::

## 四、本阶段材质对比球实战

为了让你**亲眼看到** 5 种受光材质的差异，stage-04 在草地远处放了一排对比球。共用 `SphereGeometry(0.5, 32, 32)`，统一蓝色 `#409eff`，只有材质不同：

```js
import * as THREE from "three";

// 共用球体几何
const sphereGeo = new THREE.SphereGeometry(0.5, 32, 32);
const COLOR = 0x409eff; // Element Plus 主色

// 5 种材质定义
const materials = [
  // 1. MeshBasicMaterial：不受光，恒亮（参考基准）
  new THREE.MeshBasicMaterial({ color: COLOR }),
  // 2. MeshLambertMaterial：漫反射，无高光（哑光球）
  new THREE.MeshLambertMaterial({ color: COLOR }),
  // 3. MeshPhongMaterial：镜面高光（高光斑点清晰）
  new THREE.MeshPhongMaterial({
    color: COLOR,
    shininess: 100,
    specular: 0x333333,
  }),
  // 4. MeshStandardMaterial：PBR 金属感（高光柔和过渡）
  new THREE.MeshStandardMaterial({
    color: COLOR,
    metalness: 0.5,
    roughness: 0.4,
  }),
  // 5. MeshPhysicalMaterial：PBR + 清漆层（额外一层亮漆反光）
  new THREE.MeshPhysicalMaterial({
    color: COLOR,
    metalness: 0.5,
    roughness: 0.3,
    clearcoat: 1.0,
    clearcoatRoughness: 0.1,
  }),
];

// 排成一排，x 从 7 到 13，间隔 1.5
const startX = 7;
const gap = 1.5;
materials.forEach((mat, i) => {
  const sphere = new THREE.Mesh(sphereGeo, mat);
  sphere.position.set(startX + i * gap, 0.5, -6);
  scene.add(sphere);
});
```

启动 `npm run dev` 后，绕到房子右后方草地（坐标 x≈7~13, z=-6），你会看到从左到右：

1. **Basic 球**：一片纯蓝，无视灯光，像贴纸
2. **Lambert 球**：蓝色但背光面发暗，无高光斑点，像粉刷球
3. **Phong 球**：蓝色 + 一个清晰亮白高光点，像塑料球
4. **Standard 球**：蓝色 + 金属反光感，高光过渡柔和，像金属球
5. **Physical 球**：Standard 基础上多一层"亮漆"，更通透，像车漆球

::: tip 为什么材质对比球放在草地远处？
材质对比球是教学辅助物，不是房子的一部分。放在草地远处（x=7~13, z=-6）既能让你绕过去仔细观察，又不会喧宾夺主影响小屋整体视觉。stage-05 起会移除对比球，专注小屋本身。
:::

## 五、本阶段小屋的材质分配

回到小屋本身。本阶段所有构件统一用 `MeshStandardMaterial`（PBR），这是 glTF 模型默认材质，跨引擎通用，性能也够用。具体分配：

| 构件 | 材质 | color | metalness | roughness | 选型理由 |
|------|------|-------|:---------:|:---------:|----------|
| 草地 | MeshStandardMaterial | #67c23a | 0.0 | 1.0 | 完全哑光，自然 |
| 地基 / 台阶 | MeshStandardMaterial | #909399 | 0.0 | 0.9 | 石材，粗糙 |
| 外墙 | MeshStandardMaterial | #e6d5b8 | 0.0 | 0.9 | 暖米色墙面，未抛光 |
| 木门 | MeshStandardMaterial | #8b5a2b | 0.0 | 0.6 | 木头有轻微光泽 |
| 屋顶瓦 | MeshStandardMaterial | #a0522d | 0.0 | 0.8 | 砖红瓦面，半粗糙 |
| 烟囱 | MeshStandardMaterial | #909399 | 0.0 | 0.95 | 砖石烟囱，最粗糙 |
| 室内地板 | MeshStandardMaterial | #d2b48c | 0.0 | 0.7 | 浅木色地板 |

可以看出，本阶段所有材质 `metalness` 都是 0（没有金属物体），靠 `roughness` 区分粗糙程度：草地最粗糙（1.0），木门最光滑（0.6）。stage-05 会换上砖墙贴图、木纹贴图，stage-06 加灯光阴影后，PBR 的真实感会完全展现。

::: warning metalness 的常见误用
新手常犯的错：想让物体"亮一点"就把 `metalness` 调高。这是错的——`metalness` 不是亮度，是金属度。木头、塑料、石材都应该 `metalness: 0`；只有金属（铁、铜、金）才设 `1`。**非金属物体 metalness 不为 0 会导致颜色失真**（材质会变黑、反射环境光过强）。
:::

## 六、本节总结

- Three.js 有 8 类材质：6 种 Mesh 系 + 1 种 ShaderMaterial + 2 种粒子系（PointsMaterial/SpriteMaterial）
- **是否受光照**是选材质的第一轴：Basic/Normal 不受光，Lambert/Phong/Standard/Physical 受光
- **是否 PBR**是第二轴：Lambert/Phong 是经验模型（快但不真实），Standard/Physical 是物理模型（真实但慢）
- 本阶段小屋所有构件统一用 `MeshStandardMaterial`（PBR 主流），靠 `roughness` 区分材质粗糙度
- 草地远处的 5 个对比球直观展示了 5 种材质在同一光照下的视觉差异
- 选型决策树：调试→Normal；UI→Basic；粒子→Points/Sprite；自定义→Shader；普通物体→Standard（追求真实）或 Lambert/Phong（追求性能）
