# 搭建尖屋顶：双坡顶几何与 rotateZ 推导

欧式乡村小屋的标志特征是**人字形双坡顶（Gable Roof）**——从正面看，屋顶是一个三角形山墙，两侧斜面像翻开的书页向左右延伸。本节我们就用 2 块倾斜的 `BoxGeometry` 拼出这个造型，再用 `Shape + ExtrudeGeometry` 把前后两端的三角形空隙封堵上。

本节最难的不是 API，而是**几何推导**：屋脊要顶到 y=5.0，墙顶在 y=3.3，那块倾斜板到底要绕哪个轴、旋转多少弧度、放在哪个坐标？我们一步步算清楚。

## 一、欧式屋顶的两种朝向

在动手前先明确朝向。HOUSE_SPEC 说我们的房子墙宽 8m（X 方向）、墙深 6m（Z 方向）、门朝 +Z。屋顶有两种摆法：

| 朝向 | 屋脊方向 | 跨度方向 | 山墙位置 | 视觉特征 |
|------|----------|----------|----------|----------|
| **方案 A：屋脊沿 X** | 屋脊沿长边 X | 跨度沿 Z（6m） | 左右两侧 X± | 从正面（+Z）看是檐口 |
| **方案 B：屋脊沿 Z** | 屋脊沿短边 Z | 跨度沿 X（8m） | 前后两端 Z± | 从正面（+Z）看是山墙 |

**我们采用方案 B**——屋脊沿 Z 方向，前后两端是三角形山墙。理由有三：

1. **视觉**：从门正面看就能看到三角形山墙，这是欧式乡村小屋最经典的造型
2. **自洽**：HOUSE_SPEC 第 27 行写"尖屋顶 8(X) × 6(Z)"，意味着 X 方向 8m（跨度，与墙宽一致）、Z 方向 6m（屋脊长，与墙深一致）——这恰好对应方案 B
3. **几何正确**：方案 B 下 `rotateZ` 才是正确的旋转轴（屋脊沿 Z，斜面在 XY 平面内倾斜）

::: tip 屋顶整体中心
HOUSE_SPEC 第 27 行还写"屋顶位置 (0, 4.15, 0)"——这个 (0, 4.15, 0) 是屋顶**整体中心**。我们后面会推导出单坡板的中心在 (±2, 4.15, 0)，两块板的中心 Y 坐标都是 4.15，与规格完全吻合。
:::

## 二、屋顶几何参数精确推导

这是本节最关键的部分。已知：

- 屋脊点 `(0, 5.0, 0)`（HOUSE_SPEC 强制要求顶高 y=5.0）
- 屋檐高度 = 墙顶 y = 3.3（墙高 3m，中心 y=1.8，所以墙顶 1.8+1.5=3.3）
- 半跨度 X = 4m（墙宽 8m 的一半）
- 屋脊长度 Z = 6m（与墙深一致，加出挑 0.3m×2 = 6.6m）

推导：

```
高度差 H  = 5.0 - 3.3         = 1.7 m
半跨度 W  = 4.0 m
坡度角 θ  = arctan(H / W)     = arctan(1.7 / 4) ≈ 0.4014 rad ≈ 23.04°
斜坡长 L  = sqrt(W² + H²)     = sqrt(16 + 2.89) = sqrt(18.89) ≈ 4.347 m
```

**单坡板的尺寸**：板沿斜坡方向长 L=4.347m，板厚 0.2m，板沿屋脊方向长 6.6m（含出挑）。所以 `BoxGeometry(L, 0.2, ridgeLen)` = `BoxGeometry(4.347, 0.2, 6.6)`。

**单坡板的中心位置**：屋脊 (0, 5, 0) 与左屋檐 (-4, 3.3, 0) 的中点 = `(-2, 4.15, 0)`。右坡对称，中心 `(2, 4.15, 0)`。两块板 Y 坐标都是 4.15 ✓ 与规格吻合。

**旋转角度**：板原始水平放置（板宽沿 X），需要把 +X 边（屋脊边）抬到 y=5.0、-X 边（屋檐边）压到 y=3.3。这等价于绕 Z 轴旋转 +θ（左手定则：从 +Z 看，逆时针旋转抬升 +X 边）。所以 `rotation.z = θ = arctan(1.7/4)`。

::: tip rotateZ 为什么有效
`rotateZ` 让物体在 XY 平面内旋转（X 和 Y 变化，Z 不变）。我们的屋顶斜面正好在 XY 平面倾斜（屋脊沿 Z 不变），所以用 `rotateZ` 是几何正确的选择。如果屋脊沿 X 方向（方案 A），就要用 `rotateX` 了。
:::

## 三、左坡板代码实现

把上面推导的参数填进代码：

```js
import * as THREE from "three";

// ---- 屋顶几何参数（精确推导）----
const ridgeY = 5.0; // 屋脊高度
const eaveY = 3.3; // 屋檐高度（= 墙顶）
const halfSpan = 4.0; // 半跨度 X
const ridgeLen = 6.6; // 屋脊长度 Z（墙深 6m + 出挑 0.3m×2）
const slopeLen = Math.sqrt(halfSpan * halfSpan + (ridgeY - eaveY) ** 2); // ≈ 4.347
const slopeAngle = Math.atan((ridgeY - eaveY) / halfSpan); // ≈ 0.4014 rad ≈ 23.04°

// 屋顶材质：砖红瓦 #a0522d，粗糙瓦面
const roofMat = new THREE.MeshStandardMaterial({
  color: 0xa0522d,
  roughness: 0.8,
  metalness: 0.0,
  side: THREE.DoubleSide, // 双面渲染（屋檐下也能看见）
});

// 左坡板：宽 4.347（沿斜坡），厚 0.2，长 6.6（沿屋脊 Z）
const leftRoof = new THREE.Mesh(
  new THREE.BoxGeometry(slopeLen, 0.2, ridgeLen),
  roofMat
);
leftRoof.position.set(-2, 4.15, 0); // 屋脊与左屋檐中点
leftRoof.rotation.z = slopeAngle; // 绕 Z 轴正方向旋转
houseGroup.add(leftRoof);
```

`side: THREE.DoubleSide` 是关键——双坡顶板是薄片，从屋檐下方（室内抬头）会看到板的背面。如果用默认的 `FrontSide`，背面会被剔除（看不见），所以必须双面渲染。

::: warning DoubleSide 的性能代价
`DoubleSide` 比 `FrontSide` 慢约 10%~20%（GPU 要渲染两面）。薄片物体（屋顶、树叶、平面）必须用；封闭实体（立方体墙、球）保持默认 `FrontSide` 即可。
:::

## 四、右坡板：对称

右坡板是左坡的镜像，位置 X 取正、旋转角度取负：

```js
// 右坡板：对称
const rightRoof = new THREE.Mesh(
  new THREE.BoxGeometry(slopeLen, 0.2, ridgeLen),
  roofMat
);
rightRoof.position.set(2, 4.15, 0); // 屋脊与右屋檐中点
rightRoof.rotation.z = -slopeAngle; // 反向倾斜
houseGroup.add(rightRoof);
```

两块板在屋脊 (0, 5, 0) 处对接，组成人字形。视觉上会看到一片砖红色的 V 字形顶盖。

## 五、前后山墙：Shape + ExtrudeGeometry

两块坡板盖上去后，前后两端（Z=±3 墙顶上方）会留下**三角形空隙**——从正面看就是一个三角形洞。我们需要用三角形把它封堵上，这就是**山墙（Gable）**。

### 5.1 用 Shape 定义 2D 三角形

`THREE.Shape` 是 2D 路径，可以定义任意 2D 形状。我们定义一个底 8m、高 1.7m 的等腰三角形：

```js
// 山墙三角形：底 8m（沿 X 从 -4 到 4），高 1.7m（从墙顶 3.3 到屋脊 5.0）
const gableShape = new THREE.Shape();
gableShape.moveTo(-4, 0); // 左下角
gableShape.lineTo(4, 0); // 右下角
gableShape.lineTo(0, 1.7); // 顶点（相对高度 1.7m）
gableShape.lineTo(-4, 0); // 闭合回起点
```

### 5.2 用 ExtrudeGeometry 挤压成 3D

`ExtrudeGeometry` 把 2D Shape 沿 +Z 方向挤压成有厚度的 3D 物体：

```js
const gableGeo = new THREE.ExtrudeGeometry(gableShape, {
  depth: 0.2, // 沿 +Z 挤压 0.2m（与墙厚一致）
  bevelEnabled: false, // 不做倒角，保持锋利边缘
});

// 山墙材质：与外墙一致 #e6d5b8
const gableMat = new THREE.MeshStandardMaterial({
  color: 0xe6d5b8,
  roughness: 0.9,
  metalness: 0.0,
  side: THREE.DoubleSide,
});
```

### 5.3 前后山墙定位

`ExtrudeGeometry` 默认挤压方向是 +Z，Shape 在 XY 平面（Y 向上）。挤压后三角形底边在 y=0、顶点在 y=1.7，沿 Z 占 0.2m。我们通过 `position` 把它移到墙顶：

```js
// 前山墙：z=3.0（与墙外表面齐平，墙厚 0.2 在 z∈[2.9, 3.1]）
const frontGable = new THREE.Mesh(gableGeo, gableMat);
frontGable.position.set(0, 3.3, 3.0); // 底边对齐墙顶 y=3.3
houseGroup.add(frontGable);

// 后山墙：z=-3.2（让 extrude 方向沿 +Z，三角形在 z∈[-3.2, -3.0]）
const backGable = new THREE.Mesh(gableGeo, gableMat);
backGable.position.set(0, 3.3, -3.2);
houseGroup.add(backGable);
```

前山墙 `position.z = 3.0`：三角形沿 Z 占 [3.0, 3.2]，正好贴在墙外表面（墙在 z∈[2.9, 3.1]）外侧 0.1m。
后山墙 `position.z = -3.2`：三角形沿 Z 占 [-3.2, -3.0]，贴在墙外表面（墙在 z∈[-3.1, -2.9]）外侧 0.1m。两侧山墙都略微凸出墙面，视觉上像"贴上去的三角装饰"。

::: tip 为什么前后山墙位置不对称（3.0 vs -3.2）
因为 `ExtrudeGeometry` 只能沿 +Z 挤压（不能反向）。前山墙在 +Z 侧，挤压方向正好朝外（+Z）；后山墙在 -Z 侧，挤压方向还是 +Z，所以要把 position.z 往负方向多退 0.2，让挤压出来的三角形落在 [-3.2, -3.0] 区间，外侧贴齐墙外表面。如果想让山墙完全居中在墙厚里，可以给后山墙单独建一个反向挤压的几何体，但代码会复杂——这点不对称肉眼几乎看不出，本阶段接受。
:::

## 六、完整屋顶代码

把上面三段拼起来，就是 `HouseScene.vue` 里 `addRoof()` 函数的完整内容：

```js
const addRoof = (houseGroup) => {
  // 屋顶材质：砖红瓦
  const roofMat = new THREE.MeshStandardMaterial({
    color: 0xa0522d,
    roughness: 0.8,
    metalness: 0.0,
    side: THREE.DoubleSide,
  });
  // 山墙材质：与外墙一致
  const gableMat = new THREE.MeshStandardMaterial({
    color: 0xe6d5b8,
    roughness: 0.9,
    metalness: 0.0,
    side: THREE.DoubleSide,
  });

  // 几何参数
  const ridgeY = 5.0;
  const eaveY = 3.3;
  const halfSpan = 4.0;
  const ridgeLen = 6.6;
  const slopeLen = Math.sqrt(halfSpan ** 2 + (ridgeY - eaveY) ** 2);
  const slopeAngle = Math.atan((ridgeY - eaveY) / halfSpan);

  // 左坡板
  const leftRoof = new THREE.Mesh(
    new THREE.BoxGeometry(slopeLen, 0.2, ridgeLen),
    roofMat
  );
  leftRoof.position.set(-2, 4.15, 0);
  leftRoof.rotation.z = slopeAngle;
  houseGroup.add(leftRoof);

  // 右坡板
  const rightRoof = new THREE.Mesh(
    new THREE.BoxGeometry(slopeLen, 0.2, ridgeLen),
    roofMat
  );
  rightRoof.position.set(2, 4.15, 0);
  rightRoof.rotation.z = -slopeAngle;
  houseGroup.add(rightRoof);

  // 山墙三角形 Shape
  const gableShape = new THREE.Shape();
  gableShape.moveTo(-4, 0);
  gableShape.lineTo(4, 0);
  gableShape.lineTo(0, 1.7);
  gableShape.lineTo(-4, 0);
  const gableGeo = new THREE.ExtrudeGeometry(gableShape, {
    depth: 0.2,
    bevelEnabled: false,
  });

  // 前后山墙
  const frontGable = new THREE.Mesh(gableGeo, gableMat);
  frontGable.position.set(0, 3.3, 3.0);
  houseGroup.add(frontGable);

  const backGable = new THREE.Mesh(gableGeo, gableMat);
  backGable.position.set(0, 3.3, -3.2);
  houseGroup.add(backGable);
};
```

## 七、验证：屋顶几何是否对齐？

把代码跑起来，绕到相机正面（+Z 方向看向房子），应当能看到：

- **正面山墙**：从墙顶 y=3.3 升到屋脊 y=5.0 的等腰三角形，底宽 8m，高 1.7m
- **左坡板**：从屋脊 (0, 5, 0) 斜向下到左屋檐 (-4, 3.3, 0)，砖红色
- **右坡板**：对称，从屋脊斜到右屋檐 (4, 3.3, 0)
- **屋脊对接**：两块板在 (0, 5, 0) 处严丝合缝（小误差 < 1cm 来自浮点运算）

如果发现屋脊有缝隙或重叠，检查这几个值：

| 症状 | 原因 | 修复 |
|------|------|------|
| 屋脊有明显缝隙 | `slopeLen` 算错 | 用 `Math.sqrt(16 + 2.89)` 而非 `4.347` 写死 |
| 屋顶太低/太高 | `slopeAngle` 算错 | 用 `Math.atan(1.7 / 4)` 而非猜角度 |
| 山墙悬空/下沉 | `gable.position.y` 不对 | 必须是 `3.3`（墙顶高度） |
| 山墙左右偏 | Shape 顶点不对称 | 三角形顶点必须 (-4,0)(4,0)(0,1.7) |

::: tip 浮点精度
本节所有数值（4.347, 0.4014, 4.15）都是 `Math.sqrt` 和 `Math.atan` 实时算出来的，不是写死的。这样调整屋脊高度时（比如改成 y=5.5），所有依赖量自动重算，不会出错。**永远用表达式而非字面量**，是 3D 编程的好习惯。
:::

## 八、本节总结

- 欧式双坡顶采用**方案 B**：屋脊沿 Z 方向，跨度沿 X，前后两端是山墙——这是正面山墙造型
- 屋顶几何 4 个关键参数：
  - 屋脊 y=5.0、屋檐 y=3.3、半跨度 X=4m、屋脊长 Z=6.6m
- 推导出：坡度角 `θ = arctan(1.7/4) ≈ 23.04°`、斜坡长 `≈ 4.347m`
- 单坡板：`BoxGeometry(4.347, 0.2, 6.6)`，`position(±2, 4.15, 0)`，`rotateZ(±θ)`
- 山墙三角形：`Shape` 定义底 8m 高 1.7m 等腰三角形，`ExtrudeGeometry` 挤压 0.2m 厚
- 屋顶板和山墙都用 `side: THREE.DoubleSide`（薄片必须双面渲染）
- 用表达式而非字面量传递尺寸参数，方便后续调整
