# 烟囱与室内地板：阶段收尾

屋顶盖好了、外墙刷好了，小屋的主体已经成型。本节我们补上最后两个构件——**烟囱**和**室内地板**——让小屋从"四面墙加顶"变成"有生活气息的家"。然后复盘本阶段的材质选型，对接下一阶段。

## 一、烟囱：BoxGeometry + 屋顶穿顶

欧式乡村小屋的烟囱是经典元素——冬天冒出袅袅白烟，象征着家里的壁炉正在燃烧。本阶段先做烟囱的"砖石结构"，stage-12 才会在烟囱顶上加粒子（白烟）。

### 1.1 烟囱尺寸与位置（HOUSE_SPEC）

```
构件    尺寸（m）             位置（中心）         颜色
烟囱    0.6×0.6×1.5 (X×Z×Y)  (2, 4.5, -1.5)      #909399 信息灰
```

- 尺寸：截面 0.6×0.6 平方米，高 1.5m（X、Z 是截面，Y 是高度）
- 位置：中心 (2, 4.5, -1.5)，立在右坡屋顶上方
- 颜色：信息灰 #909399，与地基一致（都是石材）

::: tip 为什么烟囱在 (2, 4.5, -1.5)
- X=2：在房子右半边（左右对称视觉舒服）
- Z=-1.5：在房子偏后方（远离门正面，烟囱靠后视觉更自然）
- Y=4.5：烟囱中心高度，烟囱高 1.5m，所以底部 y=3.75、顶部 y=5.25
- 右坡屋顶在 X=2 处的高度：y = 3.3 + (5.0-3.3) × (2/4) = 3.3 + 0.85 = 4.15
- 烟囱底部 y=3.75 < 屋顶表面 y=4.15，所以烟囱**穿过屋顶**伸出（顶部 y=5.25 高于屋脊 5.0）——这是烟囱的真实物理表现
:::

### 1.2 烟囱代码

```js
import * as THREE from "three";

// 烟囱材质：信息灰 #909399，最粗糙的砖石
const chimneyMat = new THREE.MeshStandardMaterial({
  color: 0x909399,
  roughness: 0.95, // 砖石最粗糙
  metalness: 0.0,
});

// 烟囱：BoxGeometry(X=0.6, Y=1.5, Z=0.6)
const chimney = new THREE.Mesh(
  new THREE.BoxGeometry(0.6, 1.5, 0.6),
  chimneyMat
);
chimney.position.set(2, 4.5, -1.5);
houseGroup.add(chimney);
```

烟囱看起来"穿过"屋顶——实际上 Three.js 没有自动遮挡或布尔运算，烟囱的几何体和屋顶的几何体在重叠区域都渲染了。视觉上从外面看，烟囱从屋顶表面伸出，底部被屋顶遮住，效果正确。如果想做真正的"开洞"烟囱，需要 CSG（构造实体几何）运算，本阶段不展开。

::: warning 烟囱底部漏空
从特定角度（比如屋顶下方仰视）可能看到烟囱底部浮在屋顶下方一段。这是无 CSG 的副作用——本阶段接受。stage-13 性能优化会讨论用 `StenciledGeometry` 或布尔运算挖洞。
:::

## 二、室内地板：铺在地基顶面

外墙已经围出了室内空间，但里面是空的——透过门洞能看到地基顶面（灰色石材）。本节铺一块浅木色地板，让室内看起来像"可以住人的家"。

### 2.1 地板尺寸与位置（HOUSE_SPEC）

```
构件       尺寸（m）              位置（中心）      颜色
室内地板   7.6×5.6×0.05 (X×Z×Y)   (0, 0.325, 0)    #d2b48c 浅木色
```

- 尺寸：7.6(X) × 5.6(Z) × 0.05(Y)。比室内空间略小（墙内壁 X=±3.9, Z=±2.9，所以室内净空 7.8×5.8，地板 7.6×5.6 留 0.1m 缝隙）
- 位置：(0, 0.325, 0)。地基顶 y=0.3，地板厚 0.05，所以中心 y=0.325
- 颜色：浅木色 #d2b48c，比木门略浅

### 2.2 地板代码

```js
// 室内地板材质：浅木色 #d2b48c
const floorMat = new THREE.MeshStandardMaterial({
  color: 0xd2b48c,
  roughness: 0.7, // 室内木地板比外墙光滑一点
  metalness: 0.0,
});

// 地板：BoxGeometry(X=7.6, Y=0.05, Z=5.6)
const floor = new THREE.Mesh(
  new THREE.BoxGeometry(7.6, 0.05, 5.6),
  floorMat
);
floor.position.set(0, 0.325, 0);
houseGroup.add(floor);
```

地板铺好后，从门洞看进去能看到浅木色地面，比灰色地基顶面温暖得多。stage-09 会加家具（GLTF 模型），那时室内会真正"活"起来。

## 三、完整收尾代码

把烟囱和地板合在一起，就是 `HouseScene.vue` 里 `addChimneyAndFloor()` 函数的完整内容：

```js
const addChimneyAndFloor = (houseGroup) => {
  // 烟囱材质：信息灰，砖石最粗糙
  const chimneyMat = new THREE.MeshStandardMaterial({
    color: 0x909399,
    roughness: 0.95,
    metalness: 0.0,
  });
  const chimney = new THREE.Mesh(
    new THREE.BoxGeometry(0.6, 1.5, 0.6),
    chimneyMat
  );
  chimney.position.set(2, 4.5, -1.5); // 立在右坡屋顶上
  houseGroup.add(chimney);

  // 室内地板材质：浅木色
  const floorMat = new THREE.MeshStandardMaterial({
    color: 0xd2b48c,
    roughness: 0.7,
    metalness: 0.0,
  });
  const floor = new THREE.Mesh(
    new THREE.BoxGeometry(7.6, 0.05, 5.6),
    floorMat
  );
  floor.position.set(0, 0.325, 0); // 铺在地基顶面
  houseGroup.add(floor);
};
```

## 五、本阶段材质选型总结

复盘本阶段所有材质的选型决策：

| 构件 | 材质类 | color | metalness | roughness | 选型理由 |
|------|--------|-------|:---------:|:---------:|----------|
| 草地 | MeshStandardMaterial | #67c23a | 0.0 | 1.0 | 完全哑光、自然有机 |
| 地基/台阶 | MeshStandardMaterial | #909399 | 0.0 | 0.9 | 石材粗糙、未抛光 |
| 外墙/山墙 | MeshStandardMaterial | #e6d5b8 | 0.0 | 0.9 | 暖米色墙面、粉刷感 |
| 木门 | MeshStandardMaterial | #8b5a2b | 0.0 | 0.6 | 木头有轻微光泽 |
| 屋顶 | MeshStandardMaterial | #a0522d | 0.0 | 0.8 | 砖红瓦面、半粗糙 |
| 烟囱 | MeshStandardMaterial | #909399 | 0.0 | 0.95 | 砖石烟囱、最粗糙 |
| 室内地板 | MeshStandardMaterial | #d2b48c | 0.0 | 0.7 | 浅木色地板、半光泽 |

**三条决策规律**：

1. **统一材质类**：全部用 `MeshStandardMaterial`，简化心智模型（只调 3 个属性）
2. **metalness 全 0**：本阶段无金属物体，全设 0 物理正确
3. **roughness 阶梯**：从 0.6（木门）到 1.0（草地）阶梯分布，让材质有层次感

::: tip 选型决策的工程权衡
本阶段选择"全部 Standard"是教学导向——让读者集中精力学一个材质。生产环境中可以更精细：远景物体（草地）可降级 Lambert 提性能；金属物体（如果有）必须 Standard/Physical。stage-13 性能优化会做这种降级。
:::

## 六、对比球的最终解释

草地远处那 5 个材质对比球，是本阶段教学的"实验装置"。它们不属于房子（是教学辅助物），但能让你**亲眼看到** 5 种材质在同一光照下的差异：

| # | 材质 | 视觉特征 | 物理对应 |
|---|------|----------|----------|
| 1 | MeshBasicMaterial | 纯蓝色、无视灯光 | 不存在的"理想发光体" |
| 2 | MeshLambertMaterial | 哑光蓝、无高光 | 纸张、粉笔 |
| 3 | MeshPhongMaterial | 蓝色 + 锐利高光斑 | 塑料球（蜡像感） |
| 4 | MeshStandardMaterial | 蓝色 + 柔和金属高光 | 真实金属/塑料 |
| 5 | MeshPhysicalMaterial | Standard + 清漆层反光 | 车漆、钢琴漆 |

绕到草地 (x=7~13, z=-6) 处，从左到右观察这 5 个球，能直观感受 PBR（4、5）与经验模型（2、3）的差距。**stage-05 起会移除对比球**，专注小屋本身。

::: warning 对比球的局限
本阶段只有 AmbientLight + DirectionalLight，没有环境光贴图（envMap）。PBR 球（4、5）的金属反射感会很弱——它们看起来更像塑料球。stage-05 加天空盒后，envMap 会让 Standard 球真正展现出金属反射效果。本阶段对比球主要看 Lambert vs Phong vs Standard 的高光差异。
:::

## 七、stage-04 完成确认

启动项目后，应当能确认以下视觉效果：

- [ ] **小屋主体**：暖米色四面墙 + 砖红色人字屋顶 + 灰色烟囱 + 木色门
- [ ] **屋顶山墙**：从正面（+Z）看，能看到顶端三角形山墙
- [ ] **屋脊对接**：两块坡板在 (0, 5, 0) 处对接，无明显缝隙
- [ ] **烟囱穿顶**：烟囱从右坡屋顶伸出，顶部高于屋脊
- [ ] **门洞可见**：透过门洞能看到室内浅木色地板
- [ ] **材质对比球**：草地远处 5 个蓝色球，从左到右材质依次变化
- [ ] **光照响应**：旋转相机时，墙面有明暗变化（受光面亮、背光面暗）
- [ ] **OrbitControls**：拖拽旋转、滚轮缩放正常

如果以上有任意一项不正常，对照本章节检查对应代码段。常见问题：

| 问题 | 原因 | 修复 |
|------|------|------|
| 屋顶悬空 | 屋顶 position.y 不是 4.15 | 检查 `slopeAngle` 和 `slopeLen` 推导 |
| 山墙不见 | gableShape 顶点错误或 position.z 错 | 三角形顶点 (-4,0)(4,0)(0,1.7)，z=3.0/-3.2 |
| 烟囱不在屋顶上 | chimney.position 不是 (2, 4.5, -1.5) | 对照 HOUSE_SPEC |
| 整体偏暗 | 灯光强度不够 | AmbientLight 强度 1.0、DirectionalLight 1.2 |
| 材质无高光 | roughness 太高或灯光方向平 | roughness 0.6~0.8，灯光斜照 |

## 八、本节总结

- **烟囱**：BoxGeometry(0.6, 1.5, 0.6) 在 (2, 4.5, -1.5)，材质 #909399 roughness 0.95（最粗糙）
- **室内地板**：BoxGeometry(7.6, 0.05, 5.6) 在 (0, 0.325, 0)，材质 #d2b48c roughness 0.7
- **stage-04 累积**：草地 + 地基 + 台阶 + 墙(含洞) + 门 + 屋顶 + 山墙 + 烟囱 + 地板 + 对比球 = 33 个 Mesh
- **材质选型三条规律**：统一 Standard、metalness 全 0、roughness 阶梯分布
- **对比球**：教学辅助物，stage-05 起移除；直观对比 5 种材质的光照响应
- **本阶段完成**：小屋已具备完整外观，下一阶段开始加贴图让材质更细腻

## 九、阶段衔接

```
stage-04 尖屋顶与外墙        stage-05 砖墙木门玻璃       stage-06 灯光与阴影
   屋顶+烟囱+地板         →    砖墙纹理/木纹/玻璃     →    阳光/环境光/阴影
   8 种材质教学                天空盒 envMap              室内点光源
   PBR 三件套                 程序化贴图                 壁灯聚光灯
```

stage-05 会在本阶段基础上：
- 给外墙加**砖墙贴图**（程序化生成的砖块纹理 map）
- 给门加**木纹贴图**（normalMap 凹凸感）
- 给窗洞填**玻璃**（MeshPhysicalMaterial transmission 透射）
- 加**天空盒**（CubeTexture 作为 envMap，让 PBR 金属感完整呈现）

到此 stage-04 圆满完成。回顾本阶段：我们认识了 8 种材质的全家族，亲手推导了屋顶的旋转几何，给小屋贴上了 PBR 三件套，最后用烟囱和地板收尾。下一阶段，让小屋真正"有质感"——砖墙、木纹、玻璃、天空，一个不少。
