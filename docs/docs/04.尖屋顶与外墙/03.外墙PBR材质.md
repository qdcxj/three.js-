# 外墙 PBR 材质：MeshStandardMaterial 三件套

屋顶盖好了，但墙还是一片默认灰色——这是因为 stage-03 的墙还没指定材质。本节我们给外墙、屋顶、烟囱、地板、门统一贴上 `MeshStandardMaterial`，并深入讲解它的三个核心属性 `color` / `metalness` / `roughness`。这是 PBR（基于物理的渲染）的灵魂三问：

1. **它是什么颜色？** → `color`
2. **它是金属吗？** → `metalness`
3. **它有多粗糙？** → `roughness`

只要回答清这三个问题，PBR 材质就立住了。stage-05 会在这一基础上加贴图（砖墙纹理、木纹），stage-06 加灯光阴影后，真实感会完全呈现。

## 一、为什么选 MeshStandardMaterial

回顾上一节的材质选型表，本阶段所有构件统一选 `MeshStandardMaterial` 而非 `MeshLambertMaterial` / `MeshPhongMaterial`，理由：

| 维度 | Lambert | Phong | **Standard** | Physical |
|------|:-------:|:-----:|:------------:|:--------:|
| 受光照 | ✅ | ✅ | ✅ | ✅ |
| 物理真实 | ❌ 经验 | ❌ 经验 | ✅ PBR | ✅ PBR |
| 高光 | 无 | 锐利 | 柔和过渡 | 柔和+清漆 |
| 跨引擎通用 | ❌ | ❌ | ✅ glTF 标准 | ✅ |
| 性能 | 最快 | 快 | 中 | 中慢 |

- **真实感**：Lambert 无高光（塑料感）、Phong 高光太锐（蜡像感），Standard 高光柔和过渡，最像真实材质
- **跨引擎通用**：PBR 参数（金属度、粗糙度）在 Unity / Unreal / Blender / glTF 通用，学一次到处能用
- **性能可接受**：比 Lambert 慢一档，但远比 Physical 快；本阶段物体少（< 30 个 Mesh），性能完全够用
- **后续可扩展**：stage-05 加贴图（map/normalMap/roughnessMap），stage-06 加环境贴图（envMap），都是 Standard 的属性，无需换材质类

::: tip 何时不用 Standard
如果场景有上百个简单物体（比如粒子化的树叶、远景树木），用 Lambert 性能更好。本阶段小屋只有几十个 Mesh，Standard 完全无压力。
:::

## 二、color：基础颜色

`color` 是材质的漫反射颜色（非金属物体）或反射率（金属物体），接受十六进制数字、CSS 字符串、THREE.Color 实例三种写法：

```js
import * as THREE from "three";

// 三种等价写法
const m1 = new THREE.MeshStandardMaterial({ color: 0xe6d5b8 }); // 十六进制数字（推荐）
const m2 = new THREE.MeshStandardMaterial({ color: "#e6d5b8" }); // CSS 字符串
const m3 = new THREE.MeshStandardMaterial({ color: new THREE.Color(0.9, 0.84, 0.72) }); // RGB 0~1
```

本阶段遵循 Element Plus 调色板，每个构件颜色都来自 HOUSE_SPEC：

| 构件 | color（hex） | 颜色名 | 来源 |
|------|:------------:|--------|------|
| 草地 | `0x67c23a` | 成功绿 | Element Plus success |
| 地基 / 台阶 / 烟囱 | `0x909399` | 信息灰 | Element Plus info |
| 外墙 / 山墙 | `0xe6d5b8` | 暖米色 | HOUSE_SPEC 自定义 |
| 木门 | `0x8b5a2b` | 木色 | HOUSE_SPEC 自定义 |
| 屋顶 | `0xa0522d` | 砖红 | HOUSE_SPEC 自定义 |
| 室内地板 | `0xd2b48c` | 浅木色 | HOUSE_SPEC 自定义 |

::: warning color 在金属材质下的不同含义
非金属（metalness=0）的 `color` 是漫反射颜色（看到什么色就是什么色）；金属（metalness=1）的 `color` 是反射率（tint 环境光），不是漫反射。本阶段所有材质 metalness 都是 0，所以 `color` 就是直观看到的颜色。stage-13 性能优化章节会接触金属物体。
:::

## 三、metalness：金属度

`metalness` 取值 0~1，决定物体是否是金属：

- `0`：电介质（Dielectric）——塑料、木材、石材、布料、玻璃、水。**绝大多数日常物体都是 0**
- `1`：纯金属——铁、铜、金、铝。`color` 此时是反射率而非漫反射色
- `0.5`：半金属——生锈金属、金属漆过渡区。**实际很少用，要么 0 要么 1**

```js
// 木材（非金属）
const woodMat = new THREE.MeshStandardMaterial({
  color: 0x8b5a2b,
  metalness: 0.0, // 木材是非金属
  roughness: 0.6,
});

// 黄金（纯金属）
const goldMat = new THREE.MeshStandardMaterial({
  color: 0xffd700,
  metalness: 1.0, // 金属
  roughness: 0.2, // 抛光
});
```

**为什么本阶段所有材质 metalness 都是 0**：因为小屋的构件全是非金属——草地、石材、木材、瓦面、砖石烟囱，没有一个是金属。把它们的 `metalness` 设为 0 是物理正确的。如果误设非金属为金属，会出现"黑色塑料感"——颜色被反射率替代，物体看起来失真发暗。

::: tip 金属与非金属的本质差异
金属的反射率高（70%~100%），且没有漫反射（光线要么被反射要么被吸收）；非金属反射率低（4%~5%），大部分光线被漫反射出去（这就是为什么我们能看到颜色）。PBR 用 `metalness` 这个 0/1 开关切换两种物理模型，比 Phong 的 `specular` 颜色更物理。
:::

## 四、roughness：粗糙度

`roughness` 取值 0~1，决定表面粗糙程度，直接控制高光的锐利度：

- `0`：完全光滑（镜面）——抛光镜面、平静水面、新涂车漆
- `0.3~0.5`：半光泽——塑料、陶瓷、抛光木材
- `0.6~0.8`：半粗糙——砖面、瓦面、普通木材
- `0.9~1.0`：完全粗糙（哑光）——粉刷墙、布料、土壤、纸张

```js
// 草地（完全粗糙）
const grassMat = new THREE.MeshStandardMaterial({
  color: 0x67c23a,
  metalness: 0.0,
  roughness: 1.0, // 草地完全哑光
});

// 木门（半光泽）
const doorMat = new THREE.MeshStandardMaterial({
  color: 0x8b5a2b,
  metalness: 0.0,
  roughness: 0.6, // 木材有轻微光泽
});

// 屋顶瓦（半粗糙）
const roofMat = new THREE.MeshStandardMaterial({
  color: 0xa0522d,
  metalness: 0.0,
  roughness: 0.8, // 瓦面较粗糙
});
```

`roughness` 的视觉效果：值越小，高光越集中、越锐利（像聚光灯打在镜子上）；值越大，高光越分散、越柔和（像阳光打在粉刷墙上，整面均匀发亮）。本阶段通过不同的 `roughness` 值区分不同材质的质感。

## 五、本阶段所有材质一览

把前面三个属性组合起来，本阶段 `HouseScene.vue` 里共定义了 6 个材质对象（不算对比球）：

```js
// 1. 草地材质：完全哑光绿
const groundMat = new THREE.MeshStandardMaterial({
  color: 0x67c23a,
  roughness: 1.0,
  metalness: 0.0,
});

// 2. 地基/台阶材质：粗糙石材灰
const foundationMat = new THREE.MeshStandardMaterial({
  color: 0x909399,
  roughness: 0.9,
  metalness: 0.0,
});

// 3. 外墙/山墙材质：暖米色未抛光
const wallMat = new THREE.MeshStandardMaterial({
  color: 0xe6d5b8,
  roughness: 0.9,
  metalness: 0.0,
});

// 4. 木门材质：木色半光泽
const doorMat = new THREE.MeshStandardMaterial({
  color: 0x8b5a2b,
  roughness: 0.6,
  metalness: 0.0,
});

// 5. 屋顶材质：砖红瓦半粗糙（双面渲染）
const roofMat = new THREE.MeshStandardMaterial({
  color: 0xa0522d,
  roughness: 0.8,
  metalness: 0.0,
  side: THREE.DoubleSide,
});

// 6. 烟囱+室内地板材质（两个独立材质）
const chimneyMat = new THREE.MeshStandardMaterial({
  color: 0x909399,
  roughness: 0.95,
  metalness: 0.0,
});
const floorMat = new THREE.MeshStandardMaterial({
  color: 0xd2b48c,
  roughness: 0.7,
  metalness: 0.0,
});
```

注意 `roughness` 的层次：草地 1.0（最粗）→ 烟囱 0.95 → 地基 0.9 → 外墙 0.9 → 屋顶 0.8 → 地板 0.7 → 木门 0.6（最光）。这个粗糙度阶梯让小屋看起来"有材质层次"而不是一片平。

## 六、PBR 微表面理论（进阶）

为什么 `roughness` 能模拟粗糙感？背后的物理是**微表面理论（Microfacet Theory）**：

> 真实表面在微观尺度上有无数细小凹凸（微表面）。这些微表面的法线方向决定光线如何反射。光滑表面微表面法线整齐，反射光集中（高光锐利）；粗糙表面微表面法线混乱，反射光被散射（高光散开、变模糊）。

`MeshStandardMaterial` 用 `roughness` 控制**微表面法线的混乱程度**：

- `roughness = 0`：所有微表面法线对齐，反射光集中 → 镜面高光
- `roughness = 1`：微表面法线完全随机，反射光各方向均匀 → 无高光，纯漫反射

::: tip PBR 不只看 color
理解 PBR 的关键：物体的视觉外观不是 `color` 一个属性决定的，而是 `color + metalness + roughness` 三者组合。同一个 #409eff 蓝色，配 `metalness=0, roughness=0.4` 是塑料球，配 `metalness=1, roughness=0.2` 是抛光金属球，配 `metalness=0, roughness=1.0` 是粉刷球。本阶段草地远处那 5 个对比球，正是用同一颜色 + 不同材质组合展示这种差异。
:::

## 七、材质对比球：PBR vs 经验模型

回顾上一节放的 5 个对比球，它们直观展示了 PBR 与经验模型的差异。**重点观察 Standard 球 vs Phong 球**：

- **Phong 球**：高光是一个清晰锐利的小圆斑（像蜡像），过渡硬
- **Standard 球**：高光柔和过渡（像真实金属/塑料），过渡自然

 Phong 的高光用 `shininess` 控制（越大越锐），是经验公式，不物理；Standard 的高光由 `roughness` 微表面模型算出，过渡自然。这就是为什么现代渲染（游戏、电影、glTF）都用 PBR——观感更真实。

::: warning PBR 需要环境光照
PBR 材质的高光反射需要环境光（`envMap` 或 `Scene.environment`）才能完整呈现金属感。本阶段只有 `AmbientLight + DirectionalLight`，金属感会比较弱（看不到环境反射）。stage-05 加天空盒后会提供 `envMap`，那时 Standard 球的金属感会完全展现。本阶段先用方向光看个大概。
:::

## 八、材质优化：共享与复用

本阶段一个性能优化细节：**多个 Mesh 共享同一个材质对象**。比如前墙有 8 块、左右墙各 4 块，这些墙块都共享 `wallMat`：

```js
const wallMat = new THREE.MeshStandardMaterial({
  color: 0xe6d5b8,
  roughness: 0.9,
  metalness: 0.0,
});

// 辅助函数：所有墙块用同一个 wallMat
const block = (w, h, d, x, y, z) => {
  const m = new THREE.Mesh(new THREE.BoxGeometry(w, h, d), wallMat);
  m.position.set(x, y, z);
  houseGroup.add(m);
  return m;
};

// 8 块前墙都用 wallMat —— GPU 只上传一次材质
block(8, 0.6, 0.2, 0, 0.6, 3);
block(1.6, 1.2, 0.2, -3.2, 1.5, 3);
// ... 其他 6 块
```

共享材质的好处：
- **GPU 内存少**：材质 uniform 只上传一次
- **修改方便**：改 `wallMat.color` 一次，所有墙同步变色
- **drawcall 可能合并**：同材质 + 同几何的 Mesh 可能被合批（取决于引擎）

::: warning 共享材质的副作用
共享材质下，改一个 Mesh 的材质属性（如 `mesh.material.color`）会**影响所有共享该材质的 Mesh**。如果想单独改某一块墙的颜色，必须先 `mesh.material = wallMat.clone()` 克隆一份再改。本阶段所有墙都同色，无需克隆。
:::

## 九、本节总结

- `MeshStandardMaterial` 是 PBR 主流材质，本阶段所有构件统一用它
- 三个核心属性：
  - `color`：基础颜色（非金属）或反射率（金属）
  - `metalness`：金属度 0~1，本阶段全是 0（无金属物体）
  - `roughness`：粗糙度 0~1，本阶段从 0.6（木门）到 1.0（草地）阶梯分布
- PBR 微表面理论：`roughness` 控制微表面法线混乱度，决定高光锐利程度
- 共享材质优化：多个 Mesh 共用同一材质对象，省 GPU 内存且便于统一修改
- PBR 完整呈现需要环境光（envMap），stage-05 加天空盒后效果会更好
