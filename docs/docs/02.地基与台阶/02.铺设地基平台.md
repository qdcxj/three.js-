# 铺设地基平台

认识完 13 种内置几何体，现在动手砌地基。地基是整栋房子的「根」——它压在草地上、承托后续的墙体与屋顶，所以**尺寸和位置一旦定下就不再变动**。本节我们用最朴素的 `BoxGeometry(8, 0.3, 6)` 推算出地基的尺寸与 `position.y`，让它的底面稳稳贴在 stage-01 的草地上，顶面在 y = 0.3 处留出后续墙体的落脚点。

## 1. 地基设计回顾

按 HOUSE_SPEC 规范，地基的尺寸与位置如下：

| 属性 | 数值 | 说明 |
|------|------|------|
| 几何体 | `BoxGeometry(8, 0.3, 6)` | 8m 宽(X) × 0.3m 高(Y) × 6m 深(Z) |
| 中心坐标 | `(0, 0.15, 0)` | X、Z 居中，Y 让底面贴地 |
| 颜色 | `#909399` | Element Plus 信息灰 |
| 材质 | `MeshStandardMaterial` | PBR 材质，受光照影响 |

为什么是 8m × 6m？因为后续 stage-03 的四面墙就建在地基顶面：8m 是前后墙的长度（X 方向），6m 是左右墙的长度（Z 方向），墙体厚度 0.2m 会贴着地基的边缘向上砌。0.3m 的高度则让房子整体抬离地面，避免墙面直接接触草地，符合真实乡村小屋的防潮构造。

::: tip 为什么不直接把墙放在草地上
真实小屋的地基有两大作用：**承重** + **防潮**。把房子整体抬高 0.3m，可以让木质墙体底端远离地面湿气，延长寿命。在 Three.js 里这样做还有一个隐性好处：地基顶面 y = 0.3 是一个「干净」的基准面，后续所有墙体、室内地板的高度都从它向上推算，坐标系更整齐。
:::

## 2. BoxGeometry 参数推算

`BoxGeometry(width, height, depth)` 的三个核心参数对应 X / Y / Z 三个轴的尺寸。地基参数推算如下：

```js
import * as THREE from "three";

// 地基几何体：8m 宽 × 0.3m 高 × 6m 深
const foundationGeo = new THREE.BoxGeometry(8, 0.3, 6);
```

| 参数 | 数值 | 推算依据 |
|------|------|---------|
| `width` (X) | 8 | HOUSE_SPEC：地基 8(X) × 6(Z) × 0.3(Y)，前后墙长度 |
| `height` (Y) | 0.3 | 抬离地面 0.3m，防潮 + 提供墙体落脚面 |
| `depth` (Z) | 6 | 左右墙长度，门朝 +Z，前后各 3m |

注意 `BoxGeometry` 的三个参数顺序是 **width → height → depth**，对应 X / Y / Z。如果你把 0.3 写在第一个参数位置，地基就会变成 0.3m 宽 × 8m 高 × 6m 深的「竖立薄板」，完全不对。

::: warning 参数顺序是常见坑
`BoxGeometry` 与 `PlaneGeometry` 的参数顺序不同：
- `BoxGeometry(width, height, depth)` —— X / Y / Z
- `PlaneGeometry(width, height)` —— X / Y（默认在 XY 平面）

写代码时如果不确定，先 `console.log(geometry.parameters)` 打印出来核对，比来回改参数快得多。
:::

## 3. position.y 的关键推算

`BoxGeometry` 的中心点在它的几何中心——也就是说，position 设置的是「几何中心」的坐标，而不是底面。这是初学者最容易踩的坑：如果直接 `position.set(0, 0, 0)`，地基会有一半埋在草地下面。

### 推导过程

设地基几何中心 y 坐标为 `cy`，地基高度为 `h = 0.3`，草地顶面 `y = 0`：

```
地基底面 y = cy - h / 2 = cy - 0.15
地基顶面 y = cy + h / 2 = cy + 0.15
```

要让底面贴地（`cy - 0.15 = 0`），则：

```
cy = 0.15
```

所以 `position.y = 0.15`，顶面自然在 `y = 0.3` 处。这个 0.3 就是后续 stage-03 墙体、stage-04 室内地板的基准面。

```js
// 地基中心点 y = 高度 / 2 = 0.3 / 2 = 0.15
// 这样底面 y = 0（贴地），顶面 y = 0.3（墙体落脚面）
foundation.position.set(0, 0.15, 0);
```

### 通用公式

对任意「底面贴地」的 Box 构件：

```
position.y = height / 2
```

后续 stage-03 的墙体也遵循这个公式——但墙体的「底面」是地基顶面 y = 0.3，所以墙体的 `position.y = 0.3 + wallHeight / 2`。这就是为什么 HOUSE_SPEC 里后墙 `position.y = 1.8`：墙体高 3m，`0.3 + 3 / 2 = 1.8`。

::: tip 中心点 vs 底面
Three.js 的所有内置几何体都以**几何中心**为原点（不是底面）。如果你希望以底面为定位基准，有两种做法：
1. **手动推算**：`position.y = height / 2`（推荐，本教程统一用此法）
2. **几何体平移**：`geometry.translate(0, height / 2, 0)` 后，position.y = 0 即底面贴地

第一种更直观，便于在 HOUSE_SPEC 里用「中心坐标」统一描述所有构件。
:::

## 4. X 与 Z 坐标：居中放置

地基的 X、Z 坐标都是 0，也就是把地基放在草地正中央。这有两个好处：

1. **房子中心 = 世界原点**：后续所有构件（墙、屋顶、烟囱）都围绕原点对称布置，坐标系整齐
2. **草地 40m × 40m 远大于地基 8m × 6m**：地基四周留出大片空地，方便后续 stage 加花园、栅栏、小路

地基的边界如下：

| 边界 | 数值 | 说明 |
|------|------|------|
| X 左边缘 | -4 | `0 - width / 2 = -4` |
| X 右边缘 | +4 | `0 + width / 2 = +4` |
| Z 后边缘 | -3 | `0 - depth / 2 = -3`（远离门） |
| Z 前边缘 | +3 | `0 + depth / 2 = +3`（门朝向） |
| Y 底面 | 0 | 贴地 |
| Y 顶面 | 0.3 | 墙体落脚面 |

下一节的入口台阶就紧贴 Z 前边缘（z = 3）向外探出。

## 5. MeshStandardMaterial：让地基受光照

地基用 `MeshStandardMaterial`，这是 Three.js 的 PBR（基于物理的渲染）材质，能正确响应环境光与平行光，产生明暗变化。如果改用 `MeshBasicMaterial`，地基会是纯灰色一块，看不出立体感。

```js
import * as THREE from "three";

const foundationMat = new THREE.MeshStandardMaterial({
  color: 0x909399, // Element Plus 信息灰
  roughness: 0.8,  // 粗糙度 0.8：混凝土质感
  metalness: 0.0,  // 金属度 0：非金属
});
```

| 参数 | 数值 | 说明 |
|------|------|------|
| `color` | `0x909399` | Element Plus 信息灰，与 HOUSE_SPEC 一致 |
| `roughness` | 0.8 | 粗糙度高，模拟混凝土/石材表面 |
| `metalness` | 0.0 | 地基是非金属，金属度必须为 0 |

::: tip PBR 材质三件套
`MeshStandardMaterial` 的三大核心参数：
- `color`：基础颜色（反照率）
- `roughness`：粗糙度，0 = 镜面光滑，1 = 完全哑光
- `metalness`：金属度，0 = 非金属（塑料/木材/石材），1 = 纯金属

stage-02 的所有构件（地基、台阶）都是石材，所以 `roughness: 0.8, metalness: 0`；stage-05 做玻璃窗时会用 `metalness: 0, roughness: 0.05` 配合透射；stage-05 的金属门把手会用 `metalness: 1, roughness: 0.3`。
:::

## 6. 完整代码：把地基加到场景

下面是 `HouseScene.vue` 里铺设地基的核心片段。注意我们用 `createMesh` 工具函数把 geometry 与 material 登记到 `disposableGeometries` / `disposableMaterials` 数组，方便 `onUnmounted` 时统一 dispose：

```js
import * as THREE from "three";

// 工具：创建 mesh 并登记 geometry/material 以便后续统一 dispose
const disposableGeometries = [];
const disposableMaterials = [];
const createMesh = (geometry, material) => {
  disposableGeometries.push(geometry);
  disposableMaterials.push(material);
  return new THREE.Mesh(geometry, material);
};

// === 地基平台 ===
// BoxGeometry(8, 0.3, 6)：8m 宽(X) × 0.3m 高(Y) × 6m 深(Z)
// position(0, 0.15, 0)：底面贴地（y=0），顶面在 y=0.3
// 颜色 #909399 Element Plus 信息灰
const foundationGeo = new THREE.BoxGeometry(8, 0.3, 6);
const foundationMat = new THREE.MeshStandardMaterial({
  color: 0x909399,
  roughness: 0.8,
  metalness: 0.0,
});
const foundation = createMesh(foundationGeo, foundationMat);
foundation.position.set(0, 0.15, 0);
scene.add(foundation);
```

::: warning 为什么不直接 new THREE.Mesh
直接 `new THREE.Mesh(geo, mat)` 当然可以，但后续 `onUnmounted` 时需要手动维护一份「待释放列表」——很容易漏掉某个 mesh。本教程用 `createMesh` 工具函数集中登记，dispose 时遍历数组释放，**一处登记、统一清理**，是 Vue 3 + Three.js 项目的推荐实践。
:::

## 7. 把地基放进累积场景

本阶段的 `HouseScene.vue` 是 stage-01 的累积升级版。`initObjects()` 函数按顺序创建所有构件：

```js
const initObjects = () => {
  // ---- 1. 草地（继承自 stage-01）----
  const grassGeo = new THREE.PlaneGeometry(40, 40);
  const grassMat = new THREE.MeshStandardMaterial({
    color: 0x67c23a, // 成功绿
    roughness: 0.95,
    metalness: 0.0,
  });
  grass = createMesh(grassGeo, grassMat);
  grass.rotation.x = -Math.PI / 2; // 躺平
  grass.position.set(0, 0, 0);
  scene.add(grass);

  // ---- 2. 地基平台（本阶段新增）----
  const foundationGeo = new THREE.BoxGeometry(8, 0.3, 6);
  const foundationMat = new THREE.MeshStandardMaterial({
    color: 0x909399,
    roughness: 0.8,
    metalness: 0.0,
  });
  foundation = createMesh(foundationGeo, foundationMat);
  foundation.position.set(0, 0.15, 0);
  scene.add(foundation);

  // ---- 3. 入口台阶（下一节讲解）----
  // ...

  // ---- 4. 几何体预览（上一节讲解）----
  // ...

  // ---- 5. 辅助工具（继承自 stage-01）----
  axesHelper = new THREE.AxesHelper(5);
  scene.add(axesHelper);
  gridHelper = new THREE.GridHelper(40, 40, 0x409eff, 0xc0c4cc);
  scene.add(gridHelper);
};
```

::: tip 累积建造的代码组织
注意 `initObjects()` 里构件的创建顺序：**草地 → 地基 → 台阶 → 几何体预览 → 辅助工具**。这个顺序保证了：
1. 草地最先创建，作为「地面基准」
2. 地基压在草地上方（虽然 Three.js 不存在真实物理碰撞，但绘制顺序与逻辑顺序一致便于阅读）
3. 辅助工具最后创建，永远在最上层不被遮挡（ AxesHelper / GridHelper 不会被深度测试影响）

后续 stage-03 会在「台阶」与「几何体预览」之间插入「四面墙 + 门板」，stage-04 会在墙后插入「屋顶 + 烟囱」，依次累积。
:::

## 8. 验证：地基应该长什么样

运行 `npm run dev`，浏览器打开 `http://localhost:5173`，你应该看到：

- 草地中央多出一块 **灰色长方体平台**，8m × 6m，厚 0.3m
- 平台 **底面贴地**，没有埋入草地，也没有悬空
- 平台 **顶面平整**，是一块 ready 给墙体落脚的基准面
- 顶面 y = 0.3，与 AxesHelper 的 Y 轴刻度对齐（红色 Y 轴穿过地基中心）
- 阳光从右上方照下来，地基 **右前侧亮、左后侧暗**，有明显明暗对比

如果地基**埋在草地里**：检查 `position.y` 是不是 0（应该是 0.15）。
如果地基**悬在空中**：检查 `BoxGeometry` 第二个参数是不是被写成 0.3 之外的值，或者 `position.y` 被误写成 0.3。
如果地基**变成竖立薄板**：检查 `BoxGeometry` 参数顺序，应为 `(width=8, height=0.3, depth=6)`。

## 9. 与 HOUSE_SPEC 的对齐核对

本节实现严格对齐 HOUSE_SPEC：

| HOUSE_SPEC 字段 | 本节实现 | 是否一致 |
|----------------|---------|---------|
| 构件：地基平台 | `BoxGeometry(8, 0.3, 6)` | 是 |
| 尺寸：8(X) × 6(Z) × 0.3(Y) | `(8, 0.3, 6)` 对应 X/Y/Z | 是 |
| 位置：(0, 0.15, 0) | `position.set(0, 0.15, 0)` | 是 |
| 颜色：#909399 | `0x909399` | 是 |
| 建造阶段：stage-02 | 本阶段 | 是 |

::: warning 后续阶段不要改地基
地基的尺寸与位置在 stage-02 就**永久定下**。stage-03 的墙体、stage-04 的屋顶都依赖地基的 8m × 6m 边界与 y = 0.3 顶面。如果你在后续阶段发现「墙对不齐地基」「屋顶悬空」，99% 是地基参数被改动了——回 stage-02 把它改回 `(8, 0.3, 6)` + `(0, 0.15, 0)` 即可。
:::

## 本节总结

本节用最朴素的 `BoxGeometry` 砌出地基平台，重点掌握了三个推算：

1. **参数顺序**：`BoxGeometry(width, height, depth)` 对应 X / Y / Z，地基是 `(8, 0.3, 6)`
2. **底面贴地公式**：`position.y = height / 2 = 0.3 / 2 = 0.15`，让底面在 y = 0，顶面在 y = 0.3
3. **PBR 材质三件套**：`color` / `roughness` / `metalness`，地基用灰色 + 高粗糙度 + 零金属度模拟混凝土

同时建立了一套 **createMesh + disposableGeometries/disposableMaterials** 的资源管理惯例，后续所有阶段都会沿用。
