# 地基与台阶

欧式乡村小屋的「地基」是整栋房子与大地之间的过渡层——它把房子抬离地面、隔绝潮气，并在门口探出两级台阶迎接来客。本章节是项目驱动教程的第二阶段：在 stage-01 已经铺好的草地上，**用 `BoxGeometry` 砌一块 8m × 6m × 0.3m 的灰色地基平台**，再在门口 **用两块小 Box 拼出两级入口台阶**，同时把 Three.js **内置几何体全家桶**一次性讲透。

## 一、建造目标

本阶段完成后，你的场景里会多出三样东西，全部用最朴素的 `BoxGeometry` 实现：

| 构件 | 尺寸（m） | 位置（中心坐标） | 颜色 |
|------|-----------|------------------|------|
| 地基平台 | 8(X) × 0.3(Y) × 6(Z) | (0, 0.15, 0) | #909399 信息灰 |
| 入口台阶第一级 | 1.5(X) × 0.15(Y) × 0.4(Z) | (0, 0.075, 3.2) | #909399 信息灰 |
| 入口台阶第二级 | 1.5(X) × 0.15(Y) × 0.4(Z) | (0, 0.225, 3.0) | #909399 信息灰 |

同时在草地远处（z = -8）会摆一排「建筑材料预览」：BoxGeometry、SphereGeometry、ConeGeometry、CylinderGeometry、TorusGeometry 五件代表，配 Element Plus 五色调色，作为本章教学几何体的实物教具。

::: tip 为什么用 BoxGeometry 而不是更复杂的几何体
地基和台阶都是规则的「长方体堆叠」，`BoxGeometry` 是最经济、最直观的选择。这阶段重点是 **把坐标系、尺寸推算、累积建造** 三件事练熟，而不是炫技。等到 stage-04 做尖屋顶、stage-05 做玻璃，才会用到 ConeGeometry、自定义 Shape 等更高级的几何体。
:::

## 二、学习目标

完成本章节后，你将能够：

- 说出 Three.js **13 种内置几何体**的名称、用途与构造参数，并能根据场景需要选用合适的几何体
- 用 `BoxGeometry` 推算地基与台阶的尺寸、位置，理解「中心坐标 = 底面 y + 高度 / 2」的推导过程
- 在 stage-01 草地基础上**累积**添加新构件，理解 HOUSE_SPEC 中「每个 stage-XX 是完整独立项目」的累积规则
- 用 `BufferGeometry` 手动定义顶点、索引，构建一个自定义三角面台阶或斜坡，理解 Three.js 几何体的最底层结构
- 在 Vue 3 组件里管理多个 Mesh 的 dispose，避免显存泄漏

本章节假设你已经完成 [01.项目启动](../01.项目启动/) 的学习，并已搭建出 stage-01 的草地场景。如果你对以下内容还不熟悉，建议先回看：

## 六、坐标系与尺寸约定（HOUSE_SPEC 摘录）

为保证 14 个阶段建出的是同一栋房子，本教程严格遵守 `lession/HOUSE_SPEC.md`：

- 原点 `(0, 0, 0)` = 房子中心地面点
- `+Y` 向上，`+Z` 向前（门朝向），`+X` 向右
- 单位：米（m），1 单位 = 1 米
- 地面 `y = 0`
- 地基 8(X) × 6(Z) × 0.3(Y)，中心 (0, 0.15, 0)
- 入口台阶 1.5(X) × 0.4(Z) × 0.15(Y) × 2 级，位置 (0, 0.075/0.225, 3.2)

后续 stage-03 的四面墙、stage-04 的尖屋顶都会以本阶段的地基为基准向上生长，所以地基的尺寸和位置一旦定下就不再变动。

准备好了吗？让我们从 [内置几何体全家桶](./01.内置几何体全家桶.md) 开始，先把工具箱摸熟，再动手砌地基。
