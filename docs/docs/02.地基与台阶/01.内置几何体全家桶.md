# 内置几何体全家桶

砌地基之前，先认识我们的工具箱。Three.js 在 `THREE` 命名空间下提供了 **13 种常用内置几何体**，全部继承自 `BufferGeometry`，可以快速拼出立方体、球体、平面、圆柱、圆环、管道、车削体等常见形状。掌握这 13 把「积木」，就能覆盖日常 80% 以上的基础建模需求——本阶段的地基与台阶只用其中的 `BoxGeometry` 就够了，但下一阶段做屋顶会用 `ConeGeometry`，做窗框会用 `BoxGeometry` 拼接，做装饰柱会用 `CylinderGeometry`，所以这里一次性把它们讲透。

本节的源码对应 `stage-02-地基与台阶/src/components/HouseScene.vue` 里的「几何体预览」部分：在草地远处 z = -8 摆了 5 件代表（Box / Sphere / Cone / Cylinder / Torus），配 Element Plus 五色调色。文档里则把全部 13 种都讲一遍，作为后续阶段的查阅手册。

## BufferGeometry：所有几何体的基类

13 种内置几何体最终都继承自 `BufferGeometry`。它不存储「这是一个立方体」这样的语义信息，而是直接持有最底层的**顶点缓冲区数据**，由 GPU 直接消费：

| 属性 | 说明 | 数据类型 | 是否必需 |
|------|------|---------|---------|
| `position` | 顶点位置坐标（x, y, z） | `Float32Array` | 必需 |
| `normal` | 顶点法线向量，决定光照计算方向 | `Float32Array` | 受光照时必需 |
| `uv` | 纹理坐标，决定贴图如何映射到表面（范围 0~1） | `Float32Array` | 使用贴图时必需 |
| `index` | 顶点索引，决定顶点如何组成三角形面 | `Uint16Array` / `Uint32Array` | 可选（用于复用顶点） |
| `color` | 顶点颜色，用于顶点级着色 | `Float32Array` | 可选 |

::: tip 三角形是基本单元
在 WebGL 中，所有 3D 模型最终都由**三角形（Triangle）**拼成。一个矩形 = 2 个三角形，一个立方体 = 12 个三角形。每 3 个顶点构成一个三角形面。13 种内置几何体本质上都是在帮我们自动生成这些顶点和三角形索引。
:::

```js
import * as THREE from "three";

// 任何内置几何体都可以通过 attributes 查看其内部数据
const geometry = new THREE.BoxGeometry(1, 1, 1);
console.log(geometry.attributes.position); // 顶点位置
console.log(geometry.attributes.normal);   // 顶点法线
console.log(geometry.attributes.uv);       // 纹理坐标
console.log(geometry.index);               // 顶点索引
```

下面按「立方体类 → 球体类 → 平面类 → 锥柱类 → 圆环类 → 由 2D 生成 3D 类」的顺序，逐个介绍这 13 种几何体。

## 1. BoxGeometry 立方体

`BoxGeometry` 是本阶段地基与台阶的主角。它创建立方体或长方体，由 6 个矩形面组成，是最常用的几何体之一。

### 构造参数

```js
new THREE.BoxGeometry(width, height, depth, widthSegments, heightSegments, depthSegments)
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `width` | X 轴方向宽度 | 1 |
| `height` | Y 轴方向高度 | 1 |
| `depth` | Z 轴方向深度 | 1 |
| `widthSegments` | X 轴方向分段数 | 1 |
| `heightSegments` | Y 轴方向分段数 | 1 |
| `depthSegments` | Z 轴方向分段数 | 1 |

### 示例

```js
import * as THREE from "three";

// 基础立方体（1×1×1）
const box = new THREE.BoxGeometry(1, 1, 1);

// 地基平台：8m 宽 × 0.3m 高 × 6m 深（本阶段使用）
const foundation = new THREE.BoxGeometry(8, 0.3, 6);

// 入口台阶：1.5m 宽 × 0.15m 高 × 0.4m 深
const step = new THREE.BoxGeometry(1.5, 0.15, 0.4);

// 每面 4×4 分段（用于后续顶点形变，如波浪、爆炸）
const segmented = new THREE.BoxGeometry(2, 2, 2, 4, 4, 4);
```

::: warning 分段数与性能
分段数（Segments）越多，顶点数越多。对于平面立方体，分段保持默认 1 即可。增加分段主要用于需要在顶点着色器中做形变（如波浪、布料、爆炸碎片）的场景，否则纯属浪费。
:::

## 2. SphereGeometry 球体

`SphereGeometry` 通过**经纬度网格**构造球体，由 `widthSegments`（经线分段）和 `heightSegments`（纬线分段）控制平滑度。

### 构造参数

```js
new THREE.SphereGeometry(radius, widthSegments, heightSegments, phiStart, phiLength, thetaStart, thetaLength)
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `radius` | 球体半径 | 1 |
| `widthSegments` | 经线（水平）分段数 | 32 |
| `heightSegments` | 纬线（垂直）分段数 | 16 |
| `phiStart` | 水平起始角度 | 0 |
| `phiLength` | 水平跨度（默认 2π 为整球） | Math.PI * 2 |
| `thetaStart` | 垂直起始角度 | 0 |
| `thetaLength` | 垂直跨度（默认 π 为整球） | Math.PI |

### 示例

```js
import * as THREE from "three";

// 完整球体（半径 0.6，32×16 分段，足够平滑）
const sphere = new THREE.SphereGeometry(0.6, 32, 16);

// 半球（垂直跨度只取 π/2，可用于穹顶）
const hemisphere = new THREE.SphereGeometry(1, 32, 16, 0, Math.PI * 2, 0, Math.PI / 2);

// 切片球（水平只取 1/4，类似吃剩的西瓜）
const slice = new THREE.SphereGeometry(1, 32, 16, 0, Math.PI / 2);
```

::: tip 分段数推荐
- 视觉平滑：`widthSegments: 32, heightSegments: 16` 即可
- 高质量反射：`widthSegments: 64, heightSegments: 32`
- 低多边形风格：`widthSegments: 8, heightSegments: 6` 配合 `flatShading: true`
:::

## 3. PlaneGeometry 平面

`PlaneGeometry` 创建矩形平面，默认位于 XY 平面、朝向 +Z。stage-01 的草地就是它。

### 构造参数

```js
new THREE.PlaneGeometry(width, height, widthSegments, heightSegments)
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `width` | X 轴方向宽度 | 1 |
| `height` | Y 轴方向高度 | 1 |
| `widthSegments` | X 轴方向分段数 | 1 |
| `heightSegments` | Y 轴方向分段数 | 1 |

### 示例

```js
import * as THREE from "three";

// 40m × 40m 草地（stage-01 使用）
const grass = new THREE.PlaneGeometry(40, 40);
const grassMat = new THREE.MeshStandardMaterial({
  color: 0x67c23a,            // Element Plus 成功绿
  side: THREE.DoubleSide,     // 双面可见
});
const grassMesh = new THREE.Mesh(grass, grassMat);
grassMesh.rotation.x = -Math.PI / 2; // 绕 X 轴旋转 -90°，躺平成地面
scene.add(grassMesh);

// 高分段平面（用于水面波浪 shader）
const water = new THREE.PlaneGeometry(20, 20, 128, 128);
```

::: tip 为什么要用 DoubleSide
平面默认只渲染正面（FrontSide）。当你旋转到背面时会"消失"。设置 `side: THREE.DoubleSide` 可让正反两面都渲染，适用于地面、墙壁、树叶等薄片物体，但会增加少量性能开销。
:::

## 4. CircleGeometry 圆形

`CircleGeometry` 创建圆形或扇形平面，本质是一个被等分的圆盘。

### 构造参数

```js
new THREE.CircleGeometry(radius, segments, thetaStart, thetaLength)
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `radius` | 圆形半径 | 1 |
| `segments` | 分段数（越大越圆滑） | 8 |
| `thetaStart` | 起始角度（弧度） | 0 |
| `thetaLength` | 圆弧跨度（默认 2π 为整圆） | Math.PI * 2 |

### 示例

```js
import * as THREE from "three";

// 整圆（半径 1，64 分段足够平滑）
const circle = new THREE.CircleGeometry(1, 64);

// 半圆扇形（起始 0，跨度 π）
const half = new THREE.CircleGeometry(1, 64, 0, Math.PI);

// 1/4 扇形（90 度）
const quarter = new THREE.CircleGeometry(1, 64, 0, Math.PI / 2);
```

::: warning 默认分段过低
`segments` 默认值 8 会导致圆形呈明显八边形。一般设置为 32 或 64 即可获得平滑外观。超过 128 后视觉提升有限，但顶点数线性增加。
:::

## 5. ConeGeometry 圆锥

`ConeGeometry` 创建圆锥体，本质是顶半径为 0 的圆柱。stage-04 的尖屋顶可以用它实现（4 段 + 旋转 45° 得四棱锥）。

### 构造参数

```js
new THREE.ConeGeometry(radius, height, radialSegments, heightSegments, openEnded, thetaStart, thetaLength)
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `radius` | 底面半径 | 1 |
| `height` | 圆锥高度 | 1 |
| `radialSegments` | 圆周分段数 | 8 |
| `heightSegments` | 高度分段数 | 1 |
| `openEnded` | 是否开口（无底面） | false |
| `thetaStart` / `thetaLength` | 圆弧起始/跨度 | 0 / 2π |

### 示例

```js
import * as THREE from "three";

// 标准圆锥（底半径 0.6，高 1.2，32 段）
const cone = new THREE.ConeGeometry(0.6, 1.2, 32);

// 开口圆锥（无底面，像漏斗）
const funnel = new THREE.ConeGeometry(1, 2, 32, 1, true);

// 四棱锥（4 段），可用于尖屋顶
const pyramid = new THREE.ConeGeometry(3, 2, 4);
pyramid.rotateY(Math.PI / 4); // 旋转 45° 让平面朝前
```

## 6. CylinderGeometry 圆柱

`CylinderGeometry` 创建圆柱或圆台，可分别指定顶部和底部半径。stage 后续做装饰柱、烟囱顶部时会用到。

### 构造参数

```js
new THREE.CylinderGeometry(radiusTop, radiusBottom, height, radialSegments, heightSegments, openEnded, thetaStart, thetaLength)
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `radiusTop` | 顶面半径 | 1 |
| `radiusBottom` | 底面半径 | 1 |
| `height` | 圆柱高度 | 1 |
| `radialSegments` | 圆周分段数 | 8 |
| `heightSegments` | 高度分段数 | 1 |
| `openEnded` | 是否开口（无顶底面） | false |

### 示例

```js
import * as THREE from "three";

// 标准圆柱（顶底等径）
const cylinder = new THREE.CylinderGeometry(0.5, 0.5, 1.2, 32);

// 圆台（顶小底大，类似水杯）
const cup = new THREE.CylinderGeometry(0.6, 1, 2, 32);

// 倒置圆锥（顶半径 0，底半径 1，等价 ConeGeometry）
const invertedCone = new THREE.CylinderGeometry(0, 1, 2, 32);
```

## 7. TorusGeometry 圆环

`TorusGeometry` 创建甜甜圈状的圆环（救生圈）。

### 构造参数

```js
new THREE.TorusGeometry(radius, tube, radialSegments, tubularSegments, arc)
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `radius` | 圆环中心到管子中心的距离 | 1 |
| `tube` | 管子半径 | 0.4 |
| `radialSegments` | 管子截面分段数 | 12 |
| `tubularSegments` | 圆环周向分段数 | 48 |
| `arc` | 圆弧跨度（默认 2π 整环） | Math.PI * 2 |

### 示例

```js
import * as THREE from "three";

// 标准甜甜圈
const torus = new THREE.TorusGeometry(0.5, 0.2, 16, 64);

// 细管手镯
const bracelet = new THREE.TorusGeometry(1.5, 0.05, 8, 128);

// 半环（C 形）
const halfTorus = new THREE.TorusGeometry(1, 0.4, 16, 64, Math.PI);
```

## 8. TorusKnotGeometry 环面纽结

`TorusKnotGeometry` 创建一个绕轴旋转的纽结曲线管，造型独特，常用于演示材质反射或环境贴图。

### 构造参数

```js
new THREE.TorusKnotGeometry(radius, tube, tubularSegments, radialSegments, p, q)
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `radius` | 纽结中心到管中心的距离 | 1 |
| `tube` | 管子半径 | 0.4 |
| `tubularSegments` | 沿曲线的分段数 | 64 |
| `radialSegments` | 管子截面分段数 | 8 |
| `p` | 绕对称轴旋转的圈数 | 2 |
| `q` | 绕轴线旋转的圈数 | 3 |

### 示例

```js
import * as THREE from "three";

// 标准环面纽结
const knot = new THREE.TorusKnotGeometry(1, 0.3, 128, 16);

// 改变 p、q 可得到不同拓扑的纽结
const knot2 = new THREE.TorusKnotGeometry(1, 0.3, 128, 16, 3, 4);
```

::: tip p 与 q 必须互质
当 `p` 和 `q` 互质（最大公约数为 1）时，曲线会闭合形成单一纽结；否则会形成多个独立的环。
:::

## 9. TubeGeometry 管道

`TubeGeometry` 沿一条 3D 曲线路径创建管道，常用于管道、绳索、霓虹灯管、道路等。

### 构造参数

```js
new THREE.TubeGeometry(path, tubularSegments, radius, radialSegments, closed)
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `path` | 3D 曲线路径（继承自 `Curve`） | - |
| `tubularSegments` | 管道路径分段数 | 64 |
| `radius` | 管道半径 | 1 |
| `radialSegments` | 管道横截面分段数 | 8 |
| `closed` | 是否闭合（首尾相连） | false |

### 示例

```js
import * as THREE from "three";

// 使用内置 CatmullRom 样条曲线
const points = [
  new THREE.Vector3(-2, 0, 0),
  new THREE.Vector3(-1, 1, 1),
  new THREE.Vector3(1, -1, 1),
  new THREE.Vector3(2, 0, 0),
];
const curve = new THREE.CatmullRomCurve3(points);

const tube = new THREE.TubeGeometry(curve, 100, 0.15, 16, false);
```

::: tip 内置曲线类
除自定义 `Curve` 外，Three.js 还提供：
- `THREE.CatmullRomCurve3`：经过一组点的平滑样条曲线
- `THREE.CubicBezierCurve3`：三次贝塞尔曲线
- `THREE.QuadraticBezierCurve3`：二次贝塞尔曲线
- `THREE.LineCurve3`：直线
:::

## 10. ExtrudeGeometry 挤压

`ExtrudeGeometry` 将 2D `Shape` 沿 Z 轴挤压成 3D 模型，是制作立体文字、徽标、按钮、山墙的利器。

### extrudeSettings 参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `depth` | 挤压深度 | 1 |
| `bevelEnabled` | 是否启用斜角（倒角） | true |
| `bevelThickness` | 斜角厚度 | 0.2 |
| `bevelSize` | 斜角尺寸 | 0.1 |
| `bevelSegments` | 斜角分段数 | 3 |
| `steps` | 挤压方向分段数 | 1 |

### 示例

```js
import * as THREE from "three";

// 创建星形 2D 形状
const shape = new THREE.Shape();
const outerRadius = 1;
const innerRadius = 0.4;
const points = 5;
for (let i = 0; i < points * 2; i++) {
  const angle = (i / (points * 2)) * Math.PI * 2;
  const r = i % 2 === 0 ? outerRadius : innerRadius;
  const x = Math.cos(angle) * r;
  const y = Math.sin(angle) * r;
  if (i === 0) shape.moveTo(x, y);
  else shape.lineTo(x, y);
}

const extrudeSettings = {
  depth: 0.5,
  bevelEnabled: true,
  bevelThickness: 0.1,
  bevelSize: 0.1,
  bevelSegments: 3,
};

const star = new THREE.ExtrudeGeometry(shape, extrudeSettings);
const material = new THREE.MeshStandardMaterial({
  color: 0xe6a23c,        // Element Plus 警告色（金色）
  metalness: 0.8,
  roughness: 0.2,
});
const starMesh = new THREE.Mesh(star, material);
scene.add(starMesh);
```

::: tip 斜角的作用
`bevelEnabled` 启用后，挤压出的 3D 模型边缘会有圆滑倒角，让物体看起来更精致。关闭斜角（`bevelEnabled: false`）则边缘锐利，适合硬朗的工业风格。
:::

## 11. ShapeGeometry 2D 形状

`ShapeGeometry` 将 `THREE.Shape` 定义的 2D 路径直接转为平面几何体（不挤压）。它类似 Canvas 2D 的路径 API，支持贝塞尔曲线、圆弧等。

### 构造参数

```js
new THREE.ShapeGeometry(shapes, curveSegments)
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `shapes` | 一个 `Shape` 或 `Shape` 数组 | - |
| `curveSegments` | 曲线分段数（越大越平滑） | 12 |

### 示例

```js
import * as THREE from "three";

// 自定义心形
const heart = new THREE.Shape();
heart.moveTo(0, 0);
heart.bezierCurveTo(0, 0.5, -0.5, 0.8, -1, 0.3);
heart.bezierCurveTo(-1.5, -0.2, -0.8, -0.8, 0, -1);
heart.bezierCurveTo(0.8, -0.8, 1.5, -0.2, 1, 0.3);
heart.bezierCurveTo(0.5, 0.8, 0, 0.5, 0, 0);

const geometry = new THREE.ShapeGeometry(heart);
const material = new THREE.MeshBasicMaterial({
  color: 0xf56c6c,            // Element Plus 危险色（红色心形）
  side: THREE.DoubleSide,
});
const heartMesh = new THREE.Mesh(geometry, material);
scene.add(heartMesh);
```

::: tip THREE.Shape 常用方法
- `moveTo(x, y)`：移动到起始点
- `lineTo(x, y)`：绘制直线
- `bezierCurveTo(c1x, c1y, c2x, c2y, x, y)`：三次贝塞尔曲线
- `quadraticCurveTo(cx, cy, x, y)`：二次贝塞尔曲线
- `absarc(x, y, radius, startAngle, endAngle)`：绘制圆弧
:::

## 12. LatheGeometry 车削

`LatheGeometry` 类似车床加工：将一组 2D 点绕 Y 轴旋转一周，生成回转体（花瓶、酒杯、瓶子等）。欧式小屋的装饰柱头、栏杆球头都可用它。

### 构造参数

```js
new THREE.LatheGeometry(points, segments, phiStart, phiLength)
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `points` | 2D 点数组（`Vector2`，按 y 升序） | - |
| `segments` | 圆周分段数 | 12 |
| `phiStart` / `phiLength` | 旋转起始/跨度 | 0 / 2π |

### 示例

```js
import * as THREE from "three";

// 定义花瓶轮廓（从下到上）
const points = [];
for (let i = 0; i <= 10; i++) {
  const t = i / 10;
  // 半径随高度变化：底部小、中部鼓、顶部收口
  const r = Math.sin(t * Math.PI) * 0.8 + 0.2;
  points.push(new THREE.Vector2(r, t * 2));
}

const vase = new THREE.LatheGeometry(points, 64);
const material = new THREE.MeshStandardMaterial({
  color: 0x409eff,           // Element Plus 主色（青花瓷）
  metalness: 0.1,
  roughness: 0.3,
});
const vaseMesh = new THREE.Mesh(vase, material);
scene.add(vaseMesh);
```

::: warning points 必须按 y 升序
`LatheGeometry` 要求 `points` 数组按 y 坐标从小到大排列，否则生成的法线方向会出错，导致光照异常。
:::

## 13. RingGeometry 圆环面

`RingGeometry` 创建一个平面圆环（带孔的扁圆盘），介于 `CircleGeometry` 与 `TorusGeometry` 之间。

### 构造参数

```js
new THREE.RingGeometry(innerRadius, outerRadius, thetaSegments, phiSegments, thetaStart, thetaLength)
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `innerRadius` | 内半径 | 0.5 |
| `outerRadius` | 外半径 | 1 |
| `thetaSegments` | 圆周分段数 | 8 |
| `phiSegments` | 径向（半径方向）分段数 | 1 |
| `thetaStart` / `thetaLength` | 圆弧起始/跨度 | 0 / 2π |

### 示例

```js
import * as THREE from "three";

// 标准圆环面（光盘）
const ring = new THREE.RingGeometry(0.5, 1, 64);

// 多层径向分段（适合径向渐变贴图）
const layered = new THREE.RingGeometry(0.3, 1, 64, 8);

// 半环（C 形光盘）
const halfRing = new THREE.RingGeometry(0.5, 1, 32, 1, 0, Math.PI);

const material = new THREE.MeshBasicMaterial({
  color: 0x909399,           // Element Plus 信息色（灰色）
  side: THREE.DoubleSide,
});
const ringMesh = new THREE.Mesh(ring, material);
scene.add(ringMesh);
```

## 在场景里摆放预览（本阶段源码片段）

下面是 `HouseScene.vue` 里「几何体预览」部分的核心代码。5 件代表物体在远处 z = -8 排成一行，X 坐标从 -6 到 6，间距 3m，颜色用 Element Plus 五色调色：

```js
import * as THREE from "three";

const previewY = 0.5;   // 让物体坐于草地之上
const previewZ = -8;    // 远处一排

// (1) BoxGeometry 立方体 —— 主色蓝 #409eff
const boxMesh = new THREE.Mesh(
  new THREE.BoxGeometry(1, 1, 1),
  new THREE.MeshStandardMaterial({ color: 0x409eff, roughness: 0.5, metalness: 0.1 })
);
boxMesh.position.set(-6, previewY, previewZ);
scene.add(boxMesh);

// (2) SphereGeometry 球体 —— 成功绿 #67c23a
const sphereMesh = new THREE.Mesh(
  new THREE.SphereGeometry(0.6, 32, 16),
  new THREE.MeshStandardMaterial({ color: 0x67c23a, roughness: 0.4, metalness: 0.1 })
);
sphereMesh.position.set(-3, previewY, previewZ);
scene.add(sphereMesh);

// (3) ConeGeometry 圆锥 —— 警告黄 #e6a23c
const coneMesh = new THREE.Mesh(
  new THREE.ConeGeometry(0.6, 1.2, 32),
  new THREE.MeshStandardMaterial({ color: 0xe6a23c, roughness: 0.5, metalness: 0.1 })
);
coneMesh.position.set(0, previewY, previewZ);
scene.add(coneMesh);

// (4) CylinderGeometry 圆柱 —— 危险红 #f56c6c
const cylinderMesh = new THREE.Mesh(
  new THREE.CylinderGeometry(0.5, 0.5, 1.2, 32),
  new THREE.MeshStandardMaterial({ color: 0xf56c6c, roughness: 0.5, metalness: 0.1 })
);
cylinderMesh.position.set(3, previewY, previewZ);
scene.add(cylinderMesh);

// (5) TorusGeometry 圆环 —— 信息灰 #909399
const torusMesh = new THREE.Mesh(
  new THREE.TorusGeometry(0.5, 0.2, 16, 64),
  new THREE.MeshStandardMaterial({ color: 0x909399, roughness: 0.4, metalness: 0.1 })
);
torusMesh.position.set(6, previewY, previewZ);
torusMesh.rotation.x = Math.PI / 2; // 立起来更像甜甜圈
scene.add(torusMesh);
```

::: warning 共享 geometry / material 的 dispose 陷阱
如果多个 Mesh 共用同一份 geometry 或 material（例如本阶段的两级台阶），dispose 时只能调用一次。重复 dispose 同一对象不会报错，但是无意义且可能在某些 Three.js 版本里触发警告。`HouseScene.vue` 用一个 `disposableGeometries` / `disposableMaterials` 数组登记，确保每份资源只 push 一次，清理时只释放一次。
:::

## 本节总结

本节系统介绍了 Three.js **13 种内置几何体**：

1. **BufferGeometry** 是所有几何体的基类，通过 `position`/`normal`/`uv`/`index`/`color` 描述形状
2. **立方体类**：`BoxGeometry`（地基、台阶、墙体）
3. **球体类**：`SphereGeometry`（粒子、穹顶）
4. **平面类**：`PlaneGeometry`（草地）、`CircleGeometry`（圆形）、`RingGeometry`（圆环面）
5. **锥柱类**：`ConeGeometry`（尖屋顶）、`CylinderGeometry`（柱子、烟囱）
6. **圆环类**：`TorusGeometry`（甜甜圈）、`TorusKnotGeometry`（纽结）
7. **管道类**：`TubeGeometry`（沿曲线管道）
8. **由 2D 生成 3D 类**：`ExtrudeGeometry`（挤压）、`ShapeGeometry`（2D 形状）、`LatheGeometry`（车削）
9. **分段数** 影响平滑度与顶点数，需在视觉与性能间权衡

掌握了这 13 把「积木」，我们就可以开始砌地基了。下一节将用最朴素的 `BoxGeometry` 推算地基平台的尺寸与位置，让它的底面稳稳贴在草地上。
