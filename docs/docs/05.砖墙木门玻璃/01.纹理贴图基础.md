# 纹理贴图基础：从 TextureLoader 到 UV 映射的完整链路

在第 04 阶段，小屋的所有表面都是纯色——`color: 0xe6d5b8` 让整面墙是一块均匀的米色。真实世界的墙面不会这样：砖块有缝隙、木材有年轮、瓦片有重叠。让纯色表面变成有细节的真实表面，靠的就是**纹理贴图（Texture Mapping）**。

本节是贴图章节的理论地基：一次讲清 TextureLoader / CanvasTexture、UV 映射、wrapS/wrapT、repeat/offset、filter、anisotropy、colorSpace、dispose 这一整套概念。学完本节，你就能看懂后续砖墙、木纹、瓦片贴图代码里的每一行配置在做什么。

## 一、什么是纹理贴图

**纹理（Texture）** 是一张 2D 图片（或程序化生成的图像数据），被"贴"到 3D 几何体的表面上，让表面呈现出图片中的图案。把纹理贴到几何体上的过程叫**纹理映射（Texture Mapping）**。

在 Three.js 里，纹理通过材质的 `map` 属性传入：

```js
import * as THREE from "three";

// 创建一张纹理（这里先用 TextureLoader 加载外部图片，后面会改用 CanvasTexture）
const texture = new THREE.TextureLoader().load("/textures/brick.png");

// 把纹理贴到材质上
const material = new THREE.MeshStandardMaterial({
  color: 0xffffff, // 用贴图时 color 设白，避免染色
  map: texture, // 纹理贴图
});

const mesh = new THREE.Mesh(geometry, material);
```

`map` 是材质最常用的贴图通道，它替代了纯色 `color`，让表面显示图片内容。除了 `map`（漫反射贴图），Three.js 还支持 `normalMap`（法线贴图）、`roughnessMap`（粗糙度贴图）、`metalnessMap`（金属度贴图）、`envMap`（环境贴图）等多种贴图通道，本阶段只讲 `map`。

## 二、两种创建纹理的方式

### 1. TextureLoader：加载外部图片

```js
import * as THREE from "three";

// TextureLoader 异步加载图片文件，返回 Texture 对象
const loader = new THREE.TextureLoader();
const texture = loader.load("/textures/brick.png", (tex) => {
  // 加载完成回调
  tex.colorSpace = THREE.SRGBColorSpace;
  tex.wrapS = THREE.RepeatWrapping;
  tex.wrapT = THREE.RepeatWrapping;
  tex.needsUpdate = true;
});
```

`TextureLoader` 适合加载美术准备的 .jpg/.png 图片，但需要**额外准备图片文件**。本阶段为了让快照自包含、复制即运行，**不使用 TextureLoader**，改用下面的 CanvasTexture。

### 2. CanvasTexture：程序化生成（本阶段核心）

```js
import * as THREE from "three";

// 1) 创建一个 canvas，用 2D API 画图案
const canvas = document.createElement("canvas");
canvas.width = 256;
canvas.height = 256;
const ctx = canvas.getContext("2d");
ctx.fillStyle = "#e6d5b8";
ctx.fillRect(0, 0, 256, 256);
// ... 画砖缝、木纹等细节

// 2) 用 CanvasTexture 包装成 Three.js 纹理
const texture = new THREE.CanvasTexture(canvas);
texture.wrapS = THREE.RepeatWrapping;
texture.wrapT = THREE.RepeatWrapping;
texture.repeat.set(4, 2);
texture.colorSpace = THREE.SRGBColorSpace;
```

`CanvasTexture` 把一个 `<canvas>` 元素当作纹理源。只要能在 canvas 上画出来，就能贴到 3D 物体上。本阶段的砖墙、木纹、瓦片、天空盒全部用这种方式生成，**零外部图片依赖**。

::: tip 为什么本阶段用 CanvasTexture
三个原因：① 快照自包含——不需要在项目里放 .png 文件，复制即运行；② 可参数化——改几行代码就能调整砖块大小、木纹密度；③ 教学价值高——你亲手看到"画布像素 → 3D 纹理"的完整映射过程。实际项目中美术资源会用 TextureLoader 加载 .jpg/.png，但理解 CanvasTexture 后你会对纹理机制有更深的把握。
:::

## 三、UV 映射：纹理如何"贴"到几何体上

纹理是一张 2D 图片，几何体是 3D 的。把 2D 图片贴到 3D 表面，靠的是 **UV 坐标**——每个顶点除了有 3D 位置坐标 (x,y,z)，还有一组 2D 纹理坐标 (u,v)，告诉纹理"这个顶点对应图片的哪个位置"。

UV 坐标的范围是 `[0, 1]`：左下角 (0,0)、右下角 (1,0)、左上角 (0,1)、右上角 (1,1)。Three.js 的内置几何体（BoxGeometry、PlaneGeometry 等）都自带默认 UV：

```js
import * as THREE from "three";

// BoxGeometry 的每个面默认 UV 都是 (0,0)~(1,1)
// 即每个面完整铺满一张纹理
const box = new THREE.BoxGeometry(8, 3, 0.2);
// box.attributes.uv 包含每个顶点的 UV 坐标
console.log(box.attributes.uv); // Float32BufferAttribute
```

可以这样理解：纹理图片的左下角对应面的左下顶点，右上角对应面的右上顶点，中间线性插值。所以一面墙贴一张砖墙纹理，纹理就铺满整面墙。

::: warning UV 是顶点属性，不是材质属性
UV 坐标存储在**几何体**的 `attributes.uv` 里，不是材质的属性。同一个材质贴到不同几何体上，UV 不同，纹理呈现方式就不同。如果你想自定义纹理在表面上的排列方式，可以修改几何体的 UV，或者用下面要讲的 `repeat` / `offset`。
:::

## 四、wrapS / wrapT：超出 [0,1] 的 UV 怎么办

当 UV 超出 `[0,1]` 范围（因为 `repeat` 让 UV 乘了一个倍数），纹理该如何采样？这就是 `wrapS`（U 方向）和 `wrapT`（V 方向）控制的：

```js
import * as THREE from "three";

const texture = new THREE.CanvasTexture(canvas);

// 三种包裹模式：
texture.wrapS = THREE.RepeatWrapping; // 重复平铺（墙面、屋顶用）
texture.wrapT = THREE.RepeatWrapping;

// texture.wrapS = THREE.ClampToEdgeWrapping; // 边缘像素拉伸（门板用）
// texture.wrapT = THREE.ClampToEdgeWrapping;

// texture.wrapS = THREE.MirroredRepeatWrapping; // 镜像重复（少用）
// texture.wrapT = THREE.MirroredRepeatWrapping;
```

| 模式 | 效果 | 适用场景 |
|------|------|----------|
| `RepeatWrapping` | 超出部分重复平铺纹理 | 砖墙、瓦片、地板等可重复图案 |
| `ClampToEdgeWrapping` | 超出部分用边缘像素拉伸 | 门板、海报等单幅不可重复图案 |
| `MirroredRepeatWrapping` | 超出部分镜像翻转后平铺 | 需要无缝对称的特殊图案 |

本阶段砖墙和瓦片用 `RepeatWrapping`（让砖块无限平铺），木门用 `ClampToEdgeWrapping`（一扇门就是一块木板，不重复）。

## 五、repeat / offset：平铺次数与平移

### repeat：纹理重复多少次

```js
// repeat 是 Vector2，set(u, v)
texture.repeat.set(4, 2);
// U 方向重复 4 次，V 方向重复 2 次
// 配合 RepeatWrapping，纹理在每个面上平铺 4×2=8 次
```

`repeat` 让 UV 乘以一个倍数。配合 `RepeatWrapping`，纹理会在表面上重复平铺。本阶段砖墙 `repeat(4,2)`——每面墙显示 4×2 个砖块图案；瓦片 `repeat(6,4)`——屋顶瓦片更密集。

### offset：纹理平移

```js
// offset 也是 Vector2，set(u, v)
texture.offset.set(0.5, 0);
// U 方向平移半个纹理宽度
```

`offset` 让纹理在表面上滑动，常用于动画（如流水、传送带）或微调对齐。本阶段用默认 `(0,0)`，但理解它有助于你调试"砖缝没对齐"这类问题。

::: tip repeat 改变后要 needsUpdate 吗
`repeat`、`offset`、`wrapS`、`wrapT` 是纹理的运行时属性，**修改后立即生效**，不需要 `needsUpdate`。只有修改了纹理的**图像数据**（如重绘 canvas）才需要 `texture.needsUpdate = true`。
:::

## 六、minFilter / magFilter：纹理缩放怎么采样

纹理在屏幕上的显示大小很少和原始分辨率一致——远处的墙纹理被缩小（minification），近处的纹理被放大（magnification）。这两种情况用什么算法采样，由 `minFilter` 和 `magFilter` 控制：

```js
import * as THREE from "three";

const texture = new THREE.CanvasTexture(canvas);

// minFilter：纹理被缩小时（物体远）的采样方式
texture.minFilter = THREE.LinearMipmapLinearFilter; // 三线性 + Mipmap，最平滑（推荐）

// magFilter：纹理被放大时（物体近）的采样方式
texture.magFilter = THREE.LinearFilter; // 双线性，平滑（推荐）
```

### minFilter 的 6 种选项

| 常量 | 采样方式 | 效果 | 性能 |
|------|----------|------|------|
| `NearestFilter` | 最近邻 | 锐利但有锯齿（像素风） | 最快 |
| `LinearFilter` | 双线性 | 平滑，远距离会闪烁 | 快 |
| `NearestMipmapNearestFilter` | 最近邻 + 最近 Mipmap | 锐利，远距离不闪 | 中 |
| `LinearMipmapNearestFilter` | 双线性 + 最近 Mipmap | 平滑，远距离不闪 | 中 |
| `NearestMipmapLinearFilter` | 最近邻 + 三线性 Mipmap | 锐利且远距离平滑 | 中慢 |
| `LinearMipmapLinearFilter` | 三线性（双线性 + 三线性 Mipmap） | 最平滑（推荐） | 慢 |

### magFilter 的 2 种选项

| 常量 | 采样方式 | 效果 |
|------|----------|------|
| `NearestFilter` | 最近邻 | 像素风（Minecraft 风格） |
| `LinearFilter` | 双线性 | 平滑（推荐，默认） |

::: tip 什么是 Mipmap
Mipmap 是纹理的"金字塔"——原始纹理 + 逐级缩小的副本（1/2、1/4、1/8...）。当物体很远时，GPU 直接采样合适大小的 Mipmap 层级，避免远距离闪烁。`LinearMipmapLinearFilter`（三线性过滤）在两个相邻 Mipmap 层级间再做双线性插值，是最平滑的方案。代价是 Mipmap 占用额外 1/3 显存。
:::

::: warning Mipmap 与 repeat 的注意点
使用 Mipmap（即 minFilter 含 Mipmap）时，纹理的宽高最好是 **2 的幂**（256、512、1024 等），否则部分 GPU 不生成 Mipmap。本阶段的 canvas 都是 256×256 或 256×512，满足要求。非 2 的幂纹理（NPOT）会被强制设为 `ClampToEdgeWrapping` 且不生成 Mipmap。
:::

## 七、anisotropy：各向异性过滤

当纹理表面与视线成**斜角**时（如地面延伸到远处、墙面斜着看），普通过滤会让纹理明显模糊。**各向异性过滤（Anisotropic Filtering）** 通过沿视线方向多次采样，缓解斜视角模糊：

```js
import * as THREE from "three";

// 获取当前 GPU 支持的最大各向异性等级（通常 4~16）
const maxAniso = renderer.capabilities.getMaxAnisotropy();

texture.anisotropy = maxAniso; // 拉满
```

效果对比：站在房子一角斜看墙面，`anisotropy = 1`（关闭）时远处砖缝模糊成一片；`anisotropy = maxAniso`（开启）时远处砖缝依然清晰。本阶段对砖墙、木纹、瓦片三张贴图都设置了 `anisotropy = maxAniso`。

::: tip anisotropy 的值
`anisotropy` 是一个整数，范围 1~maxAniso。1 = 关闭各向异性，值越大效果越好但越耗性能。通常直接拉满 `maxAniso` 即可，现代 GPU 上性能开销很小。移动端可适当降低到 4 或 8。
:::

## 八、colorSpace：颜色空间

纹理分两类：**颜色纹理**（砖墙、木纹、天空——人眼看的颜色）和**数据纹理**（法线贴图、粗糙度贴图——存的是数据不是颜色）。两类纹理的 colorSpace 不同：

```js
import * as THREE from "three";

// 颜色纹理：设 sRGB，让颜色显示正确（否则会发灰）
brickTexture.colorSpace = THREE.SRGBColorSpace;

// 数据纹理：保持 NoColorSpace（线性），不要设 sRGB
normalTexture.colorSpace = THREE.NoColorSpace; // 默认值
```

如果忘了给颜色纹理设 `SRGBColorSpace`，砖墙会看起来比预期灰暗——因为 Three.js 默认把纹理当作线性数据处理，而图片文件是 sRGB 编码的。设置 `colorSpace = SRGBColorSpace` 后，Three.js 会在采样时自动做 sRGB → 线性的转换，颜色才正确。

同时，渲染器也要设输出颜色空间：

```js
// 输出颜色空间设为 sRGB（0.169 默认即为 sRGB，显式写出便于教学）
renderer.outputColorSpace = THREE.SRGBColorSpace;
```

本阶段所有颜色纹理（砖墙、木纹、瓦片、天空）都设了 `SRGBColorSpace`，渲染器输出也设了 `SRGBColorSpace`。

## 九、dispose：纹理也要释放

和 geometry / material 一样，纹理也占用 GPU 显存，组件卸载时必须释放。但有个**重要细节**：`material.dispose()` **不会**自动释放其 `map` 引用的纹理——纹理可能被多个材质共享，Three.js 不敢擅自释放。所以纹理要单独 dispose：

```js
// 收集所有 texture
const textures = [];
textures.push(brickTex, woodTex, tileTex, skyTex);

// 卸载时统一释放
const disposeScene = () => {
  // 1) 释放 geometry / material（同前几阶段）
  disposables.forEach((obj) => {
    if (obj.geometry) obj.geometry.dispose();
    if (obj.material) obj.material.dispose();
  });

  // 2) 单独释放纹理（关键！material.dispose() 不会释放 map）
  textures.forEach((t) => t.dispose());
  textures.length = 0;
};
```

::: warning 常见内存泄漏
新手常犯的错：只 dispose 了 material，忘了 dispose texture。结果切换场景时几何体和材质释放了，但纹理还留在显存里——多次切换后显存溢出崩溃。记住：**每张纹理都要配对一个 dispose**。
:::

## 十、本节总结

- **纹理**是贴在几何体表面的 2D 图片，通过材质的 `map` 属性传入
- 创建纹理有两条路：`TextureLoader`（加载外部图片）和 `CanvasTexture`（程序化生成）。本阶段全用 CanvasTexture，快照自包含
- **UV 映射**把 2D 纹理坐标 `[0,1]` 对应到 3D 顶点，几何体自带的 `attributes.uv` 决定贴图方式
- **wrapS/wrapT** 控制 UV 超出 `[0,1]` 时的采样：`RepeatWrapping` 平铺（砖墙）、`ClampToEdgeWrapping` 拉伸（门板）
- **repeat/offset** 控制平铺次数和纹理平移，是运行时属性，改了立即生效
- **minFilter/magFilter** 控制缩放采样：推荐 `LinearMipmapLinearFilter` + `LinearFilter`（三线性+双线性）
- **anisotropy** 缓解斜视角模糊，直接拉满 `getMaxAnisotropy()`
- **colorSpace**：颜色纹理设 `SRGBColorSpace`，数据纹理保持 `NoColorSpace`
- **dispose**：纹理要单独释放，`material.dispose()` 不会自动释放其 `map`
