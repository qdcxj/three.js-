# 砖墙木门贴图：用 Canvas 2D 程序化生成纹理

理解了纹理贴图的理论后，本节动手画两张真实纹理：**砖墙**和**木纹**。我们用 Canvas 2D API 在 `<canvas>` 上画好图案，再用 `THREE.CanvasTexture` 包装成 Three.js 纹理，最后应用到外墙和门板的 `map` 属性——纯色小屋瞬间变成有质感的砖墙木门小屋。

本节的关键不是 Canvas 绘图 API（那是前端基础），而是**如何让画出来的图案在 3D 表面上无缝重复**——这考验你对 `RepeatWrapping`、`repeat`、UV 映射的理解。

## 一、砖墙纹理：running bond 错缝

### 1. 砖墙的视觉特征

欧式乡村小屋的外墙是**砌砖墙（Brick Wall）**，视觉上有三个特征：

1. **砖缝网格**：砖块之间有较深的缝隙（mortar joint），形成网格线
2. **running bond 错缝**：相邻行的竖缝错开半块砖，不上下对齐
3. **砖块色差**：每块砖颜色略有差异（烧制温度不同），不死板

### 2. Canvas 2D 绘制策略

绘制思路：先填砖缝色（深米色）作底，再逐块画砖（暖米色 + 随机亮度），留出 2px 缝隙形成网格：

```js
import * as THREE from "three";

const createBrickTexture = () => {
  const size = 256; // 画布尺寸（正方形，便于 RepeatWrapping 无缝）
  const cols = 4; // 砖块列数
  const rows = 8; // 砖块行数
  const bw = size / cols; // 每块砖宽 64px
  const bh = size / rows; // 每块砖高 32px
  const seam = 2; // 砖缝宽度 2px

  const canvas = document.createElement("canvas");
  canvas.width = size;
  canvas.height = size;
  const ctx = canvas.getContext("2d");

  // 1) 先整体填砖缝颜色（深米色），后续画砖时留出 seam 即形成网格线
  ctx.fillStyle = "#a89878"; // 砖缝色（比砖体深）
  ctx.fillRect(0, 0, size, size);

  // 2) 逐块画砖：暖米色 #e6d5b8 = rgb(230,213,184)，每块加轻微随机亮度
  for (let r = 0; r < rows; r++) {
    // running bond：奇数行水平偏移半块，让竖缝错开
    const offset = (r % 2) * (bw / 2);
    // c 从 -1 到 cols，确保画布左右边缘出现半块砖，RepeatWrapping 拼接后形成整块
    for (let c = -1; c <= cols; c++) {
      const x = c * bw + offset + seam / 2;
      const y = r * bh + seam / 2;
      const w = bw - seam;
      const h = bh - seam;
      // 轻微随机亮度变化（±15），让每块砖不死板
      const v = Math.floor(Math.random() * 30 - 15);
      ctx.fillStyle = `rgb(${230 + v}, ${213 + v}, ${184 + v})`;
      ctx.fillRect(x, y, w, h);
    }
  }

  // 3) 转 CanvasTexture
  const texture = new THREE.CanvasTexture(canvas);
  texture.wrapS = THREE.RepeatWrapping;
  texture.wrapT = THREE.RepeatWrapping;
  texture.repeat.set(4, 2); // 每个面重复 4×2 次
  texture.colorSpace = THREE.SRGBColorSpace;
  return texture;
};
```

### 3. 为什么 c 从 -1 到 cols

这是让纹理**无缝拼接**的关键。奇数行偏移了半块砖（32px），导致画布左边缘有一个"半块砖"。如果只画 `c=0` 到 `c=cols-1`，左边缘的半块砖就缺失了，RepeatWrapping 拼接时会出现错位。

让 `c` 从 `-1` 开始，多画一块在画布左侧外的砖，它的右半部分会出现在画布左边缘——正好和右侧边缘的半块砖（`c=cols`）在拼接时组成完整的一块。这就是无缝纹理的核心：**画布边缘的图案在拼接处必须连续**。

::: tip 无缝纹理的通用技巧
让画布包含**整数个重复单元**（本例 4 列 × 8 行砖），且偏移量是单元宽度的整数分之一（本例半块 = bw/2）。这样 RepeatWrapping 在画布边界处自然衔接。如果偏移量是 bw/3，就需要 3 行才完成一个周期，画布要包含 3 的倍数行。
:::

### 4. repeat(4,2) 的视觉效果

砖墙纹理 `repeat.set(4, 2)`：BoxGeometry 每个面的 UV 是 `[0,1]`，repeat(4,2) 让 UV 变成 `[0,4]×[0,2]`，配合 RepeatWrapping，纹理在每个面上平铺 4×2=8 次。每次平铺是 256×256 的画布（含 4×8=32 块砖），所以每面墙显示 4×2×32 = 256 块砖。

在后墙（8m×3m）上，256 块砖分布在 8m×3m 面积里，每块砖约 0.5m×0.19m——接近真实砖块比例。在小墙块（如门洞上方 0.2m 高的条）上，同样显示 256 块砖，砖就显得很小——这是共享材质的代价，但视觉上可接受。

## 二、应用到外墙材质

有了砖墙纹理，把它应用到 stage-04 的外墙材质上只需改一行：

```js
import * as THREE from "three";

const addWallsAndDoor = (houseGroup) => {
  // 外墙材质：stage-05 给 map 贴砖墙纹理。
  // 注意：使用 map 时 color 应设白色 0xffffff，避免对贴图二次染色。
  const wallMat = new THREE.MeshStandardMaterial({
    color: 0xffffff, // 白色 = 不染色，让砖墙纹理原色显示
    map: brickTex, // 砖墙 CanvasTexture
    roughness: 0.9,
    metalness: 0.0,
  });

  // 后续 block() 创建的所有墙块都共享 wallMat，自动获得砖墙纹理
  const block = (w, h, d, x, y, z) => {
    const m = new THREE.Mesh(new THREE.BoxGeometry(w, h, d), wallMat);
    m.position.set(x, y, z);
    houseGroup.add(m);
    return m;
  };

  block(8, 3, 0.2, 0, 1.8, -3); // 后墙
  // ... 其他墙块
};
```

### color 设白色的原因

`map` 的颜色会和材质的 `color` **相乘**。stage-04 没用贴图时 `color: 0xe6d5b8`（暖米色）让墙是米色；stage-05 用了砖墙纹理（纹理本身已是米色），如果 `color` 还是 `0xe6d5b8`，结果就是 `0xe6d5b8 × 纹理颜色`——纹理被染得更暗。所以用贴图时要把 `color` 设为 `0xffffff`（白色），让纹理原色显示。

```js
// ❌ 错误：color 染色，纹理变暗
const wallMat = new THREE.MeshStandardMaterial({
  color: 0xe6d5b8,
  map: brickTex,
});

// ✅ 正确：color 白色，纹理原色显示
const wallMat = new THREE.MeshStandardMaterial({
  color: 0xffffff,
  map: brickTex,
});
```

::: warning color 与 map 的乘法关系
`map` 不是替换 `color`，而是与 `color` 相乘。`color: 0xffffff`（白）× 任何颜色 = 原色；`color: 0xff0000`（红）× 任何颜色 = 只保留红色通道。所以想让纹理显示原色，`color` 必须是白色。想给纹理整体染色（如做夜视镜绿滤），可以设非白 color。
:::

## 三、木纹纹理：垂直条纹 + 木节

### 1. 木门的视觉特征

欧式小屋的木门是**实木板门**，视觉特征：

1. **垂直纹理**：木材年轮沿树干方向，门板纹理沿垂直方向（Y 轴）
2. **深浅条纹**：年轮有深有浅，呈不规则垂直条纹
3. **木节**：树枝生长点留下的圆形深色节疤

### 2. Canvas 2D 绘制策略

画布用 **256×512（竖向）**，匹配门板 1.0m×2.0m 的 1:2 宽高比，让纹理不变形：

```js
import * as THREE from "three";

const createWoodTexture = () => {
  const w = 256;
  const h = 512; // 竖向画布，匹配门板宽高比 1:2
  const canvas = document.createElement("canvas");
  canvas.width = w;
  canvas.height = h;
  const ctx = canvas.getContext("2d");

  // 1) 基色：木色 #8b5a2b = rgb(139,90,43)
  ctx.fillStyle = "#8b5a2b";
  ctx.fillRect(0, 0, w, h);

  // 2) 画 60 条垂直木纹：用正弦波模拟自然纹理的弯曲
  for (let i = 0; i < 60; i++) {
    const x = Math.random() * w; // 条纹基准 x
    const amp = Math.random() * 8 + 2; // 弯曲幅度
    const freq = Math.random() * 0.05 + 0.02; // 弯曲频率
    const alpha = Math.random() * 0.3 + 0.1; // 透明度
    const dark = Math.random() > 0.5;
    // 深纹（暗）与浅纹（亮）交替，模拟木材年轮的深浅
    ctx.strokeStyle = dark
      ? `rgba(80, 45, 20, ${alpha})`
      : `rgba(170, 120, 70, ${alpha})`;
    ctx.lineWidth = Math.random() * 2 + 0.5;
    ctx.beginPath();
    for (let y = 0; y < h; y += 2) {
      const xx = x + Math.sin(y * freq) * amp;
      if (y === 0) ctx.moveTo(xx, y);
      else ctx.lineTo(xx, y);
    }
    ctx.stroke();
  }

  // 3) 加 3 个木节（深色径向渐变椭圆），增加真实感
  for (let i = 0; i < 3; i++) {
    const cx = Math.random() * w;
    const cy = Math.random() * h;
    const rx = Math.random() * 15 + 8;
    const ry = rx * (0.6 + Math.random() * 0.4);
    const grad = ctx.createRadialGradient(cx, cy, 0, cx, cy, rx);
    grad.addColorStop(0, "rgba(60, 35, 15, 0.8)");
    grad.addColorStop(1, "rgba(60, 35, 15, 0)");
    ctx.fillStyle = grad;
    ctx.beginPath();
    ctx.ellipse(cx, cy, rx, ry, 0, 0, Math.PI * 2);
    ctx.fill();
  }

  // 4) 转 CanvasTexture
  const texture = new THREE.CanvasTexture(canvas);
  // 门板是单块木板，不需要重复平铺，用 ClampToEdgeWrapping（边缘拉伸）
  texture.wrapS = THREE.ClampToEdgeWrapping;
  texture.wrapT = THREE.ClampToEdgeWrapping;
  texture.repeat.set(1, 1); // 不重复
  texture.colorSpace = THREE.SRGBColorSpace;
  return texture;
};
```

### 3. 为什么木门用 ClampToEdgeWrapping

门板是**一整块木板**，纹理不应该重复（重复会出现两扇门拼接的接缝）。`ClampToEdgeWrapping` 让超出 `[0,1]` 的 UV 用边缘像素拉伸，配合 `repeat(1,1)`，纹理完整铺满门板一次，不重复。

这与砖墙的 `RepeatWrapping` 形成对比：**可重复图案用 RepeatWrapping，单幅图案用 ClampToEdgeWrapping**。

### 4. 画布比例与门板比例匹配

门板是 BoxGeometry(1.0, 2.0, 0.05)，正面是 1.0m×2.0m（宽高比 1:2）。画布用 256×512（宽高比 1:2），两者比例一致。BoxGeometry 正面的 UV 是 `[0,1]×[0,1]`，纹理被完整映射到 1:2 的面上，不变形。

如果画布用 256×256（正方形）贴到 1:2 的门板上，纹理会被纵向拉伸，砖块变成竖长条。所以**画布比例要和贴图面比例匹配**，避免变形。

## 四、应用到门板材质

```js
import * as THREE from "three";

// 木门材质：贴木纹纹理
const doorMat = new THREE.MeshStandardMaterial({
  color: 0xffffff,
  map: woodTex, // 木纹 CanvasTexture
  roughness: 0.6,
  metalness: 0.0,
});

// 木门板：1.0(X) × 2.0(Y) × 0.05(Z)，中心 (0, 1.3, 3.125)
const door = new THREE.Mesh(new THREE.BoxGeometry(1.0, 2.0, 0.05), doorMat);
door.position.set(0, 1.3, 3.125);
houseGroup.add(door);
```

门板的 `roughness: 0.6` 比砖墙的 `0.9` 低——木头比砖墙光滑一点，有轻微光泽。`metalness: 0.0` 保持非金属。

## 五、屋顶瓦片纹理（鱼鳞瓦）

虽然屋顶贴图放在视觉上和砖墙木门一组，但它的 CanvasTexture 思路类似，这里一并讲解。鱼鳞瓦片的特征是**重叠的半圆弧**，每片瓦上部高光、下部阴影：

```js
import * as THREE from "three";

const createRoofTileTexture = () => {
  const size = 256;
  const canvas = document.createElement("canvas");
  canvas.width = size;
  canvas.height = size;
  const ctx = canvas.getContext("2d");

  // 基色：砖红 #a0522d
  ctx.fillStyle = "#a0522d";
  ctx.fillRect(0, 0, size, size);

  // 鱼鳞瓦片：逐行画半椭圆，下一行覆盖上一行下半部分
  const tileW = 64; // 每片宽
  const tileH = 48; // 每片露出高度
  const rows = Math.ceil(size / tileH) + 2;
  const cols = Math.ceil(size / tileW) + 2;

  for (let r = 0; r < rows; r++) {
    const y = r * tileH;
    const offset = (r % 2) * (tileW / 2); // 奇数行偏移半片
    for (let c = -1; c <= cols; c++) {
      const x = c * tileW + offset;
      // 每片瓦用径向渐变：中心亮（高光）、边缘暗（阴影/缝隙）
      const grad = ctx.createRadialGradient(x, y - tileH * 0.3, 2, x, y, tileW / 2);
      grad.addColorStop(0, "#c4683a"); // 顶部高光
      grad.addColorStop(0.6, "#a0522d"); // 中部砖红
      grad.addColorStop(1, "#6e3820"); // 底部阴影
      ctx.fillStyle = grad;
      ctx.beginPath();
      // 画上半椭圆（瓦片露出的弧形），canvas 中 y 向下，π~2π 为上半部分
      ctx.ellipse(x, y, tileW / 2, tileH, 0, Math.PI, Math.PI * 2);
      ctx.fill();
    }
  }

  const texture = new THREE.CanvasTexture(canvas);
  texture.wrapS = THREE.RepeatWrapping;
  texture.wrapT = THREE.RepeatWrapping;
  texture.repeat.set(6, 4); // 屋顶面积大，多重复几次让瓦片密度合理
  texture.colorSpace = THREE.SRGBColorSpace;
  return texture;
};
```

屋顶材质用 `side: THREE.DoubleSide`（双面渲染，屋檐下也能看见瓦片），并贴 `tileTex`：

```js
const roofMat = new THREE.MeshStandardMaterial({
  color: 0xffffff,
  map: tileTex,
  roughness: 0.8,
  metalness: 0.0,
  side: THREE.DoubleSide,
});
```

::: tip 山墙为什么不贴砖墙纹理
stage-04 的山墙是用 `Shape + ExtrudeGeometry` 生成的三角形。ExtrudeGeometry 的 UV 不是标准的 `[0,1]` 归一化，而是按 Shape 的坐标直接生成，贴上砖墙纹理会出现拉伸错位。为保持视觉干净，山墙保留纯色 `0xe6d5b8` 不贴图。这体现了"贴图要看几何体 UV 是否合适"的工程判断。
:::

## 六、本节总结

- **砖墙纹理**：先填砖缝色作底，再逐块画砖留缝隙形成网格；running bond 错缝靠奇数行偏移半块实现；`c` 从 -1 到 cols 保证画布边缘半块砖在 RepeatWrapping 拼接时连续
- **无缝纹理**核心：画布包含整数个重复单元，偏移量是单元宽度的整数分之一
- **木纹纹理**：竖向画布 256×512 匹配门板 1:2 比例；正弦波画弯曲条纹；径向渐变画木节
- **RepeatWrapping vs ClampToEdgeWrapping**：可重复图案（砖墙、瓦片）用前者，单幅图案（门板）用后者
- **color 设白色**：用 `map` 时 `color: 0xffffff`，避免对纹理二次染色（map 与 color 是乘法关系）
- **画布比例匹配贴图面比例**：避免纹理变形
- **山墙不贴图**：ExtrudeGeometry 的 UV 不规则，贴图会拉伸，保留纯色更干净
