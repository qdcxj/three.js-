# 天空盒与立方纹理：程序化天空与 CubeTexture

stage-04 的场景背景是一片纯色天蓝（`scene.background = new THREE.Color(0x87ceeb)`）——平、假、没有层次。本节给小屋换上**程序化渐变天空盒**：天顶深蓝、中部天蓝、地平线近白，像真实天空一样有层次。同时讲解 Three.js 天空盒的两种实现方式——`scene.background` 渐变贴图（本阶段用）和 `CubeTexture` 立方纹理（更通用的方案）。

## 一、场景背景的三种形态

`scene.background` 可以接受三种类型的值，呈现不同效果：

```js
import * as THREE from "three";

// 1) 纯色背景（stage-04 用）
scene.background = new THREE.Color(0x87ceeb);

// 2) 2D 纹理背景（本阶段用：渐变天空）
scene.background = skyTexture; // 一张 CanvasTexture

// 3) 立方纹理背景（CubeTexture，6 面天空盒）
scene.background = cubeTexture; // 6 张图组成的立方体贴图
```

| 形态 | 效果 | 是否随相机旋转 | 适用场景 |
|------|------|:--------------:|----------|
| 纯色 | 一片单色 | 否 | 调试、占位 |
| 2D 纹理 | 一张图全屏拉伸 | 否（固定背景） | 渐变天空、远景画 |
| 立方纹理 | 6 面包裹，360° 天空盒 | 是（相机转动看到不同面） | 真实天空、环境反射 |

本阶段用 2D 纹理背景做渐变天空——简单、自包含、效果够用。下一节会讲解更通用的立方纹理方案。

## 二、程序化渐变天空（本阶段实现）

### 1. Canvas 画垂直渐变

天空的真实视觉是：天顶（抬头看）深蓝、地平线（平视）浅白。用 Canvas 画一条垂直渐变即可：

```js
import * as THREE from "three";

const createSkyTexture = () => {
  const w = 16;
  const h = 256;
  const canvas = document.createElement("canvas");
  canvas.width = w;
  canvas.height = h;
  const ctx = canvas.getContext("2d");

  // 垂直渐变：顶部深蓝 → 中部天蓝 → 底部近白（地平线）
  const grad = ctx.createLinearGradient(0, 0, 0, h);
  grad.addColorStop(0, "#4a7fc1"); // 天顶深蓝
  grad.addColorStop(0.5, "#87ceeb"); // 中部天蓝
  grad.addColorStop(1, "#e8f0f5"); // 地平线近白
  ctx.fillStyle = grad;
  ctx.fillRect(0, 0, w, h);

  const texture = new THREE.CanvasTexture(canvas);
  texture.colorSpace = THREE.SRGBColorSpace;
  return texture;
};
```

画布只用 16×256——天空是纯渐变，不需要高分辨率。设为 `scene.background` 后，Three.js 会把它全屏拉伸到视口大小，垂直渐变铺满整个背景。

### 2. 设为场景背景

```js
const createTextures = () => {
  // ... 创建其他纹理
  skyTex = createSkyTexture();
  scene.background = skyTex;
};
```

这样场景背景就从纯色变成渐变天空。相机怎么转，背景都固定（2D 纹理背景不随相机旋转），但渐变天空本来就无所谓旋转，视觉上没问题。

::: tip 为什么 2D 背景不随相机旋转
2D 纹理背景在 Three.js 里渲染为一个全屏的四边形，固定在屏幕上（screen-aligned）。它的作用是"幕布"，不是真正的 3D 天空。如果你需要相机转动时看到天空的不同部分（如地平线随视角移动），需要用 CubeTexture 或天空球。
:::

## 三、CubeTexture：6 面立方纹理天空盒

虽然本阶段用 2D 渐变就够了，但 Three.js 天空盒的主流方案是 **CubeTexture（立方纹理）**——6 张正方形图片贴到一个虚拟立方体的 6 个内表面，相机在立方体中心，转动时看到不同的面。

### 1. CubeTexture 的原理

想象你站在一个房间中央，房间的 6 面墙（上下左右前后）各贴一张图。你转头时看到不同墙上的图——这就是 CubeTexture 天空盒的视觉。

6 个面对应 6 张图，按 Three.js 约定顺序：+X、-X、+Y、-Y、+Z、-Z（右、左、上、下、前、后）。

### 2. CubeTextureLoader 加载 6 张图

实际项目通常用美术准备的 6 张天空照片：

```js
import * as THREE from "three";

const cubeLoader = new THREE.CubeTextureLoader();
const cubeTexture = cubeLoader.load([
  "/sky/px.jpg", // +X 右
  "/sky/nx.jpg", // -X 左
  "/sky/py.jpg", // +Y 上
  "/sky/ny.jpg", // -Y 下
  "/sky/pz.jpg", // +Z 前
  "/sky/nz.jpg", // -Z 后
]);

scene.background = cubeTexture; // 立方纹理背景，随相机旋转
```

`CubeTextureLoader` 异步加载 6 张图，组装成 `CubeTexture`。设为 `scene.background` 后，相机会"身处"立方体中心，转动时看到 6 面天空——这是真正的 360° 天空盒。

### 3. 程序化生成 6 面 CubeTexture

本阶段强调自包含，不依赖外部图片。也可以用 6 个 Canvas 程序化生成 CubeTexture：

```js
import * as THREE from "three";

const createSkyCubeTexture = () => {
  const size = 256;
  // 6 个面的 canvas
  const faces = [];

  // 辅助：画一个天空渐变面
  const drawFace = (topColor, bottomColor) => {
    const canvas = document.createElement("canvas");
    canvas.width = size;
    canvas.height = size;
    const ctx = canvas.getContext("2d");
    const grad = ctx.createLinearGradient(0, 0, 0, size);
    grad.addColorStop(0, topColor);
    grad.addColorStop(1, bottomColor);
    ctx.fillStyle = grad;
    ctx.fillRect(0, 0, size, size);
    return canvas;
  };

  // 4 个侧面：上蓝下白
  const side = () => drawFace("#4a7fc1", "#e8f0f5");
  // 顶面（+Y 天顶）：纯深蓝
  const top = () => drawFace("#3a6fb5", "#3a6fb5");
  // 底面（-Y 地面）：纯近白
  const bottom = () => drawFace("#e8f0f5", "#e8f0f5");

  // 顺序：+X, -X, +Y, -Y, +Z, -Z
  faces.push(side(), side(), top(), bottom(), side(), side());

  const cubeTexture = new THREE.CubeTexture(faces);
  cubeTexture.colorSpace = THREE.SRGBColorSpace;
  cubeTexture.needsUpdate = true;
  return cubeTexture;
};

scene.background = createSkyCubeTexture();
```

这样不需要任何外部图片，也能得到一个 360° 旋转的天空盒。相比 2D 渐变背景，CubeTexture 天空盒在相机旋转时能看到天空的"顶面"和"底面"，更立体。

::: tip 本阶段为什么选 2D 渐变而非 CubeTexture
本阶段的天空只是简单渐变，2D 背景足够呈现效果，且代码更简洁。CubeTexture 的优势在于 6 面可以各不相同（如真实天空照片），但对于纯渐变天空，6 面拼接的优势不明显。stage-06 加阳光阴影后，可能会改用 CubeTexture 或天空球以获得更真实的环境光照。理解两种方案的原理后，可按需选择。
:::

## 四、天空球：第三种方案

除了 2D 背景和 CubeTexture，还有一种**天空球（Sky Dome）**方案——用一个巨大的球体，内侧贴天空纹理，相机在球内：

```js
import * as THREE from "three";

// 巨大球体（半径 100），内侧贴天空纹理
const skyGeo = new THREE.SphereGeometry(100, 32, 32);
const skyMat = new THREE.MeshBasicMaterial({
  map: skyTexture,
  side: THREE.BackSide, // 只渲染内侧（相机在球内）
});
const skyDome = new THREE.Mesh(skyGeo, skyMat);
scene.add(skyDome);
```

天空球的优势：可以用一张**球面投影（equirectangular）**的全景图贴到球上，呈现真实照片级天空。Three.js 还内置 `Sky` shader（`three/examples/jsm/objects/Sky.js`）做大气散射真实天空，stage-06 以后可能用到。

三种方案对比：

| 方案 | 实现 | 旋转跟随 | 复杂度 | 适用 |
|------|------|:--------:|:------:|------|
| 2D 背景 | `scene.background = texture` | 否 | 最低 | 渐变天空、远景 |
| CubeTexture | 6 面 CanvasTexture | 是 | 中 | 真实天空盒、环境反射 |
| 天空球 | 大球 + BackSide | 是 | 中 | 球面全景图、Sky shader |

## 五、天空盒与玻璃的配合

本阶段的天空盒不只是装饰——它还影响玻璃的透射效果。回忆 03 节：透射玻璃会采样背后的场景渲染目标，而场景背景（天空）是渲染目标的一部分。所以透过玻璃能看到折射的天空颜色——浅蓝玻璃 + 蓝白天空 = 通透的窗户感。

```js
const createTextures = () => {
  // ... 砖墙、木纹、瓦片纹理
  skyTex = createSkyTexture();
  scene.background = skyTex; // 天空作为背景，玻璃透射会采样到它
};
```

如果把天空换成纯黑（夜晚），玻璃透射也会变暗——天空盒和玻璃是联动的。

::: tip 环境反射也需要天空
除了玻璃透射，PBR 材质（金属、清漆）的环境反射也需要天空。stage-04 的材质因为 `metalness: 0`（非金属）反射不明显，但 stage-06 加金属物件后，`scene.environment`（环境贴图）会用到天空。通常用 `PMREMGenerator` 把 CubeTexture 预处理成环境贴图，stage-06 会讲解。
:::

## 六、本阶段完整的天空实现

回到本阶段的实际代码。天空在 `createTextures()` 中创建并设为背景：

```js
import * as THREE from "three";

let skyTex = null;

const createSkyTexture = () => {
  const w = 16;
  const h = 256;
  const canvas = document.createElement("canvas");
  canvas.width = w;
  canvas.height = h;
  const ctx = canvas.getContext("2d");

  const grad = ctx.createLinearGradient(0, 0, 0, h);
  grad.addColorStop(0, "#4a7fc1"); // 天顶深蓝
  grad.addColorStop(0.5, "#87ceeb"); // 中部天蓝
  grad.addColorStop(1, "#e8f0f5"); // 地平线近白
  ctx.fillStyle = grad;
  ctx.fillRect(0, 0, w, h);

  const texture = new THREE.CanvasTexture(canvas);
  texture.colorSpace = THREE.SRGBColorSpace;
  return texture;
};

const createTextures = () => {
  // 砖墙、木纹、瓦片纹理（前两节已讲）
  brickTex = createBrickTexture();
  woodTex = createWoodTexture();
  tileTex = createRoofTileTexture();

  // 天空渐变贴图
  skyTex = createSkyTexture();
  scene.background = skyTex;

  // 收集到 textures 数组，dispose 时统一释放
  textures.push(brickTex, woodTex, tileTex, skyTex);
};
```

启动项目后，整个场景被蓝白渐变天空包裹，砖墙小屋立在草地中央，玻璃窗折射着天空的浅蓝色——第 05 阶段完工。

## 七、阶段总结

第 05 阶段我们给小屋穿上了"皮肤"和"玻璃"：

1. **砖墙纹理**：Canvas 2D 画 running bond 错缝砖墙，`RepeatWrapping + repeat(4,2)` 平铺到外墙
2. **木纹纹理**：Canvas 2D 画垂直条纹 + 木节，`ClampToEdgeWrapping` 贴到门板
3. **瓦片纹理**：Canvas 2D 画鱼鳞半圆瓦，`repeat(6,4)` 贴到屋顶
4. **玻璃窗**：`MeshPhysicalMaterial` 的 transmission/ior/thickness 做 4 扇透射玻璃 + 蓝色窗框
5. **天空盒**：Canvas 渐变贴图作 `scene.background`，蓝白渐变天空

所有纹理**程序化生成、零外部依赖**，快照复制即运行。到本阶段末，小屋已具备完整的视觉外观——有材质、有玻璃、有天空。下一阶段（stage-06）会加阳光、环境光、室内灯和阴影，让小屋在光照下展现 PBR 材质的真实感。

## 八、本节总结

- `scene.background` 接受三种类型：纯色（Color）、2D 纹理（Texture）、立方纹理（CubeTexture）
- **2D 纹理背景**：全屏拉伸，不随相机旋转，适合渐变天空（本阶段用）
- **CubeTexture 天空盒**：6 面立方体贴图，相机在中心，转动看到不同面，适合真实天空
- **程序化 CubeTexture**：用 6 个 Canvas 生成 6 面，零外部依赖，顺序 +X/-X/+Y/-Y/+Z/-Z
- **天空球**：大球 + BackSide + 球面全景图，第三种方案
- 天空盒影响玻璃透射（玻璃折射采样背景）和 PBR 环境反射
- 本阶段用 2D 渐变背景（简洁够用），stage-06 起可能改用 CubeTexture 或 Sky shader
