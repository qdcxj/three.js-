# 玻璃窗与透射：MeshPhysicalMaterial 的真实折射

stage-03 我们在墙上留了 4 个窗洞（前墙 2 个、左右墙各 1 个），但一直是空着的——能直接看穿到室内。本节给这些窗洞装上**真实玻璃**：光线穿过玻璃时发生折射，远处的景物会扭曲变形，就像真实窗户一样。

实现真实玻璃的核心是 `MeshPhysicalMaterial` 的 `transmission`（透射）属性——这是 Three.js 里做玻璃、水、肥皂泡等透明折射物体的标准方案。本节还会用 BoxGeometry 拼 4 格窗框，让窗户更像欧式木窗。

## 一、为什么不用 transparent + opacity

做"透明物体"最直觉的做法是设 `transparent: true` + `opacity: 0.5`：

```js
import * as THREE from "three";

// ❌ 半透明塑料片，不是玻璃
const fakeGlass = new THREE.MeshStandardMaterial({
  color: 0xa8d0ff,
  transparent: true,
  opacity: 0.5, // 半透明
});
```

这种做法只是让物体**变淡**（alpha 混合），光直线穿过，没有折射。看起来像有色塑料片或毛玻璃，不像真实玻璃——真实玻璃会让背后的景物**扭曲变形**（折射），且表面有**反光**（菲涅尔反射）。

要做真实玻璃，需要 `MeshPhysicalMaterial` 的 `transmission`：

```js
// ✅ 真实玻璃：透射 + 折射 + 菲涅尔反射
const realGlass = new THREE.MeshPhysicalMaterial({
  color: 0xa8d0ff,
  transmission: 1.0, // 完全透射
  roughness: 0.0,
  ior: 1.5,
  thickness: 0.1,
  transparent: true,
});
```

## 二、MeshPhysicalMaterial 玻璃四参数

`MeshPhysicalMaterial` 是 `MeshStandardMaterial` 的扩展，多了清漆层、透射、虹彩等高级属性。做玻璃主要用以下四个：

### 1. transmission：透射强度

```js
material.transmission = 1.0; // 0~1
```

`transmission` 控制光线穿过物体的程度。`0` = 不透射（普通不透明物体）；`1` = 完全透射（清澈玻璃）。介于 0 和 1 之间是半透明玻璃（如磨砂玻璃、有色玻璃）。

::: warning transmission 与 opacity 的区别
`opacity` 是 alpha 混合（光直线穿过，无折射）；`transmission` 是物理透射（光折射穿过，有扭曲）。两者可以共存：`transmission` 控制折射透光，`opacity` 控制非折射的 alpha 透明度。纯玻璃用 `transmission: 1.0` + `opacity: 1.0`（默认）。
:::

### 2. ior：折射率

```js
material.ior = 1.5; // 玻璃折射率
```

`ior`（Index of Refraction）是材质的折射率，决定光线穿过时弯曲程度。常见值：

| 材质 | ior |
|------|-----|
| 真空 / 空气 | 1.0 |
| 水 | 1.33 |
| 玻璃 | 1.5 |
| 水晶 | 2.0 |
| 钻石 | 2.4 |

`ior: 1.0` 时不折射（光直线穿过）；`ior: 1.5` 时玻璃后的景物会扭曲——这是玻璃的视觉特征。本阶段用 1.5（标准玻璃）。

### 3. thickness：厚度

```js
material.thickness = 0.1; // 玻璃厚度
```

`thickness` 控制折射位移的程度。玻璃越厚，背后的景物偏移越大。`thickness: 0` 时几乎无折射位移（像一层膜）；`thickness: 0.1` 有明显折射；`thickness: 1.0` 折射位移很大（像厚玻璃砖）。本阶段用 0.1（薄窗玻璃）。

### 4. roughness：光滑度

```js
material.roughness = 0.0; // 完全光滑
```

`roughness` 控制玻璃表面的光滑度。`0` = 完全光滑（清澈透明，能看清背后）；`1` = 完全粗糙（磨砂玻璃，背后模糊）。普通窗户玻璃 `roughness: 0.0`；磨砂玻璃 `roughness: 0.5~0.8`。本阶段用 0.0（清澈窗玻璃）。

::: tip 完整玻璃材质
```js
const glassMat = new THREE.MeshPhysicalMaterial({
  color: 0xa8d0ff,      // 浅蓝玻璃色（玻璃的固有色调）
  transmission: 1.0,     // 完全透射
  roughness: 0.0,        // 完全光滑（清晰）
  ior: 1.5,              // 玻璃折射率
  thickness: 0.1,        // 薄玻璃厚度
  transparent: true,     // 开启透明渲染通道
  side: THREE.DoubleSide // 双面可见
});
```
:::

## 三、透射渲染的原理

`transmission > 0` 时，Three.js 会做一个**额外的渲染通道**：

1. 先把场景（不含透射物体）渲染到一个**透射渲染目标（transmission render target）**
2. 渲染玻璃时，对玻璃背后的渲染目标采样，按 `ior` 和 `thickness` 做折射计算
3. 把折射后的颜色作为玻璃的颜色输出

这意味着玻璃能折射**场景中所有不透明物体和背景**（天空、墙、地板）。但透射物体之间**不会相互折射**（一个玻璃不会折射另一个玻璃）——这是性能与真实的权衡。

::: warning 透射的性能开销
透射需要额外的渲染通道，性能开销约为普通材质的 2 倍。大量玻璃物体（如一栋玻璃幕墙大楼）会明显降低帧率。优化方案：远处用 `transparent + opacity` 假玻璃，近处才用 transmission 真玻璃。本阶段只有 4 扇小窗，性能无忧。
:::

## 四、创建一扇窗户

一扇欧式木窗 = 1 块玻璃 + 4 根窗框边 + 十字窗棂（mullion，把玻璃分 4 格）。用 Group 组织：

```js
import * as THREE from "three";

const createWindow = (width = 0.8, height = 1.2) => {
  const group = new THREE.Group();

  // ---- 窗框材质：Element Plus 主色 #409eff，半光泽 ----
  const frameMat = new THREE.MeshStandardMaterial({
    color: 0x409eff,
    roughness: 0.4,
    metalness: 0.3,
  });

  // ---- 玻璃材质：MeshPhysicalMaterial 透射玻璃 ----
  const glassMat = new THREE.MeshPhysicalMaterial({
    color: 0xa8d0ff,
    transmission: 1.0,
    roughness: 0.0,
    ior: 1.5,
    thickness: 0.1,
    transparent: true,
    side: THREE.DoubleSide,
  });

  const border = 0.04; // 窗框边宽
  const t = 0.06; // 窗框厚度（沿墙面方向）

  // ---- 玻璃：0.72 × 1.12 × 0.02 ----
  // 玻璃比窗洞小一圈（减去 2×border），嵌在窗框内
  const glass = new THREE.Mesh(
    new THREE.BoxGeometry(width - 2 * border, height - 2 * border, 0.02),
    glassMat
  );
  group.add(glass);

  // ---- 4 根窗框边（上/下/左/右）----
  const top = new THREE.Mesh(new THREE.BoxGeometry(width, border, t), frameMat);
  top.position.set(0, height / 2 - border / 2, 0);
  group.add(top);

  const bottom = new THREE.Mesh(new THREE.BoxGeometry(width, border, t), frameMat);
  bottom.position.set(0, -height / 2 + border / 2, 0);
  group.add(bottom);

  const left = new THREE.Mesh(new THREE.BoxGeometry(border, height, t), frameMat);
  left.position.set(-width / 2 + border / 2, 0, 0);
  group.add(left);

  const right = new THREE.Mesh(new THREE.BoxGeometry(border, height, t), frameMat);
  right.position.set(width / 2 - border / 2, 0, 0);
  group.add(right);

  // ---- 十字窗棂：把玻璃分 4 格，更欧式 ----
  const mullionH = new THREE.Mesh(
    new THREE.BoxGeometry(width - 2 * border, border * 0.6, t * 0.6),
    frameMat
  );
  group.add(mullionH);

  const mullionV = new THREE.Mesh(
    new THREE.BoxGeometry(border * 0.6, height - 2 * border, t * 0.6),
    frameMat
  );
  group.add(mullionV);

  return group;
};
```

### 尺寸推导

HOUSE_SPEC 规定前墙窗洞 `0.8(X) × 1.2(Y)`，玻璃 `0.72 × 1.12 × 0.02`。尺寸关系：

- 窗框外尺寸 = 窗洞尺寸 = 0.8 × 1.2
- 窗框边宽 `border = 0.04`
- 玻璃尺寸 = 窗框内尺寸 = (0.8 - 2×0.04) × (1.2 - 2×0.04) = 0.72 × 1.12 ✓

窗框边宽 0.04m（4cm）是欧式木窗的合理尺寸。十字窗棂更细（`border × 0.6 = 0.024m`），不遮挡玻璃透射。

## 五、4 扇窗户的位置与朝向

HOUSE_SPEC 规定 4 个窗洞位置：

| 窗 | 位置 | 窗洞尺寸 | 朝向 |
|----|------|----------|------|
| 前墙左窗 | (-2, 1.5, 3) | 0.8(X) × 1.2(Y) | 朝 +Z（正面） |
| 前墙右窗 | (2, 1.5, 3) | 0.8(X) × 1.2(Y) | 朝 +Z（正面） |
| 左墙窗 | (-4, 1.5, 0) | 1.2(Z) × 1.2(Y) | 朝 -X（左面） |
| 右墙窗 | (4, 1.5, 0) | 1.2(Z) × 1.2(Y) | 朝 +X（右面） |

前墙窗户朝 +Z，直接放置即可；侧墙窗户朝 ±X，需要绕 Y 轴旋转 90°：

```js
const addWindows = (houseGroup) => {
  // 前墙左窗：朝 +Z，不旋转
  const frontLeft = createWindow();
  frontLeft.position.set(-2, 1.5, 3.0);
  houseGroup.add(frontLeft);

  // 前墙右窗
  const frontRight = createWindow();
  frontRight.position.set(2, 1.5, 3.0);
  houseGroup.add(frontRight);

  // 左墙窗：绕 Y 旋转 90°，窗面从朝 +Z 变为朝 -X
  const leftWin = createWindow();
  leftWin.position.set(-4, 1.5, 0);
  leftWin.rotation.y = Math.PI / 2;
  houseGroup.add(leftWin);

  // 右墙窗：对称
  const rightWin = createWindow();
  rightWin.position.set(4, 1.5, 0);
  rightWin.rotation.y = Math.PI / 2;
  houseGroup.add(rightWin);
};
```

### 为什么旋转 Math.PI/2

`createWindow` 默认创建的窗户朝 +Z（玻璃面在 XY 平面，厚度沿 Z）。侧墙窗洞朝 ±X，需要把窗户的 +Z 方向转到 ±X 方向——绕 Y 轴旋转 90°（`Math.PI / 2`）正好做到。旋转后窗户的宽度方向（原 X）变成 Z 方向，厚度方向（原 Z）变成 X 方向，正好嵌入侧墙。

::: tip 旋转方向
左墙窗旋转 `Math.PI / 2` 后朝 -X，右墙窗也旋转 `Math.PI / 2` 朝 +X。两个都旋转同样的角度看起来"不对称"，但因为窗户是对称的（正反面一样），所以视觉上没问题。如果窗户有正反之分（如把手在一侧），就要分别旋转 `Math.PI / 2` 和 `-Math.PI / 2`。
:::

## 六、玻璃的视觉效果

启动项目后，绕到房子正面看前墙窗户：

1. **透射折射**：透过玻璃能看到室内的地板和后墙，但景物有轻微扭曲（ior=1.5 折射）
2. **浅蓝色调**：玻璃 `color: 0xa8d0ff` 给透射光加上浅蓝色，像真实玻璃的绿色/蓝色调
3. **菲涅尔反射**：斜看玻璃时表面反光更强（近垂直看更透明），这是物理正确的
4. **窗框遮挡**：蓝色窗框和十字窗棂不透明，把玻璃分成 4 格，更有窗户感

::: warning 玻璃看起来全透明怎么办
如果玻璃几乎看不见（像没有），检查：① `transmission` 是否 > 0；② `transparent` 是否 true；③ 场景里玻璃背后是否有物体或背景（空场景的玻璃看不到折射）；④ `roughness` 是否太高（高粗糙度磨砂玻璃看不清背后）。本阶段有天空背景和室内物体，玻璃折射效果明显。
:::

## 七、本节总结

- **真实玻璃**用 `MeshPhysicalMaterial` 的 `transmission`（透射），不是 `opacity`（alpha 混合）。透射有折射扭曲，opacity 没有
- 玻璃四参数：`transmission: 1.0`（完全透射）、`ior: 1.5`（玻璃折射率）、`thickness: 0.1`（薄玻璃）、`roughness: 0.0`（清澈光滑）
- 透射渲染原理：额外渲染通道先把场景渲到 render target，玻璃再采样折射
- **透射有性能开销**（约 2 倍），大量玻璃需优化（远处用假玻璃）
- 一扇窗户 = 玻璃 + 4 根窗框边 + 十字窗棂，用 Group 组织
- 侧墙窗户绕 Y 旋转 90° 嵌入侧墙；尺寸推导：玻璃 = 窗洞 - 2×边框
- `side: THREE.DoubleSide` 让玻璃双面可见（室内外都能看）
