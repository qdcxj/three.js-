# 环境光与平行光

如果没有光，再精致的模型也只是一片黑。灯光是 3D 场景从"几何体堆叠"走向"真实世界"的最后一公里。本节我们先把场景的"户外光照"搞定：用 `AmbientLight` 给全场打底亮度，用 `DirectionalLight` 模拟太阳，让房子第一次在草地上投下长长的影子。这两种光是户外场景的标配，理解了它们，你就掌握了 Three.js 灯光体系的"地基"。

## 一、Three.js 灯光全家桶速览

在动手之前，先建立全局认知。Three.js 内置 6 种灯光，按"是否有方向、是否有位置、是否衰减"可分为四类：

| 灯光 | 方向 | 位置 | 衰减 | 投影 | 典型用途 |
|------|------|------|------|------|----------|
| AmbientLight 环境光 | 无 | 无 | 无 | 否 | 打底亮度，避免纯黑 |
| HemisphereLight 半球光 | 上→下 | 无 | 无 | 否 | 天空与地面两种色的环境光 |
| DirectionalLight 平行光 | 有 | 仅决定方向 | 无 | 是 | 太阳 / 月亮 |
| PointLight 点光源 | 四面八方 | 有 | 有 | 是 | 灯泡 / 火焰 / 室内吊灯 |
| SpotLight 聚光灯 | 锥形 | 有 | 有 | 是 | 手电筒 / 壁灯 / 舞台灯 |
| RectAreaLight 面光源 | 矩形面 | 有 | 有 | 否 | 发光板 / 灯箱 |

本阶段的小屋用到前 5 种中的 4 种（除 RectAreaLight 外）：环境光 + 平行光（本节）、点光源 + 聚光灯（下一节）。`RectAreaLight` 不支持阴影且需配合专门的着色器，留到进阶章节再讲。

::: tip 受光材质
记住一个铁律：**只有受光材质才会被灯光照亮**。`MeshBasicMaterial` / `MeshNormalMaterial` 不受光，再亮的灯也照不亮它们；`MeshLambertMaterial` / `MeshPhongMaterial` / `MeshStandardMaterial` / `MeshPhysicalMaterial` 才受光。本阶段小屋全部用 `MeshStandardMaterial`，所以灯光能正常生效。
:::

## 二、环境光 AmbientLight

环境光是最简单的灯：它没有方向、没有位置，对所有物体的所有面均匀地加上一层亮度。可以把它理解为"空气里弥漫的光"——它不产生阴影，不体现立体感，唯一作用是**把背阴面从纯黑抬到一个基础亮度**。

### 2.1 构造与属性

```js
import * as THREE from 'three';

// AmbientLight(color, intensity)
const ambient = new THREE.AmbientLight(0xffffff, 0.3);
scene.add(ambient);
```

- `color`：环境光颜色，通常用白色 `0xffffff` 或冷灰 `0x404040`
- `intensity`：强度，0~1 常见。值越高，全场越"平"，阴影对比越弱

### 2.2 强度的取舍

环境光强度是"真实感"与"可读性"的权衡：

- **强度过高（>0.6）**：阴影对比被压平，物体显得"灰蒙蒙"，像阴天
- **强度过低（<0.1）**：背阴面纯黑，细节丢失，对比过强像舞台剧
- **推荐 0.2~0.4**：既有明暗对比，背阴面又看得出细节

我们的小屋取 `0.3`——阳光照不到的墙体内侧、屋檐下、台阶底，都能看到一层淡淡的亮度，而不是死黑。

::: warning 环境光不能替代主光
新手常犯的错：只加环境光让场景"亮起来"。结果整个场景没有方向、没有阴影，看起来像 2D 贴图。**环境光永远是配角**，主角必须是平行光/点光源/聚光灯这类有方向的光。我们的配置是 `AmbientLight(0.3)` + `DirectionalLight(1.2)`，主光强度是环境光的 4 倍。
:::

## 三、半球光 HemisphereLight（拓展）

在讲阳光之前，先提一下 `HemisphereLight`——它是环境光的"升级版"。普通环境光全场一色，而半球光把场景分成上下两半：上半球（天空色）和下半球（地面色），中间柔和过渡。

```js
// HemisphereLight(skyColor, groundColor, intensity)
const hemi = new THREE.HemisphereLight(0x87ceeb, 0x67c23a, 0.4);
scene.add(hemi);
```

这行代码的效果是：物体朝上的面染上一层天蓝色，朝下的面染上一层草绿色——比纯白环境光更真实。户外场景推荐用半球光替代环境光。本阶段为教学清晰，先用 `AmbientLight` 让你直观看到"环境光打底"的作用；进阶项目可换成 `HemisphereLight`。

## 四、平行光 DirectionalLight（阳光）

平行光模拟无限远的光源（如太阳）。它的核心特征是：**所有光线互相平行**，因此无论物体离光源多远，光照强度都不变（不衰减）。位置属性 `position` 只用来和 `target` 一起决定光照方向，不决定强度。

### 4.1 构造与基本属性

```js
import * as THREE from 'three';

// DirectionalLight(color, intensity)
const sun = new THREE.DirectionalLight(0xfffaf0, 1.2);
sun.position.set(10, 15, 8);       // 光源位置
sun.target.position.set(0, 0, 0);  // 照射目标
scene.add(sun);
scene.add(sun.target);             // target 必须加入场景才生效
```

- `color`：阳光颜色 `0xfffaf0` 暖白（带一点黄），比纯白更像真实阳光
- `intensity`：强度 1.2，比环境光强，是户外主光
- `position` 与 `target`：光照方向 = `target.position - position` 的反方向，即从 `position` 指向 `target`

::: tip target 必须加入场景
`DirectionalLight.target` 是一个 `Object3D`，默认在原点。如果你移动了 target，**必须把它 `scene.add(target)`**，否则方向不会更新。这是新手最常踩的坑之一。
:::

### 4.2 阳光方向的选择

阳光方向决定了阴影的朝向和长度。我们选 `(10, 15, 8)` 照向原点，意思是阳光从右前上方斜照下来：

- 右上方（+X, +Y）：影子落在左下方草地
- 前方（+Z）：影子朝后（-Z）拉长
- 高度角 ≈ `arctan(15 / sqrt(10²+8²))` ≈ 50°，影子长度适中，既能看到影子又不会被拉得过长

如果想让影子更长（黄昏感），把 `Y` 调小（如 `(10, 6, 8)`）；想正午顶光，把 `position` 调到正上方 `(0, 20, 0)`。

## 五、平行光阴影（本阶段重点）

平行光是本阶段阴影系统的主力——房子在草地上的长影就是它投的。配置阴影需要三层：渲染器层、光源层、物体层。本节先讲光源层，渲染器层和物体层留到第三节系统讲。

```js
// 1. 光源层：开启投影 + 配置阴影相机
sun.castShadow = true;
sun.shadow.mapSize.set(2048, 2048);       // 阴影贴图分辨率

// 2. 平行光阴影用正交相机，必须手动设定可视范围（覆盖房子）
sun.shadow.camera.left = -15;
sun.shadow.camera.right = 15;
sun.shadow.camera.top = 15;
sun.shadow.camera.bottom = -15;
sun.shadow.camera.near = 0.1;
sun.shadow.camera.far = 30;
sun.shadow.camera.updateProjectionMatrix();  // 改完必须更新

// 3. 阴影偏置，消除"阴影痤疮"
sun.shadow.bias = -0.0005;
sun.shadow.normalBias = 0.02;
```

### 5.1 shadow.camera 的正交范围

平行光的阴影是用一个正交相机（`OrthographicCamera`）从光源位置往 `target` 方向"拍"一张深度图来实现的。只有落在正交相机视锥范围内的物体才会投阴影。因此：

- `left/right/top/bottom` 必须足够大，覆盖整栋房子（8×6）外加一点余量，我们用 ±15
- `near/far` 必须覆盖从光源到目标的距离。光源在 (10,15,8)，距原点约 19.7m，`far=30` 足够

::: warning 范围越大，阴影越糊
正交范围越大，2048×2048 的贴图被"摊"到越大的面积上，单个像素代表的实际尺寸越大，阴影就越糊。所以**范围要刚好覆盖场景，不要无脑开大**。±15 对我们 8×6 的房子是合适的。
:::

### 5.2 mapSize 与阴影质量

`shadow.mapSize` 是阴影贴图的分辨率，直接影响阴影清晰度：

| mapSize | 清晰度 | 显存占用 | 适用场景 |
|---------|--------|----------|----------|
| 512×512 | 模糊 | 低 | 移动端 / 小物体 |
| 1024×1024 | 一般 | 中 | 室内 / 中等物体 |
| 2048×2048 | 清晰 | 高 | 户地主光 / 大场景 |
| 4096×4096 | 锐利 | 极高 | 高品质渲染（慎用） |

我们的阳光用 2048×2048，保证房子长影边缘清晰。室内点光源的立方体阴影用 512（开销是平行光的 6 倍，必须降级）。

### 5.3 bias 与阴影痤疮

`shadow.bias` 是阴影偏置，用来消除**阴影痤疮（shadow acne）**——物体表面出现条纹状的假阴影。原因是深度贴图的精度误差，让物体"自己投到自己身上"。给一个微小的负偏置（`-0.0005`）就能把阴影推到表面之下，消除痤疮。

`normalBias` 沿法线方向偏置，对薄物体（如墙板）的自阴影穿孔更有效，且不会像 `bias` 那样让阴影"漂浮"。两者可以配合使用。

::: tip 没有阴影的排查
如果加了 `castShadow` 还是没有阴影，按这个顺序查：① `renderer.shadowMap.enabled` 是否 true；② 光源 `castShadow` 是否 true；③ 投影物体 `castShadow` 是否 true；④ 接收物体 `receiveShadow` 是否 true；⑤ `shadow.camera` 范围是否覆盖了物体。90% 的问题出在这五步。
:::

## 六、整合到 HouseScene.vue

把环境光和阳光整合进 `addLights()` 函数，并移除前序阶段的临时预览灯光：

```js
const addLights = () => {
  // 环境光：纯白 0.3，打底亮度，避免背阴面纯黑
  const ambient = new THREE.AmbientLight(0xffffff, 0.3);
  scene.add(ambient);
  lights.push(ambient);

  // 阳光（平行光）：暖白 1.2，从 (10,15,8) 照向原点
  const sun = new THREE.DirectionalLight(0xfffaf0, 1.2);
  sun.position.set(10, 15, 8);
  sun.target.position.set(0, 0, 0);
  scene.add(sun);
  scene.add(sun.target);

  // 阳光投射阴影
  sun.castShadow = true;
  sun.shadow.mapSize.set(2048, 2048);
  sun.shadow.camera.left = -15;
  sun.shadow.camera.right = 15;
  sun.shadow.camera.top = 15;
  sun.shadow.camera.bottom = -15;
  sun.shadow.camera.near = 0.1;
  sun.shadow.camera.far = 30;
  sun.shadow.bias = -0.0005;
  sun.shadow.normalBias = 0.02;
  sun.shadow.camera.updateProjectionMatrix();
  lights.push(sun);
};
```

同时在 `initScene()` 里开启渲染器阴影：

```js
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;
```

并在所有墙/屋顶/门/地基上设 `castShadow = true; receiveShadow = true;`，草地上设 `receiveShadow = true`。这些物体层的标记会在第三节统一讲。

## 七、本节总结

- Three.js 有 6 种灯光，按"方向/位置/衰减"分四类；户外场景标配是环境光 + 平行光
- `AmbientLight` 无方向无位置，均匀打底，强度建议 0.2~0.4，**永远是配角**
- `HemisphereLight` 是环境光升级版，分天空色与地面色，进阶可替代环境光
- `DirectionalLight` 模拟太阳，光线平行不衰减，`position` 只决定方向
- `target` 必须加入场景，否则光照方向不更新——这是最常踩的坑
- 平行光阴影用正交相机，`shadow.camera` 范围要刚好覆盖场景，`mapSize` 2048 主流，`bias` 消除痤疮
- 阳光方向 `(10,15,8)` 让影子斜落在左下方草地，既有立体感又不过长
