# 点光源与聚光灯

上一节我们用环境光和平行光搞定了户外光照——房子有了阳光长影。但走进室内，你会发现天花板下面依然昏暗：阳光被屋顶挡住，只能从窗户透进一点点。这一节我们给室内装上灯具：用 `PointLight` 在天花板正中挂一盏暖黄吊灯，用两盏 `SpotLight` 在后墙装壁灯。这两种光都有"位置"和"距离衰减"，能营造出真实的室内氛围——离灯近的地方亮，远的地方暗，光锥打在木地板上形成漂亮的光斑。

## 一、点光源 PointLight

点光源从一个点向四面八方均匀发光，像现实中的灯泡、蜡烛、火把。它有位置、有距离衰减，是最常用的室内光源。

### 1.1 构造与参数

```js
import * as THREE from 'three';

// PointLight(color, intensity, distance, decay)
const indoorLight = new THREE.PointLight(0xffd27a, 1.0, 10, 1.5);
indoorLight.position.set(0, 2.8, 0);  // 天花板正中
scene.add(indoorLight);
```

四个参数的含义：

| 参数 | 值 | 含义 |
|------|-----|------|
| `color` | `0xffd27a` | 暖黄色，像白炽灯 / 烛光 |
| `intensity` | `1.0` | 强度（物理正确光照下单位是坎德拉 cd） |
| `distance` | `10` | 光照影响的最大距离，超过此距离光强衰减为 0；为 0 表示不衰减 |
| `decay` | `1.5` | 衰减系数，控制光强随距离下降的快慢 |

### 1.2 distance 与 decay 的物理意义

这两个参数共同决定"离灯越远越暗"的程度，是点光源区别于平行光的核心特征。

- **`distance`**：光的"射程"。设为 10 表示 10m 外完全没光。设为 0 表示无限远（不推荐，室内灯应该有范围）
- **`decay`**：衰减曲线。现实光按平方反比衰减（`decay=2`），Three.js 默认就是 2。我们用 1.5 让衰减稍缓，室内看起来更均匀

衰减公式（简化）：`光强 = intensity × (1 / (1 + decay × 距离²))`。当 `decay=0` 时不衰减（退化成无方向的全场亮），`decay=2` 是物理正确。

::: tip decay 的取值经验
- `decay=0`：不衰减，类似环境光但有点位置（少用）
- `decay=1`：线性衰减，复古游戏常用
- `decay=1.5~2`：物理正确，现代 3D 主流
- `decay>2`：超快衰减，营造"灯下亮、远处全黑"的戏剧效果

我们的小屋用 1.5，让天花板吊灯能均匀照亮 6m×8m 的房间，但离门近处比墙角亮。
:::

### 1.3 室内点光源的位置

我们把它放在 `(0, 2.8, 0)`——房间正中、天花板下方 0.5m（墙高 3m，天花板约 3.3m）。这个位置：

- 居中：到四面墙距离均匀，光照对称
- 偏下：离地板 2.8m，离地板上的物体（未来 stage-09 会放家具）够近，能投出清晰阴影
- 在屋顶下方：不会被屋顶遮挡（屋顶从 y=3.3 起）

```js
// 室内点光源投射阴影
indoorLight.castShadow = true;
indoorLight.shadow.mapSize.set(512, 512);  // 立方体阴影，6 倍开销，降级到 512
indoorLight.shadow.camera.near = 0.1;
indoorLight.shadow.camera.far = 10;        // 与 distance 一致
indoorLight.shadow.bias = -0.001;
scene.add(indoorLight);
```

::: warning 点光源阴影的开销
点光源的阴影是**立方体贴图（CubeShadowMap）**——它要从光源位置往 6 个方向各渲染一次深度图，开销是平行光的 6 倍。所以 `mapSize` 必须降级：平行光用 2048，点光源只用 512。一个场景里点光源阴影不要超过 2~3 个，否则帧率会暴跌。
:::

## 二、聚光灯 SpotLight

聚光灯是点光源的"加方向加角度版"：它从一个点出发，但只在一个锥形范围内发光，像手电筒、舞台灯、壁灯。它有 6 个构造参数，是最复杂的灯光。

### 2.1 构造与参数

```js
import * as THREE from 'three';

// SpotLight(color, intensity, distance, angle, penumbra, decay)
const wallLamp = new THREE.SpotLight(
  0xffe4b5,        // 颜色：暖光
  0.8,             // 强度
  8,               // distance：8m 外衰减为 0
  Math.PI / 6,     // angle：30° 半锥角
  0.4,             // penumbra：半影
  1.5              // decay：距离衰减
);
wallLamp.position.set(-2, 2.5, -2.8);   // 左壁灯位置
wallLamp.target.position.set(-2, 0.5, 0.5);  // 朝前下方
scene.add(wallLamp);
scene.add(wallLamp.target);
```

| 参数 | 值 | 含义 |
|------|-----|------|
| `color` | `0xffe4b5` | 暖白偏黄，壁灯色 |
| `intensity` | `0.8` | 强度，比点光源弱（两盏叠加） |
| `distance` | `8` | 射程 8m |
| `angle` | `Math.PI / 6` | **半锥角** 30°（注意是半角，全锥角 60°） |
| `penumbra` | `0.4` | 半影，0=硬边、1=完全软边 |
| `decay` | `1.5` | 距离衰减 |

### 2.2 angle 与 penumbra 的光锥形状

这两个参数决定光锥的"形状"，是聚光灯的灵魂：

- **`angle`**：光锥的张角。注意它是**半角**——`Math.PI/6`（30°）意味着全锥角 60°。取值范围 0~`Math.PI/2`（90°，变成半球光）。角度越小光锥越细（手电筒），越大越散（泛光灯）
- **`penumbra`**：半影，控制锥边过渡的柔和度。0 是硬边（光锥边界一刀切），1 是完全软边（从中心到边缘线性衰减）。0.3~0.5 是常用的"自然"值

我们用 `angle=30°, penumbra=0.4`，壁灯光锥既有明确方向，边缘又不会硬得突兀——打在地板上是一个柔和的椭圆光斑。

::: tip angle 是半角
无数新手在这里翻车：想要 60° 的光锥，写成 `Math.PI/3`（60°），结果实际全锥角 120°，光锥散成一片。记住：**`angle` 是从光轴到锥边的半角**。要 60° 全锥角就写 `Math.PI/6`（30° 半角）。
:::

### 2.3 target 决定照射方向

和 `DirectionalLight` 一样，`SpotLight` 通过 `target` 决定照射方向。光照方向 = `target.position - position`。我们的壁灯装在后墙内侧 `(±2, 2.5, -2.8)`，`target` 放在 `(±2, 0.5, 0.5)`——前下方。这样光锥朝 +Z（前方，朝门）和 -Y（下方）打出去，照亮室内地板。

```js
wallLamp.position.set(-2, 2.5, -2.8);
wallLamp.target.position.set(-2, 0.5, 0.5);  // 前 + 下
scene.add(wallLamp.target);  // 别忘了加入场景
```

::: warning target 也要加入场景
和 `DirectionalLight` 一样，`SpotLight.target` 必须显式 `scene.add()`。否则无论你怎么改 `target.position`，光照方向都默认朝原点，壁灯光锥会指向错误的地方。
:::

## 三、SpotLightHelper 可视化光锥

聚光灯的光锥看不见摸不着，调试时很难判断角度对不对。Three.js 提供 `SpotLightHelper`，用线框画出光锥的范围与方向，是教学和调试的利器。

```js
// 在 addLights() 里，创建完 spot 后：
if (SHOW_LIGHT_HELPERS) {
  const helper = new THREE.SpotLightHelper(spot, 0xffe4b5);
  scene.add(helper);
  lightHelpers.push(helper);
}
```

`SpotLightHelper` 画出的线框包括：

- 一条从光源到 target 的中心线（光轴）
- 一个锥形轮廓（angle 决定的张角）
- 一个底面圆（distance 决定的射程）

::: tip Helper 要每帧 update
如果你在动画循环里改了灯光的 `position` 或 `angle`，必须每帧调用 `helper.update()`，否则线框不会跟着变。我们的渲染循环里加了：
```js
if (SHOW_LIGHT_HELPERS) {
  lightHelpers.forEach((h) => h.update && h.update());
}
```
:::

`SHOW_LIGHT_HELPERS` 是文件顶部的开关，教学时设 `true` 看光锥，想看最终效果时设 `false`。其他灯光也有 helper：`DirectionalLightHelper`、`PointLightHelper`、`HemisphereLightHelper`，用法类似。

## 四、两盏壁灯的完整代码

把两盏壁灯封装成一个工厂函数，左右对称创建：

```js
const createWallLamp = (x) => {
  const spot = new THREE.SpotLight(
    0xffe4b5, 0.8, 8, Math.PI / 6, 0.4, 1.5
  );
  spot.position.set(x, 2.5, -2.8);
  spot.target.position.set(x, 0.5, 0.5);
  scene.add(spot);
  scene.add(spot.target);

  // 聚光灯投射阴影
  spot.castShadow = true;
  spot.shadow.mapSize.set(1024, 1024);
  spot.shadow.camera.near = 0.5;
  spot.shadow.camera.far = 10;
  spot.shadow.bias = -0.0005;
  lights.push(spot);

  // SpotLightHelper 演示光锥
  if (SHOW_LIGHT_HELPERS) {
    const helper = new THREE.SpotLightHelper(spot, 0xffe4b5);
    scene.add(helper);
    lightHelpers.push(helper);
  }
  return spot;
};
createWallLamp(-2);  // 左壁灯
createWallLamp(2);   // 右壁灯
```

## 五、室内灯光的层次感

注意我们室内用了**两种**灯：天花板点光源（主）+ 后墙两盏壁灯（辅）。这种"主灯 + 辅灯"的组合是室内照明的经典手法：

| 灯 | 角色 | 范围 | 效果 |
|----|------|------|------|
| PointLight (0,2.8,0) | 主灯 | 全室 | 整体提亮，让室内不黑 |
| SpotLight ×2 (±2,2.5,-2.8) | 辅灯 | 局部 | 后墙打出光锥，营造氛围 |

如果只用点光源，室内会"平"——到处一样亮，没有层次。加上两盏聚光灯后，后墙附近会有明亮的光斑，前部稍暗，形成纵深。stage-09 加家具后，壁灯还能在家具上投出局部阴影，真实感倍增。

::: tip 灯光颜色与情绪
灯光颜色直接影响场景情绪。我们用 `0xffd27a`（暖黄）和 `0xffe4b5`（暖白）——暖色光让人感觉温馨、居家，适合乡村小屋。如果换成 `0xe0e0ff`（冷白）就会变成医院/实验室的冷清感。做夜景时，月光用 `0xb0c4de`（冷蓝），室内用暖光，冷暖对比能极大提升画面张力。
:::

## 六、本节总结

- `PointLight` 从一点向四面八方发光，有 `distance`（射程）和 `decay`（衰减）两个核心参数
- `decay=2` 是物理正确，`1.5` 让衰减稍缓更适合室内；`distance=0` 不衰减（不推荐）
- 点光源阴影是立方体贴图，开销是平行光的 6 倍，`mapSize` 必须降级到 512
- `SpotLight` 在点光源基础上加方向（`target`）和角度（`angle`），形成光锥
- `angle` 是**半角**，想要 60° 全锥角写 `Math.PI/6`——这是最常踩的坑
- `penumbra` 控制锥边柔和度，0.3~0.5 是自然值
- `SpotLightHelper` 用线框画出光锥，教学调试必备，改了灯光参数要每帧 `update()`
- 室内照明用"主灯 + 辅灯"组合：点光源整体提亮 + 聚光灯局部打光，营造层次感
