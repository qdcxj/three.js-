# 阴影系统

阴影是 3D 场景"真实感"的最后一块拼图。没有阴影，物体像悬浮在空中；有了阴影，物体才"落"在地面上，场景才有空间纵深。前两节我们给灯光加了 `castShadow`，但阴影要真正生效，需要"渲染器 / 光源 / 物体"三层全部配置正确，缺一不可。本节把这三层串成完整体系，并给出一份能独立排查"没有阴影 / 阴影痤疮 / 阴影断裂"的检查清单。掌握本节，你就拿下了 Three.js 灯光体系最难的部分。

## 一、阴影的本质：阴影贴图（Shadow Map）

Three.js 的阴影用的是**阴影贴图（Shadow Map）**技术，原理分两步：

1. **从光源视角渲染一张深度图**：把相机放到光源位置，朝目标看，记录每个像素的深度（离光源多远）。这张图叫阴影贴图
2. **正式渲染时比对深度**：对每个片元，计算它到光源的距离，与阴影贴图里的深度比对。如果片元比贴图里的深度远，说明它被前面的物体挡住了，处于阴影中

这就解释了为什么阴影配置要分三层：渲染器层（开启阴影贴图功能）、光源层（提供深度图）、物体层（标记谁投谁收）。少任何一层，阴影都出不来。

```js
// 阴影系统的三层模型
// 第 1 层：渲染器 —— 开启阴影贴图功能
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;

// 第 2 层：光源 —— 开启投影 + 配置阴影相机
sun.castShadow = true;
sun.shadow.mapSize.set(2048, 2048);
sun.shadow.camera.left = -15; /* ... */

// 第 3 层：物体 —— 标记谁投阴影、谁接收阴影
wall.castShadow = true;     // 墙投阴影
ground.receiveShadow = true; // 草地接收阴影
```

## 二、第 1 层：渲染器配置

渲染器层只有两个属性，但决定了阴影的"总开关"和"风格"。

### 2.1 开启阴影

```js
renderer.shadowMap.enabled = true;
```

这是总开关。不开启它，所有光源的 `castShadow` 和物体的 `castShadow/receiveShadow` 全部失效。**90% 的"没有阴影"问题出在这里**——忘了开总开关。

### 2.2 阴影类型

```js
renderer.shadowMap.type = THREE.PCFSoftShadowMap;
```

Three.js 提供 3 种阴影类型：

| 类型 | 效果 | 性能 | 适用 |
|------|------|------|------|
| `BasicShadowMap` | 硬边、锯齿明显 | 最快 | 低保真 / 卡通风格 |
| `PCFShadowMap` | 软边、轻微锯齿 | 中 | 默认值，通用 |
| `PCFSoftShadowMap` | 软边、柔和 | 较慢 | 真实感首选 |
| `VSMShadowMap` | 可模糊、可透明 | 慢 | 进阶（有光渗问题） |

我们用 `PCFSoftShadowMap`——阳光长影边缘柔和，不像刀切那样生硬。这是真实感与性能的最佳平衡点。

::: warning 改类型要趁早
`shadowMap.type` 必须在第一次渲染前设置。运行时改它会导致已生成的阴影贴图失效，需要手动 `material.needsUpdate = true`。所以**在 `initScene()` 里一次性设好**，不要在运行时切换。
:::

## 三、第 2 层：光源配置

光源层决定"阴影从哪来、有多清晰、覆盖哪片区域"。本阶段三个会投影的光源配置如下。

### 3.1 平行光阴影（阳光）

```js
sun.castShadow = true;
sun.shadow.mapSize.set(2048, 2048);

// 平行光阴影用正交相机
sun.shadow.camera.left = -15;
sun.shadow.camera.right = 15;
sun.shadow.camera.top = 15;
sun.shadow.camera.bottom = -15;
sun.shadow.camera.near = 0.1;
sun.shadow.camera.far = 30;
sun.shadow.camera.updateProjectionMatrix();

sun.shadow.bias = -0.0005;
sun.shadow.normalBias = 0.02;
```

平行光阴影用**正交相机**（`OrthographicCamera`），因为它模拟无限远光源，光线平行。正交相机的 `left/right/top/bottom` 定义阴影覆盖的矩形区域，必须覆盖整栋房子（8×6）外加余量，我们用 ±15。`near/far` 沿光路方向，要覆盖光源到目标的距离。

### 3.2 点光源阴影（室内吊灯）

```js
indoorLight.castShadow = true;
indoorLight.shadow.mapSize.set(512, 512);  // 立方体阴影，6 倍开销
indoorLight.shadow.camera.near = 0.1;
indoorLight.shadow.camera.far = 10;        // 与 distance 一致
indoorLight.shadow.bias = -0.001;
```

点光源阴影用**透视相机**，而且是 6 面立方体贴图（往 6 个方向各拍一张）。`mapSize` 必须降级到 512，否则显存和帧率都会爆。`far` 与 `distance` 保持一致即可。

### 3.3 聚光灯阴影（壁灯）

```js
spot.castShadow = true;
spot.shadow.mapSize.set(1024, 1024);
spot.shadow.camera.near = 0.5;
spot.shadow.camera.far = 10;
spot.shadow.bias = -0.0005;
```

聚光灯阴影用**透视相机**，视锥角由 `spot.angle` 决定，无需手动设 `left/right`。`mapSize` 用 1024（介于平行光和点光之间），`near` 不要设太小（0.5），避免壁灯附近的墙面产生自阴影。

::: tip 阴影相机类型对照
- 平行光 → 正交相机（手设 left/right/top/bottom）
- 点光源 → 透视相机 + 立方体贴图（只设 near/far）
- 聚光灯 → 透视相机（视锥角随 `angle`，只设 near/far）
:::

## 四、第 3 层：物体配置

物体层最简单但最容易漏。每个 `Mesh` 有两个布尔属性：

- `castShadow`：是否**投射**阴影（挡光，在别处留下影子）
- `receiveShadow`：是否**接收**阴影（被别人的影子落在身上）

一个物体可以只投不收、只收不投、既投又收、都不做——取决于物理特性。本阶段小屋的配置：

| 物体 | castShadow | receiveShadow | 理由 |
|------|------------|---------------|------|
| 草地 | 否 | 是 | 平地不挡光，但要承接房子长影 |
| 地基/台阶 | 是 | 是 | 立体物挡光，也承接屋顶投影 |
| 墙体 | 是 | 是 | 挡光，墙面承接屋顶/树影 |
| 屋顶/山墙 | 是 | 是 | 挡光，屋顶面承接烟囱投影 |
| 烟囱 | 是 | 是 | 立体物，全开 |
| 木门 | 是 | 是 | 立体物，全开 |
| 室内地板 | 是 | 是 | 承接壁灯光锥下的家具投影 |
| 窗框 | 是 | 是 | 立体物，全开 |
| 玻璃 | **否** | **否** | 透明物，阳光应穿过它 |

```js
// 草地：只接收
ground.receiveShadow = true;

// 墙体：既投又收
wall.castShadow = true;
wall.receiveShadow = true;

// 玻璃：都不做（阳光穿过玻璃照进室内）
glass.castShadow = false;
glass.receiveShadow = false;
```

::: warning 玻璃为什么不投影
玻璃是透明物体，物理上阳光应穿过它照进室内。如果给玻璃开 `castShadow`，它会像实心墙一样投下完整阴影，室内就黑了。所以玻璃 `castShadow=false`。代价是玻璃后的物体也不会被玻璃挡光——这是阴影贴图技术的固有局限（它只支持不透明阴影）。要实现真正的透明阴影（彩色玻璃投影），需要用着色器自定义，留到 stage-10 着色器章节。
:::

## 五、shadow.camera 范围与阴影质量

这是阴影系统最需要调的参数。`shadow.camera` 的可视范围决定了"哪片区域内的物体会被画进阴影贴图"。范围之外的物体完全不投阴影——即使它 `castShadow=true`。

### 5.1 范围太小：阴影被裁切

如果 `shadow.camera.left/right/top/bottom` 只覆盖了房子中心一小块，房子的边缘（如屋檐、烟囱）就会"消失"在阴影贴图之外，投不出影子。表现为：房子中间有阴影，四周边缘的影子突然断掉。

### 5.2 范围太大：阴影变糊

范围越大，同样的 `mapSize`（2048×2048）被"摊"到越大的面积上，单个像素代表的实际尺寸越大，阴影越糊。表现为：影子边缘模糊不清，像有一层雾。

### 5.3 取舍：刚好覆盖场景

最佳实践是**范围刚好覆盖需要投影的物体**。我们的房子 8×6，加上影子会朝左下方拉长约 5m，所以用 ±15 既能覆盖房子本体，又能覆盖落影区域，又不至于过大。

```js
// 刚好覆盖：±15 对 8×6 的房子
sun.shadow.camera.left = -15;
sun.shadow.camera.right = 15;
sun.shadow.camera.top = 15;
sun.shadow.camera.bottom = -15;
```

## 六、shadow.bias 与阴影痤疮

`shadow.bias` 是阴影系统最"玄学"的参数。它解决的是**阴影痤疮（shadow acne）**——物体表面出现条纹状、网格状的假阴影。

### 6.1 痤疮的成因

阴影贴图是离散的像素，每个像素记录一个深度值。当物体表面与光路接近平行时，多个片元会落到同一个阴影贴图像素上，但它们的实际深度略有差异。深度比较时，部分片元会被误判为"在阴影里"，于是表面出现亮暗相间的条纹——这就是痤疮。

### 6.2 用 bias 消除

`bias` 给深度比较加一个偏移量，把阴影"推"到表面之下，让片元不再误判为自己挡自己。负偏置（`-0.0005`）是常用值：

```js
sun.shadow.bias = -0.0005;
```

`normalBias` 沿法线方向偏置，对薄物体（墙板、屋顶板）更有效，且不会让阴影"漂浮"（`bias` 过大时影子会和物体分离）：

```js
sun.shadow.normalBias = 0.02;
```

### 6.3 bias 过大的副作用

`bias` 不是越大越好。过大时，阴影会从物体底部"脱开"——比如墙根的影子会悬空一段距离，看起来像物体浮起来了。所以 bias 要调到"刚好消除痤疮"的最小绝对值。一般 `-0.0001 ~ -0.001` 之间，薄物体可加 `normalBias 0.01 ~ 0.05`。

::: tip 痤疮 vs 漂浮
- 表面有条纹假影 → 痤疮 → **增大** `bias` 的绝对值（更负）
- 阴影和物体脱节、底部悬空 → 漂浮 → **减小** `bias` 的绝对值（更接近 0）
两者是反向的，要反复微调找到平衡点。
:::

## 七、阴影问题排查清单

把前面所有要点汇总成一份清单，遇到阴影问题按此顺序排查。

### 7.1 问题：完全没有阴影

按这个顺序检查 5 个开关：

1. `renderer.shadowMap.enabled === true`（总开关，最常漏）
2. 光源 `light.castShadow === true`（光源投不投）
3. 投影物体 `mesh.castShadow === true`（投阴影的物体）
4. 接收物体 `mesh.receiveShadow === true`（接收阴影的物体）
5. `light.shadow.camera` 范围覆盖了物体（范围外的物体不投阴影）

还有两个隐藏坑：

6. 材质必须是受光材质（`MeshStandardMaterial` 等），`MeshBasicMaterial` 不参与阴影
7. `DirectionalLight.target` / `SpotLight.target` 必须 `scene.add()`，否则方向错误，阴影投错地方

### 7.2 问题：阴影痤疮（表面条纹）

1. 设 `light.shadow.bias = -0.0005`（负值）
2. 薄物体加 `light.shadow.normalBias = 0.02`
3. 仍不行，增大 `mapSize`（精度提高，减少误判）

### 7.3 问题：阴影断裂 / 被裁切

1. 增大 `shadow.camera` 的 `left/right/top/bottom` 范围
2. 增大 `shadow.camera.far`，确保覆盖光路
3. 检查 `shadow.camera.updateProjectionMatrix()` 是否调用（改参数后必须调）

### 7.4 问题：阴影太糊

1. 增大 `shadow.mapSize`（512→1024→2048）
2. 缩小 `shadow.camera` 范围（让贴图覆盖更小面积）
3. 检查 `shadowMap.type` 是否为 `PCFSoftShadowMap`

### 7.5 问题：阴影漂浮（与物体脱节）

1. 减小 `shadow.bias` 的绝对值（更接近 0）
2. 减小 `shadow.normalBias`
3. 检查物体是否真的贴地（位置 y 对不对）

## 八、整合：完整的阴影配置

把本阶段三个投影光源的阴影配置汇总，这就是 `HouseScene.vue` 里 `addLights()` 的阴影部分：

```js
// 阳光（平行光）阴影
sun.castShadow = true;
sun.shadow.mapSize.set(2048, 2048);
sun.shadow.camera.left = -15;
sun.shadow.camera.right = 15;
sun.shadow.camera.top = 15;
sun.shadow.camera.bottom = -15;
sun.shadow.camera.near = 0.1;
sun.shadow.camera.far = 30;
sun.shadow.bias = -0.0005;
sun.shadow.normalBias = 0.02;
sun.shadow.camera.updateProjectionMatrix();

// 室内点光源阴影（立方体贴图，降级 512）
indoorLight.castShadow = true;
indoorLight.shadow.mapSize.set(512, 512);
indoorLight.shadow.camera.near = 0.1;
indoorLight.shadow.camera.far = 10;
indoorLight.shadow.bias = -0.001;

// 壁灯聚光灯阴影
spot.castShadow = true;
spot.shadow.mapSize.set(1024, 1024);
spot.shadow.camera.near = 0.5;
spot.shadow.camera.far = 10;
spot.shadow.bias = -0.0005;
```

物体层则遵循"实体全开、玻璃全关、草地只收"的原则：

```js
ground.receiveShadow = true;            // 草地只接收
wall.castShadow = true;                 // 墙既投又收
wall.receiveShadow = true;
roof.castShadow = true;                 // 屋顶既投又收
roof.receiveShadow = true;
glass.castShadow = false;               // 玻璃都不做
glass.receiveShadow = false;
```

## 九、dispose 释放阴影资源

阴影贴图是 GPU 资源，组件卸载时必须手动释放，否则会内存泄漏。我们的 `disposeScene()` 单独处理了灯光：

```js
lights.forEach((l) => {
  if (l.shadow && l.shadow.map) l.shadow.map.dispose();  // 释放阴影贴图
  if (l.parent) l.parent.remove(l);
  if (l.target && l.target.parent) l.target.parent.remove(l.target);
});
lightHelpers.forEach((h) => {
  if (h.parent) h.parent.remove(h);
  if (h.dispose) h.dispose();
});
```

::: warning 别忘了 shadow.map
普通 `light.dispose()` 不会自动释放 `shadow.map`。必须显式 `light.shadow.map.dispose()`，否则切场景时阴影贴图会一直留在显存里，几次切换后显存就满了。
:::

## 十、本节总结

- 阴影用**阴影贴图**技术：从光源视角拍深度图，正式渲染时比对深度判断阴影
- 阴影配置分**三层**：渲染器（`shadowMap.enabled/type`）、光源（`castShadow/camera/mapSize/bias`）、物体（`castShadow/receiveShadow`），缺一不可
- 平行光阴影用正交相机（手设范围），点光源用立方体贴图（6 倍开销，mapSize 降级），聚光灯用透视相机（角随 `angle`）
- `shadow.camera` 范围**刚好覆盖场景**——太小裁切、太大变糊
- `shadow.bias` 消除阴影痤疮（负值），`normalBias` 处理薄物体自阴影，过大则阴影漂浮
- 物体层原则：实体全开（投+收）、玻璃全关、地面只收
- dispose 要显式释放 `shadow.map`，否则显存泄漏
- 排查清单：没阴影查 5 开关；痤疮加 bias；断裂扩范围；变糊升 mapSize；漂浮减 bias
