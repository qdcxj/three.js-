# 着色器基础：ShaderMaterial 三件套与 GLSL 内置变量

前 9 个阶段我们用的都是 Three.js 内置材质：`MeshBasicMaterial`、`MeshStandardMaterial`、`MeshPhysicalMaterial`——它们封装好了一切，你只要给 `color`、`map`、`roughness`，Three.js 就自动生成对应的 GPU 程序。但封装越厚，灵活性越低：你无法让玻璃"按视线角度反光"、无法让草地"按时间起伏"。要做这两件事，必须直接写 GPU 程序——也就是**着色器（Shader）**。本节是 stage-10 的理论基石：先讲清楚 ShaderMaterial 的"三件套"结构，再讲清楚 uniforms/attribute/varying 三种变量的本质区别，最后给出一份 GLSL 速查表，让你能看懂后续两节的玻璃与草地着色器代码。

## 一、什么是着色器

着色器是运行在 GPU 上的小程序。Three.js 中我们写的是 **GLSL**（OpenGL Shading Language），它有两个核心入口：

- **顶点着色器（Vertex Shader）**：对每个顶点运行一次，负责把顶点从模型空间变换到裁剪空间（屏幕），并可以向片段着色器传递数据。它的"输出"是顶点的最终位置 `gl_Position`。
- **片段着色器（Fragment Shader）**：对每个像素（更准确地说是每个片段）运行一次，负责决定这个像素的颜色。它的"输出"是 `gl_FragColor`。

可以这样理解流水线：

```
顶点数据 (position/normal/uv)
        ↓
   顶点着色器  ← uniforms（全局参数，如 uTime）
        ↓
   光栅化（顶点之间插值成像素）
        ↓
   片段着色器  ← uniforms + varying（从顶点着色器传来的插值数据）
        ↓
   像素颜色 (gl_FragColor)
```

::: tip 顶点数 vs 像素数
顶点着色器运行的次数 = 顶点数（草地 100×100 细分 = 10201 次/帧）；片段着色器运行的次数 = 像素数（草地铺满半屏 ≈ 几十万次/帧）。所以片段着色器里的计算越简单越好——这正是 GPU 并行的精髓。
:::

## 二、ShaderMaterial 三件套

`ShaderMaterial` 是 Three.js 提供的"写自定义着色器"的材质类。它的核心是三件套：

```js
import * as THREE from "three";

const material = new THREE.ShaderMaterial({
  // 1. uniforms：JS → GPU 的全局参数，所有顶点/片段共享
  uniforms: {
    uTime: { value: 0 },
    uColorA: { value: new THREE.Color(0xa8d0ff) },
    uColorB: { value: new THREE.Color(0xffffff) },
  },
  // 2. vertexShader：顶点着色器 GLSL 源码（字符串）
  vertexShader: /* glsl */ `
    void main() {
      gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
    }
  `,
  // 3. fragmentShader：片段着色器 GLSL 源码（字符串）
  fragmentShader: /* glsl */ `
    void main() {
      gl_FragColor = vec4(1.0, 1.0, 1.0, 1.0); // 白色
    }
  `,
  // 可选：透明、双面、不写深度等
  transparent: true,
  side: THREE.DoubleSide,
});
```

三个字段缺一不可。`uniforms` 是 JS 与 GLSL 之间的"桥梁"——JS 这边改 `uniforms.uTime.value`，下一帧 GPU 就能读到新值。

::: warning uniforms 必须用 `{ value: ... }` 包装
这是 Three.js 的约定：`uniforms` 的每个字段必须是 `{ value: 某个值 }` 的对象，不能直接写值。这是因为 Three.js 需要在内部追踪 value 的类型（float / vec3 / Color / Texture）来选择正确的 GPU 上传方式。
:::

## 三、三种变量：uniforms / attribute / varying

这是着色器最容易混淆的概念。一张表说清楚：

| 变量类型 | 中文名 | 数据流向 | 谁声明 | 谁能改 | 典型用途 |
|---------|--------|---------|--------|--------|---------|
| **uniform** | 全局变量 | JS → GPU（顶点+片段共享） | JS 端 `uniforms` 配置 + GLSL 端 `uniform` 关键字声明 | JS 端改 `.value` | uTime、uColor、相机位置 |
| **attribute** | 顶点属性 | 几何体 → 顶点着色器 | Three.js 内置或 `BufferGeometry` 自定义 | 几何体数据，每顶点不同 | position、normal、uv |
| **varying** | 插值变量 | 顶点着色器 → 片段着色器 | 两端都用 `varying` 关键字声明（同名同类型） | 顶点着色器写、片段着色器读 | 把 uv/normal/worldPos 传给片段 |

### 1. uniform：全局共享

uniform 在一次绘制调用中对所有顶点/片段都是同一个值。改 uniform 比改顶点数据便宜得多，所以时间、颜色、变换矩阵都用 uniform。

```glsl
// GLSL 端声明
uniform float uTime;
uniform vec3 uColorA;
```

```js
// JS 端配置 + 更新
const material = new THREE.ShaderMaterial({
  uniforms: {
    uTime: { value: 0 },
    uColorA: { value: new THREE.Color(0xa8d0ff) },
  },
  // ...
});
// 渲染循环里更新
material.uniforms.uTime.value = clock.getElapsedTime();
```

### 2. attribute：每顶点不同

attribute 是几何体自带的"每顶点数据"。Three.js 的 `BoxGeometry` / `PlaneGeometry` 等会自动生成 `position`、`normal`、`uv` 三个 attribute，你不需要自己声明就能在顶点着色器里直接用。

```glsl
// Three.js 自动注入的 attribute（不需要你声明）
attribute vec3 position;  // 顶点局部坐标
attribute vec3 normal;    // 顶点法线
attribute vec2 uv;        // 纹理坐标
```

::: tip attribute 只能在顶点着色器用
attribute 是"每顶点"的数据，而片段着色器处理的是"每像素"。要把 attribute 数据传到片段着色器，必须通过 varying"插值"——下一小节讲。
:::

### 3. varying：顶点 → 片段

varying 是顶点着色器和片段着色器之间的"传话筒"。顶点着色器写入 varying，光栅化阶段会在三个顶点之间线性插值，片段着色器读到的就是插值后的值。

```glsl
// 顶点着色器
varying vec2 vUv;       // 声明
void main() {
  vUv = uv;             // 写入（uv 是内置 attribute）
  gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
}
```

```glsl
// 片段着色器
varying vec2 vUv;       // 同名同类型声明
void main() {
  // vUv 是三个顶点 uv 插值后的结果，每个像素不同
  gl_FragColor = vec4(vUv.x, vUv.y, 0.5, 1.0);
}
```

本阶段的玻璃着色器用 varying 传递 `vNormalW`（世界法线）和 `vWorldPos`（世界坐标）给片段着色器，草地着色器用 varying 传递 `vWave`（波动高度）——这些都是"顶点算一次，片段插值用"的典型场景。

## 四、Three.js 自动注入的内置变量

`ShaderMaterial`（不是 `RawShaderMaterial`）会自动注入一批内置 uniform 和 attribute，你不需要自己声明就能直接用。这是 ShaderMaterial 比 RawShaderMaterial 友好的地方。

### 内置 uniform（顶点 + 片段都能用）

| 名称 | 类型 | 含义 |
|------|------|------|
| `projectionMatrix` | `mat4` | 投影矩阵（相机 fov/aspect/near/far 决定） |
| `modelViewMatrix` | `mat4` | 模型 × 视图矩阵（局部 → 视图空间） |
| `viewMatrix` | `mat4` | 视图矩阵（世界 → 视图空间） |
| `modelMatrix` | `mat4` | 模型矩阵（局部 → 世界空间） |
| `normalMatrix` | `mat3` | 法线矩阵（modelViewMatrix 逆转置的 3×3 部分） |
| `cameraPosition` | `vec3` | 相机在世界空间的位置 |

### 内置 attribute（只能在顶点着色器用）

| 名称 | 类型 | 含义 |
|------|------|------|
| `position` | `vec3` | 顶点局部坐标 |
| `normal` | `vec3` | 顶点法线（局部空间） |
| `uv` | `vec2` | 纹理坐标 |

### 内置 varying（无需声明，但 ShaderMaterial 不会自动注入，需手动写）

实际上 Three.js 不会自动帮你声明 varying，你需要在两个着色器里同名声明。但有一些"约定俗成"的命名（如 `vUv`、`vNormal`）是社区惯例。

### 最小可用顶点着色器

```glsl
void main() {
  // 标准变换：局部 → 视图 → 裁剪
  gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
}
```

### 最小可用片段着色器

```glsl
void main() {
  gl_FragColor = vec4(1.0); // 不透明纯白
}
```

## 五、GLSL 速查表

GLSL 是 C 风格的强类型语言。下面是写本阶段着色器需要的全部语法：

### 类型

| 类型 | 含义 | 示例 |
|------|------|------|
| `float` | 标量 | `float a = 1.5;` |
| `int` | 整数 | `int i = 0;` |
| `bool` | 布尔 | `bool b = true;` |
| `vec2` / `vec3` / `vec4` | 2/3/4 维向量 | `vec3 c = vec3(1.0, 0.5, 0.0);` |
| `mat3` / `mat4` | 3×3 / 4×4 矩阵 | `mat4 m = mat4(1.0);` |
| `sampler2D` | 2D 纹理 | `uniform sampler2D uMap;` |

### 向量分量访问（swizzling）

```glsl
vec4 c = vec4(1.0, 0.5, 0.3, 1.0);
float r = c.r;     // 红色通道
vec3 rgb = c.rgb;  // 取前三分量
vec2 rg = c.rg;    // 取红绿
// xyzw 与 rgba 等价，可混用但建议同一向量内一致
```

### 常用内置函数

| 函数 | 作用 |
|------|------|
| `sin(x)` / `cos(x)` | 正弦/余弦（弧度） |
| `pow(x, n)` | x 的 n 次方 |
| `sqrt(x)` | 平方根 |
| `abs(x)` | 绝对值 |
| `max(x, y)` / `min(x, y)` | 最大/最小 |
| `clamp(x, a, b)` | 把 x 限制在 [a, b] |
| `mix(a, b, t)` | 线性插值 a→b，t∈[0,1] |
| `smoothstep(a, b, x)` | 平滑过渡（Hermite 插值），x≤a 返回 0，x≥b 返回 1 |
| `normalize(v)` | 归一化向量 |
| `dot(a, b)` | 点积 |
| `cross(a, b)` | 叉积 |
| `length(v)` | 向量长度 |
| `reflect(i, n)` | 反射向量（i 入射方向，n 法线） |

::: tip mix 与 smoothstep 是着色器灵魂
`mix(a, b, t)` 等价于 `a * (1-t) + b * t`，是颜色/数值混合的主力；`smoothstep(a, b, x)` 在 a/b 之间做平滑过渡，比 clamp 更柔和。本阶段玻璃着色器用 `mix` 混合中心/边缘色，草地着色器用 `smoothstep` 让高低过渡更自然。
:::

### 矩阵 × 向量

```glsl
vec4 worldPos = modelMatrix * vec4(position, 1.0); // 局部 → 世界
vec4 viewPos = viewMatrix * worldPos;              // 世界 → 视图
vec4 clipPos = projectionMatrix * viewPos;         // 视图 → 裁剪
// 也可合并：modelViewMatrix = viewMatrix * modelMatrix
gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
```

## 六、最简 ShaderMaterial 实例

把上面所有知识串起来，写一个"全白"的最简着色器，确认环境能跑通：

```js
import * as THREE from "three";

const geo = new THREE.PlaneGeometry(2, 2);
const mat = new THREE.ShaderMaterial({
  uniforms: {
    uTime: { value: 0 },
  },
  vertexShader: /* glsl */ `
    varying vec2 vUv;
    void main() {
      vUv = uv;
      gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
    }
  `,
  fragmentShader: /* glsl */ `
    uniform float uTime;
    varying vec2 vUv;
    void main() {
      // 用 uTime 让颜色随时间变化，验证 uniform 通路
      float g = 0.5 + 0.5 * sin(uTime);
      gl_FragColor = vec4(vUv.x, vUv.y, g, 1.0);
    }
  `,
});

const mesh = new THREE.Mesh(geo, mat);
scene.add(mesh);

// 渲染循环
function animate() {
  requestAnimationFrame(animate);
  mat.uniforms.uTime.value += 0.01; // 更新 uniform
  renderer.render(scene, camera);
}
```

::: tip 调试着色器
着色器报错时，浏览器控制台会打印 GLSL 编译错误，但行号对的是 GLSL 源码不是 JS 源码——排查时要看错误信息里的 "ERROR: 0:行号"。常见错误：忘记分号、`float` 写成 `int`（GLSL 不会自动转型，`1.0` 不能写成 `1`）、向量分量用错（`vec3.rg` 不合法，必须 `vec3.rgb` 或 `vec3.xy`）。
:::

::: warning GLSL 必须用浮点字面量
GLSL 是强类型语言，`float a = 1;` 会编译失败，必须写 `float a = 1.0;`。`sin(1)` 也不行，必须 `sin(1.0)` 或 `sin(float(1))`。这是初学者最常踩的坑。
:::

## 本节总结

| 知识点 | 关键 API / 语法 | 说明 |
|--------|----------------|------|
| ShaderMaterial | `new THREE.ShaderMaterial({ uniforms, vertexShader, fragmentShader })` | 三件套缺一不可 |
| uniforms | `{ value: ... }` 包装 | JS → GPU 全局参数 |
| attribute | Three.js 自动注入 position/normal/uv | 几何体每顶点数据 |
| varying | 顶点 + 片段同名声明 | 顶点 → 片段插值 |
| 内置 uniform | projectionMatrix / modelViewMatrix / modelMatrix / viewMatrix / normalMatrix / cameraPosition | ShaderMaterial 自动注入 |
| 内置 attribute | position / normal / uv | ShaderMaterial 自动注入 |
| 顶点输出 | `gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0)` | 标准变换链 |
| 片段输出 | `gl_FragColor = vec4(r, g, b, a)` | 决定像素颜色 |
| 更新 uniform | `material.uniforms.uTime.value = elapsed` | 渲染循环里调用 |
| GLSL 浮点 | 必须写 `1.0` 不能写 `1` | 强类型，不会自动转型 |
| mix / smoothstep | `mix(a, b, t)` / `smoothstep(a, b, x)` | 颜色/数值混合主力 |
