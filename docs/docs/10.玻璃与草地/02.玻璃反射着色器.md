# 玻璃反射着色器：菲涅尔反射让玻璃"活"起来

stage-05 我们用 `MeshPhysicalMaterial` 的 `transmission` 实现了"透射玻璃"——它能透光，但不会反光。真实世界的玻璃有两个特点：正视时透明（你能看到室内），斜看时反光（你看到的是天光与周围环境的倒影）。这种"视线越平行表面、反射越强"的现象，物理学上叫**菲涅尔反射（Fresnel reflection）**。本节我们用 ShaderMaterial 手写一个菲涅尔反射着色器，把小屋的 4 块玻璃换成"真玻璃"——边缘反光强、中心透射强，并随 uTime 微微闪烁。

## 一、菲涅尔反射原理

### 1. 现象观察

站在窗前正视玻璃，你能清楚看到室内；侧身斜看玻璃，室内变模糊，玻璃上倒映着天空与对面建筑。这就是菲涅尔效应：**反射强度随视线与表面法线夹角增大而增大**。

### 2. 物理公式（Schlick 近似）

完整的菲涅nel 方程很复杂，工程上常用 Schlick 近似：

```
R(θ) = R0 + (1 - R0) * (1 - cos θ)^5
```

- `θ` 是视线方向与法线的夹角
- `R0` 是正视时的反射率（垂直入射），取决于两种介质的折射率
- 当 θ → 90°（视线擦过表面）时，cos θ → 0，R → 1（全反射）

在着色器里我们常用更简化的形式：

```glsl
float fresnel = 1.0 - max(dot(viewDir, normal), 0.0);
fresnel = pow(fresnel, 2.5); // 控制边缘锐度，指数越大边缘越窄越亮
```

- `dot(viewDir, normal)`：视线与法线的点积。正视时 = 1，斜看时 → 0
- `1 - dot`：正视 = 0（不反射），斜看 → 1（强反射）
- `pow(_, 2.5)`：让过渡更陡，集中在边缘

::: tip 为什么用 pow 调整
直接用 `1 - dot` 反射区域太宽，整个玻璃都偏亮。`pow(_, n)` 把数值压向 0，只有边缘（接近 90°）才显著抬升。指数 n 越大，反射越集中在极边缘。本阶段取 2.5 是经验值，效果接近真实玻璃。
:::

## 二、需要的输入数据

要计算菲涅尔，片段着色器需要两个向量：

1. **视线方向 `viewDir`**：从像素指向相机。Three.js 内置 `cameraPosition` uniform（世界空间相机位置），减去像素世界坐标即可
2. **法线 `normal`**：像素所在表面的法线（世界空间）

所以顶点着色器要做两件事：
- 把法线从局部变换到世界空间，传给片段着色器
- 把顶点位置变换到世界空间，传给片段着色器（用于算 viewDir）

### 法线变换的注意点

法线不能直接用 `modelMatrix` 变换——如果模型有非均匀缩放，法线会变形。正确做法是用 `normalMatrix`（Three.js 自动注入的 mat3，等于 modelViewMatrix 逆转置的 3×3 部分）。但 `normalMatrix` 把法线变到**视图空间**，而我们要的是**世界空间**（因为 `cameraPosition` 是世界空间）。

折中方案：用 `modelMatrix` 的 3×3 部分变换法线（`mat3(modelMatrix) * normal`）。只要模型没有非均匀缩放，结果就是正确的。本阶段玻璃 mesh 没有缩放，所以这个简化是安全的。

```glsl
vNormalW = normalize(mat3(modelMatrix) * normal);
```

::: warning 非均匀缩放会出问题
如果 mesh 有 `scale.set(1, 2, 1)` 这种非均匀缩放，`mat3(modelMatrix) * normal` 会得到错误法线。这种情况下要用 `transpose(inverse(mat3(modelMatrix))) * normal`。GLSL ES 1.0 没有 `inverse` 内置函数，需要手写或用 normalMatrix + 额外变换。本阶段玻璃没有缩放，简化是安全的。
:::

## 三、顶点着色器实现

顶点着色器的职责：透传 uv + 把法线/位置变换到世界空间。

```glsl
// Three.js 自动注入：modelMatrix / viewMatrix / projectionMatrix /
//                    normalMatrix / cameraPosition / position / normal / uv
varying vec2 vUv;
varying vec3 vNormalW;   // 世界空间法线
varying vec3 vWorldPos;  // 世界空间顶点坐标

void main() {
  vUv = uv;
  // 法线：用 modelMatrix 的 3×3 部分变换到世界空间（无缩放时正确）
  vNormalW = normalize(mat3(modelMatrix) * normal);
  // 顶点：用 modelMatrix 变换到世界空间
  vec4 worldPos = modelMatrix * vec4(position, 1.0);
  vWorldPos = worldPos.xyz;
  // 标准变换链：世界 → 视图 → 裁剪
  gl_Position = projectionMatrix * viewMatrix * worldPos;
}
```

注意这里没有用 `projectionMatrix * modelViewMatrix`（最简形式），而是拆成 `projectionMatrix * viewMatrix * worldPos`——因为我们需要中间产物 `worldPos` 传给片段着色器。拆开后 `viewMatrix * worldPos` 等价于 `modelViewMatrix * vec4(position, 1.0)`，效果完全一样。

## 四、片段着色器实现

片段着色器的职责：用视线/法线算菲涅尔，混合两种颜色，加 uTime 闪烁。

```glsl
uniform float uTime;
uniform vec3 uColorA;  // 中心透射色（浅蓝）
uniform vec3 uColorB;  // 边缘反射色（天光白）

varying vec2 vUv;
varying vec3 vNormalW;
varying vec3 vWorldPos;

void main() {
  // 1) 视线方向：从顶点指向相机（cameraPosition 由 Three.js 自动注入）
  vec3 viewDir = normalize(cameraPosition - vWorldPos);

  // 2) 菲涅尔系数：视线越平行于表面（边缘），1 - dot 越接近 1
  float fresnel = 1.0 - max(dot(viewDir, normalize(vNormalW)), 0.0);
  fresnel = pow(fresnel, 2.5);

  // 3) 时间相关微光闪烁，模拟玻璃反光的动态变化
  float shimmer = sin(uTime * 2.0 + vUv.x * 10.0 + vUv.y * 6.0) * 0.05 + 0.95;

  // 4) 颜色混合：中心透射色 ↔ 边缘反射色
  vec3 color = mix(uColorA, uColorB, fresnel) * shimmer;

  // 5) 透明度也随菲涅尔变化：边缘更不透明（反光强），中心更透明
  float alpha = mix(0.35, 0.85, fresnel);

  gl_FragColor = vec4(color, alpha);
}
```

逐步拆解：

1. **viewDir**：`cameraPosition` 是世界空间相机坐标（Three.js 内置），减去像素世界坐标 `vWorldPos`，归一化后得到视线方向
2. **fresnel**：`1 - dot(viewDir, normal)`，正视 = 0、斜看 → 1；`pow(_, 2.5)` 让反射集中在边缘
3. **shimmer**：用 `sin(uTime + uv)` 产生 5% 幅度的闪烁，让玻璃不至于"死板"
4. **mix**：中心（fresnel=0）显示 uColorA 浅蓝透射色，边缘（fresnel=1）显示 uColorB 天光白反射色
5. **alpha**：中心透明度 0.35（能看穿室内），边缘 0.85（反光强、不透明）

::: tip 为什么 alpha 也随 fresnel 变
真实玻璃正视时透光率最高（透明），斜看时反光把透射光遮住（不透明）。让 alpha 跟随 fresnel 变化，比固定透明度真实得多。
:::

## 五、JS 端组装 ShaderMaterial

```js
import * as THREE from "three";

// 创建 ShaderMaterial（4 块玻璃共享同一个 material，省 GPU 程序）
const glassMaterial = new THREE.ShaderMaterial({
  uniforms: {
    uTime: { value: 0 },
    uColorA: { value: new THREE.Color(0xa8d0ff) }, // 中心透射色：浅蓝
    uColorB: { value: new THREE.Color(0xffffff) }, // 边缘反射色：天光白
  },
  vertexShader: /* glsl */ `
    varying vec2 vUv;
    varying vec3 vNormalW;
    varying vec3 vWorldPos;
    void main() {
      vUv = uv;
      vNormalW = normalize(mat3(modelMatrix) * normal);
      vec4 worldPos = modelMatrix * vec4(position, 1.0);
      vWorldPos = worldPos.xyz;
      gl_Position = projectionMatrix * viewMatrix * worldPos;
    }
  `,
  fragmentShader: /* glsl */ `
    uniform float uTime;
    uniform vec3 uColorA;
    uniform vec3 uColorB;
    varying vec2 vUv;
    varying vec3 vNormalW;
    varying vec3 vWorldPos;
    void main() {
      vec3 viewDir = normalize(cameraPosition - vWorldPos);
      float fresnel = 1.0 - max(dot(viewDir, normalize(vNormalW)), 0.0);
      fresnel = pow(fresnel, 2.5);
      float shimmer = sin(uTime * 2.0 + vUv.x * 10.0 + vUv.y * 6.0) * 0.05 + 0.95;
      vec3 color = mix(uColorA, uColorB, fresnel) * shimmer;
      float alpha = mix(0.35, 0.85, fresnel);
      gl_FragColor = vec4(color, alpha);
    }
  `,
  transparent: true,         // 启用透明
  side: THREE.DoubleSide,    // 双面都能看到（玻璃从内外看都有效）
  depthWrite: false,         // 透明物体不写深度，避免遮挡室内家具
});

// 4 块玻璃共享同一个 material
const frontGlass1 = new THREE.Mesh(
  new THREE.BoxGeometry(0.72, 1.12, 0.02),
  glassMaterial
);
frontGlass1.position.set(-2, 1.5, 3.0);
scene.add(frontGlass1);
// ... 另外 3 块玻璃同样用 glassMaterial
```

::: warning depthWrite: false 的作用
透明物体如果开 `depthWrite: true`，会先把它的深度写入深度缓冲，导致它后面的家具（在同一帧后渲染时）被深度测试剔除——家具看不见了。设 `depthWrite: false` 让玻璃不写深度，家具就能正常显示。代价是玻璃之间不会有正确的遮挡关系，但本阶段 4 块玻璃互不重叠，没问题。
:::

::: tip transparent 与 alpha 的关系
`transparent: true` 是开启"透明渲染通道"的开关。开了它，Three.js 才会按 alpha 混合（而不是直接覆盖）。如果 `transparent: false`，片段着色器输出的 alpha 会被忽略，玻璃完全不透明。
:::

## 六、在渲染循环中更新 uTime

着色器写好后，必须每帧更新 `uTime`，否则玻璃不会闪烁。在 stage-10 的 `animate` 中：

```js
const clock = new THREE.Clock();

const animate = () => {
  requestAnimationFrame(animate);
  const dt = clock.getDelta();              // 帧间隔（用于门/灯/昼夜 lerp）
  const elapsed = clock.getElapsedTime();   // 累计秒数（用于着色器 uTime）

  controls.update();
  updateDoor(dt);
  updateLamp(dt);
  updateDayNight(dt);

  // 更新玻璃着色器的 uTime
  if (glassMaterial) {
    glassMaterial.uniforms.uTime.value = elapsed;
  }

  renderer.render(scene, camera);
};
```

::: tip getDelta vs getElapsedTime
- `getDelta()`：返回**上次调用以来**的时间间隔，用于"速度"（门转多快、灯亮多快）
- `getElapsedTime()`：返回**自 start() 以来**的累计秒数，用于"绝对时间"（着色器 uTime）

两者都用同一个 Clock，互不影响。注意 `getDelta()` 会"消费"时间——连续调用两次，第二次会返回 0。`getElapsedTime()` 不消费，可以反复调。
:::

## 七、与昼夜循环的联动（可选进阶）

stage-08 的昼夜循环会改 `sunLight.color` 和 `ambientLight.intensity`，但 ShaderMaterial 不自动接收灯光。如果要让玻璃在夜晚变暗，可以加一个 `uBrightness` uniform，像草地着色器那样在 `updateDayNight` 中同步更新：

```js
// 创建时加 uniform
uniforms: {
  uTime: { value: 0 },
  uColorA: { value: new THREE.Color(0xa8d0ff) },
  uColorB: { value: new THREE.Color(0xffffff) },
  uBrightness: { value: 1.0 }, // 新增
}

// updateDayNight 中同步
glassMaterial.uniforms.uBrightness.value = 0.3 + 0.7 * dayFactor;
```

片段着色器末尾乘上 `uBrightness`：

```glsl
vec3 color = mix(uColorA, uColorB, fresnel) * shimmer * uBrightness;
```

本阶段为了教学聚焦，玻璃着色器没有加 uBrightness（让它始终保持反光效果，便于观察菲涅尔）。草地着色器则会完整演示这套联动机制。

## 八、dispose 完整释放

ShaderMaterial 走和普通材质一样的 `dispose()` 路径，会自动释放 GPU 程序：

```js
const disposeScene = () => {
  // disposables 中收集了所有 mesh（含 4 块玻璃 mesh）
  disposables.forEach((obj) => {
    if (obj.geometry) obj.geometry.dispose();
    if (obj.material) {
      if (Array.isArray(obj.material)) {
        obj.material.forEach((m) => m.dispose());
      } else {
        obj.material.dispose(); // ShaderMaterial 也能这样 dispose
      }
    }
  });
  disposables.length = 0;
  // 显式断引用
  glassMaterial = null;
};
```

::: warning 共享 material 只 dispose 一次
4 块玻璃共享同一个 `glassMaterial`。当 disposables 遍历时，每块玻璃 mesh 都会调一次 `obj.material.dispose()`——这其实会 dispose 4 次同一个 material。Three.js 的 `dispose()` 是幂等的，重复调不会报错，但理解这一点有助于排查"为什么 dispose 后还在用"的问题。
:::

## 本节总结

| 知识点 | 关键 API / 语法 | 说明 |
|--------|----------------|------|
| 菲涅尔反射 | `1.0 - max(dot(viewDir, normal), 0.0)` | 视线越擦边、反射越强 |
| Schlick 近似 | `pow(fresnel, n)` | n 控制边缘锐度 |
| 法线变换 | `normalize(mat3(modelMatrix) * normal)` | 局部 → 世界（无缩放时正确） |
| 世界坐标 | `modelMatrix * vec4(position, 1.0)` | 用于算 viewDir |
| 视线方向 | `normalize(cameraPosition - vWorldPos)` | 内置 cameraPosition uniform |
| 颜色混合 | `mix(uColorA, uColorB, fresnel)` | 中心透射 ↔ 边缘反射 |
| 时间闪烁 | `sin(uTime + uv) * 0.05 + 0.95` | 5% 幅度微光 |
| 透明设置 | `transparent: true, depthWrite: false` | 不写深度避免遮挡 |
| uTime 更新 | `glassMaterial.uniforms.uTime.value = elapsed` | 渲染循环每帧调用 |
| dispose | `material.dispose()` | 走与普通材质相同的路径 |
